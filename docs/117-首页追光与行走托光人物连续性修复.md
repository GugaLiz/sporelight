# 首页追光与行走托光人物连续性修复

2026-11-18，`dev`，继续GQ-025。用户要求修复116号后续核查确认的抬头与行走、托光形象不一致。本次只调整首页六张追光素材与对应头部锚点，原有行走、托光、光源路线、关卡人物及存档保持原实现。

## 修改与依据

116号只将帽宽与身体长度回到原比例范围，仍有圆脸、蓬发、厚帽沿和张嘴表情的身份偏差。本轮不使用被否决的追光稿作参考，以当前`idle-quarter.png`、`walk-quarter-1.png`与`palm-3.png`为直接参考，用内置image_gen编辑生成六姿势完整透明图。

六姿势统一沿用原四分之三脸，取消抬头组独立的正面脸设计与夸张张嘴，保留小幅抬眼、平视、低头和探手/胸前手势。对照原组收敛下巴、脸颊、刘海、发梢和帽沿的差异。仍是完整位图动作，并非已改成同模型骨骼动画；不保证生成素材像素级相同。

原稿与完整提示词、参考路径见[生成记录](../assets/images/cover-identity-20261118/generation.json)，原稿位于`assets/images/cover-identity-20261118/masters/attention-sheet.png`；运行六帧在`godot/assets/images/cover-identity-20261118/`，旧稿保留。包装器新增`--profile=identity`，六图同一等比尺度、靴底中心配准至512画布[256,472]，源alpha保留；更新对应颈部shader锚，没有分别缩头、拉身或拼接五官。
