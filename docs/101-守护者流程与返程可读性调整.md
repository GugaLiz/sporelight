## 本次设计

原流程保留：三节根阶接通并固定 → 主角搬重镜、伙伴接水 → 升降台运镜到高岸 → 放镜并调光 → 主角乘台下降、内庭接回西岸 → 伙伴返回 → 双人主动照料。玩家仍自行决定路线、机关朝向与操作时机。

确认的表达缺口：原目标从开局到6/8都不变；原“花阀”名称没说它控制整块地面；升降台仅有细小水柱，缺少整体运动结构；6/8被标为沿途微光，易被误解成高岸还有两件隐藏物；花坛同格默认站位让伙伴被主角遮住。

本次将当前意图放在已有目标行，一次一句。根路、供水、运镜、受光后返回、等伙伴和可照料分别表达；没有新任务面板、场景文字牌或角度答案。目标读取当前光照、方向、高低位置及真实会合关系，历史赠礼不代替当前条件。只修改3-4的动作显示名为“升起/降下升降台”“转动中央庭院”“转动水渠”“转动灯台”和“一起照料花坛”，动作ID、可用性与原选择保持。

升降台添加随整台运动的贴面铜制角箍及高岸悬挂导轨：高低行程1.30m，两条导轨经悬臂和斜撑连接到真实固定高岸f:7:-1、f:7:1的侧壁，固定锚点(6.57,.96,±1.28)，台体套环沿轨升降。中央登台口保留，没有新可走面、硬障碍或远程召台。光已送达且需要返台时铜箍轻微提亮，光线未落稳时不提前提示完成。既有地砖及移动平台纹理身份保持。

早期液压柱候选虽通过坐标/通行测试，独立看图发现固定底脚悬空，并投影到另一旋转台边，因此已否决。保留gpu-flow-candidate图及cpu-candidate检查，不能以这些旧图声称最终导轨结构通过。新结构的检查从“世界坐标固定”扩展为“实体锚点确实进入永久岸壁”，再查看实际GPU中段/落稳。

花坛继续使用100号缩小后的1.65m完整画布及受光叶，不扩大花坛。两人同格默认真实站位在石基开放的一侧分开；已保存的合法身体偏移仍保留，不用仅移动图片掩盖重叠。没有新增需要玩家猜含义的花坛徽章。
