# 场景素材重绘与通关漫步续关修复

2026-11-16，针对 `dev` 分支用户四张截图反馈。修复范围为场景贴图边缘及通关后继续旅程的入口。

## 用户反馈与原因

1. 微光收集物、石门、白花、蓝铃花和核心粉花有明显抠图感、白边和锯齿。原图中部分资源只有全透明／全不透明两种 alpha；舞台虽然选择带 mipmap 的线性滤波，原资源导入却没有生成 mipmap。仅更换滤波常量不能消除画进图里的白色残边。
2. 完成“一起种下微光”后关闭结算、留下漫步，结算只在首次完成事件打开；完成态又不再提供 `repair`，于是无法从现场再次找到下一关入口。

## 修改范围

- 内置 `imagegen` 参考现有造型重绘七张透明图：`arch`、`spore`、`gold-lotus`、`ivory-lotus`、`blue-flowers`、`flower`、`bloom`。保留高分辨母图，另导出兼容原逻辑画布的游戏贴图；花蕾从新开花态编辑，底座共用导出变换。完整提示词见[重绘提示词](scene-redraw-20261116-prompts.md)。
- 通过 `element-theme.json` 公共槽接入；原始资源仍保留。像素尺寸、根锚和两柱脚／花坛基座分别对齐，新的导入纹理生成 mipmap。保留正常深度、实体支撑和已有轮廓测量保护。
- 通关漫步增加可重复打开结算的主操作，普通关显示“前往下一片微光”，目录末尾显示“查看旅程纪事”；按钮、E 和附近操作面板共用入口。附近观察仍可使用。
- 重新查看结算不会重做种植、覆盖完成纪念或保存漫步位置。主线、云庭、回看与正常进行中的旅程仍按各自保存语义处理；下一关顺序沿用当前关卡目录。
