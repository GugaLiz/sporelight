# 终章逐行文字与告别动作及花瓣氛围

## 最终表现

- 标题先淡入，正文十行按1.45秒间隔依次出现，每行淡入1.1秒，约15秒呈现完整祝福。版面提前保留位置，不随文字出现跳动。轻触文字区域可立即显示全文，底部出口始终可用。
- 字芯保留深棕色；标题与正文用暖金阴影光晕，刚出现的句子有一次柔和提亮。初稿偏厚描边已调淡，最终以gpu-final为准。
- 以当前idle-front为图像参考，经内置image_gen生成同身份的正面举手告别姿态；完整透明原图入库，脚锚固定在台面。局部着色器驱动自由手臂挥动，九秒一轮，约1～5秒轻挥，其余时间停顿；头部轻微回应，不拉伸头身、不叠两张脸。小苔灵在旁微笑、轻摇回应。
- 42片远近花瓣，带随风漂移、翻转和叶脉高光；112颗散布微光使用多层柔晕。近层在角色前、远层在角色后，文字与按钮始终在最上层；阅读区域主动降低花瓣与粒子的透明度。
- 减少动态立即显示全文并冻结角色、花瓣和粒子；粒子关闭隐藏新增花瓣和散点。原微光与光虫装饰保留。
