# Native draw CPU profile

The retained scripts are instrumented copies of the current presentation code, outside the Godot resource tree. They do not change the application. `profile_paint.gd` extends the original painter; `profile_view.gd` times the current view and calls the original environment. The harness draws initial 1-1 and 2-2 at 1280×720, fixed visual time 1200 ms, warms 12 frames, then records 30 draws each. There is no HUD or save I/O. Inclusive rows overlap and include timer/wrapper overhead; these numbers are not Web frame rates.

From the repository root, run the pinned engine with the Godot project and the absolute path of `draw-profile.gd`. Use `--headless` for CPU-only submission or `--rendering-method gl_compatibility --audio-driver Dummy` for GPU submission. Launch graphical runs hidden and offscreen as required by the project conventions. Output is written alongside the harness as `current-Windows.json` or `current-headless.json`.

`before.json` includes additional pond section timings and geometric counts from a temporary instrumented copy before the geography cache. `after.json` uses the same view/painter grouping after the cache. `comparison.json` records the source hashes and measured deltas. Both source variants use primitive ellipse fans, so the comparison isolates pond geography caching. Warm gradient/material cache counts stayed unchanged.

Before: 2-2 performs 195 polygon queries against a 252-point shape, 3565 grid-to-tile distance checks and 713 particle-to-tile iterations every draw. After: one per-view geography record holds inside cells, proximity flags, particle seeds/positions and eligible edge tiles. Camera projection, water translation, drawing order, rain, ripple phases and particle animation still update every draw. The cache key covers the actual authored level dictionary and rule tile data; only one geography entry is retained per view.

Correctness evidence: `visual_pond_geometry_test.gd` compares 12 original reference states under four camera/water transforms (180 checks), including cache hits, invalidation, independent results and unchanged source boards. The full native dynamic sweep passed 224 size/level/time combinations. All 36 before/after reference captures are byte-identical in pixel values; see the sibling `pond-after-native/pixel-comparison.json`. Formal Web performance is measured separately.
