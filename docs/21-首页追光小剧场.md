# 首页追光小剧场

首页原先把正面立绘整体上下移动，与背景石台缺少联系。现在复用已经精修的角色素材，让露薇和小苔灵在前景石台上追随一粒微光。

- 24 秒循环：观察微光 → 迈步靠近 → 半蹲 → 蹲下观察、闭眼微笑 → 半蹲起身 → 右侧面、右前侧、正面、左前侧、左侧面依次转身 → 走回 → 稍作停留。折返时正面停留 350 毫秒，转身完成后再迈步。
- 根据用户授权，以原始角色图为身份参考，用内置 imagegen 补绘 8 张完整侧身步态和 1 张配套站姿。整张角色帧直接播放，取消分割腿部、旋转鞋片和光流混合；步态按移动距离推进，每帧支撑鞋底注册到相同地面线。
- 人物沿石台斜向移动时略微缩小，配合接触阴影、微光拖尾和石面反光。小苔灵稍晚跟上，停留时露出笑眼。
- 补绘保留红色蘑菇帽、叶披肩、米白裙和棕色短靴；首页行走、站姿、半蹲、蹲姿及转身均使用配套补绘素材。生成图与原画并非像素级一致，未覆盖原始角色图或关卡素材。
- 依据 `material/fx.png`，用内置 imagegen 重绘金色飞虫与圆形孢子，素材为 `assets/images/menu-fx-redrawn/`。直接保留生成 PNG 的透明翼膜和渐隐光晕，已删除旧的颜色抠底代码。四只飞虫分布在远近景，关闭粒子时隐藏飞虫。
- 首页根画面铺满视口。横屏背景与人物共用 cover 缩放并对齐底边，菜单独立按安全区域缩放；超宽屏不再留边。竖屏保留全屏景色底图，上方石台与角色一起裁切，菜单区域叠加半透明暖纸色遮罩保障文字可读，较矮屏幕可滚动。
- 打开设置、页面隐藏时暂停；离开首页时释放动画与监听；游戏或系统的“减少动态”设置使整个小场景静止。粒子、动态光照和画质设置分别生效。

实现：`src/app/scenes/MenuVignette.ts`、`menuVignetteMotion.ts`、`src/styles/menu-vignette.css`。

首页现在使用 `assets/images/menu-walk-redrawn/`。`scripts/import_menu_redraw.py` 只做透明图集切片、统一缩放与位置注册，保留生成图本身的 alpha；旧 `menu-walk/` 与裁片脚本不再用于首页。深浅背景检查图和循环预览见 `docs/qa-menu-vignette/redrawn-*`。

蹲姿和转身以 `scripts/import_menu_poses.py` 打包（在行走导入后运行），六种姿势统一物理比例和鞋底支点，避免蹲下后人物反而放大。新姿势图与转身预览：`crouch-turn-poses.jpg`、`turn-through-front.gif`。自动检查明确验证半蹲进出和经过正面的五阶段转身顺序。

验证：TypeScript 检查、Vite 生产构建、现有 140 项测试通过。`scripts/check-menu-vignette.mjs` 验证路径连续、全部步态帧、朝向、暂停恢复、系统减少动态、手机布局及首页切换清理；浏览器无脚本错误或失败资源请求。报告和截图位于 `docs/qa-menu-vignette/`。
