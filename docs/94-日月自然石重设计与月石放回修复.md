# 日月自然石重设计与月石放回修复

2026-11-14，用户指出3-2月石拿起后无法放回，并否决93号在晶石上附加日月徽章的造型。本轮按原玩法修复放置，同时重新制作两块自然石；旧报告通过不代表用户认可美术。

## 原因与修复

原规则允许在合法地面放回月石，并不存在“拿起后只能一直携带”的锁定。截图只能证明当次被安全站位检查拒绝；进一步实机复现发现：放置规划把所有旧底座也当成新放置需要避让的原因，远在左岛、合法贴着日石的伙伴会阻止右岛月石落地。另一个问题是普通移动的到达容差比窄站位余量大，身体提前停止后再次准备仍认为没站稳。

现在只有新增底座占地触发让位；旧障碍仍用于安全选点和路径检查。需要让位时角色真实走开，放置接近采用1毫米到达精度，并在实际到达后重新判断。保留原放置目标、任意合法地面摆放、碰撞边界和道路占用保护；取消仍保持携带，撤销仍恢复拿放状态。主角贴旧灯但伙伴占新底座的组合也单独验证。

## 石头造型

新增两张透明手绘自然石PNG：日石为蜂蜜金石材与放射矿脉；月石为银蓝石材与自然月牙凹纹。移除PostEmblem及边框，不再叠贴日月badge。地面和携带缩略图使用同一资源，当前模式对应石材保持原色，另一块略暗。

PNG原图1165×1350完整保留；运行时使用缓存AtlasTexture去透明边，保持宽高比，启用mipmap。脚锚按有效alpha测量，不靠抬高模型遮掩位置。日石可见宽高约0.53305×0.84302米，月石0.54622×0.84302米，包含在原0.72731×0.84302米展示包络内；这是用户授权重设计造成的局部轮廓变窄，不是全关统一缩小。原硬底座半宽0.25714米、日槽北移0.20米、角色及其他道具比例保留。携带图按原叶包缩略图包络等比容纳。

原图来源、SHA、alpha8/128边界、脚像素与pixel_size见[素材清单](../godot/assets/images/shadow-stones/manifest.json)。槽、切换器、留影和实际影路沿用93号状态表达。
