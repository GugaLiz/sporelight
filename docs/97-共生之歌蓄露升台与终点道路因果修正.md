# 共生之歌：蓄露、升台与终点道路因果修正

2026-11-15，用户标注3-3的①分水轮、②蓄露根碗、③升降台，指出②放入清露、③升起后，最终道路仍受①朝向限制，不符合预期。本次明确修订这一后期门槛，保留前期引根、四节逐格搭路、升台取露、下降送回和双人抵达照料。

## 原因及边界

旧规则在道路生成与`ready()`两处都要求`root && water==1 && lift高位`。这与旧TS及旧57号契约一致，属于历史设计条件，并非本次移植新增的错误。但交露反馈已经表示根系能够蓄水、自给，玩家升到高位却仍须回头将分水轮转到90°，阶段结果与最终道路的依赖不够一致。

现在以同一个`GardenWorld.symbiosis_final_route_open()`判断终路与照料的机关条件：**根系已蓄露稳定，且花台处于高位**。水轮的朝向不再额外关闭这条高处归途。

| 状态 | 终点道路 | 仍需遵守 |
| --- | --- | --- |
| 未交露，即使台已升高 | 不生成 | 先取露并送回，单纯根路连通不等于稳定 |
| 已交露，台在低位 | 不生成 | 原供水朝向0/1才有上升动力 |
| 已交露，台在高位 | 四种水向均生成同一终路 | 实际沿路抵达、双人会合并主动照料 |
| 高位下降 | 缺口道路收起 | 原人物/物品支撑保护仍阻止危险下降 |

水轮自身是低层L形旋转庭院，仍会改变西/北/东/南的实际出口，仍托着乘员转动。本次没有让水轮失效，也没有将“高位道路独立于水向”扩大为“任何水向都可以升台”。

另外发现原终路末端重复将已有固定南岸`f:0:3`登记为shadow薄板。本次只生成五块真正缺口，保留该岸原厚度、ID、高度与完整台面；不补新捷径、不改花坛尺寸。

## 路线与兼容

新路线保留旧参考0–38步至交露完成，将随后绕回水轮再转90°的一段替换为沿已建根路返回花台的实际行走，然后升台走归途。新增测试保留旧fixture不重录；旧的转轮路线也应继续合法。

旧档不需要清空或迁移布局：未交露/低台状态不变；已交露且高台但水向不是1的存档新增合法终路，不移除既有支撑；已完成档保留。领域状态、实际身体落点与渲染高度分别检查，尤其水向2/3时低层庭院与高处终路出现上下重叠，不能只按XZ坐标合并。

默认目标与主动分级帮助同步新规则，不新增场景文字牌。`godot/content/levels.json`只更新3-3文案；旧TS来源及fixture保留为历史。`export-reference.mjs`是从旧站重生成参考数据的工具，不是当前正式打包入口，直接运行会覆盖原生修订，不能用它代替本轮验证。
