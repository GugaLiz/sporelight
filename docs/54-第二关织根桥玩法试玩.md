# 1-2「织一座根桥」玩法试玩

2026-11-08。用户在确认原版为“四节根芽绕中央岩石”后，进一步授权制作更清楚的新玩法版本。本次是独立可玩原型，保留原图片素材，以规划与执行分阶段改善空间理解。

## 试玩入口

`http://localhost:4218/?playtest=root-weaving`

独立构建 `root-weaving-playtest`，原 4216 / 4217 构建不覆盖。进入即创建 1-2 的内存会话，使用内存存档适配器，不读取或写入玩家磁盘旅程。刷新会重新开始。桌面也可以使用 `--root-weaving` 启动同一原型。

## 一轮玩法

1. 走到根台旁，点击原操作栏中的“规划根桥”或按 E。
2. 点击地图上的可用落点，依次规划四节根桥。已选格显示编号与连接线，真实世界仍保持断开。
3. 点原操作栏的“撤销”、按 Z / Backspace，或者点已选编号退回；空草稿再撤销可退出规划，不消耗芽节。
4. 四节恰好连到对岸后，“让根桥生长”才可确认。按 E 或点击原主操作按钮，根桥逐节生成。Enter 优先操作当前聚焦的按钮；无按钮焦点时可确认路线。
5. 用地图点击、WASD / 方向键前往花坛，再使用原上下文操作完成照料。
6. 从原暂停菜单重新开始可尝试另一侧路线。暂停、地图返回保留当前草稿与生长进度；手机竖屏显示横屏提示。

这版保持四节预算、连续合法邻接、中央岩石阻挡和上下两条解法，改变操作组织：从边操作边生成改为先规划、后执行。没有增加新的收集门槛，也不把一条推荐答案预先填好。

## 画面与边界

- 镜头固定全景，两岸和终点始终同时出现。
- 中央石块使用原图，移除满格石板底座，缩小并下沉，使缺口与上、下绕行区域可辨。
- 规划格使用半透明颜色、编号和连接线；只有确认后的真实根桥拥有可走支撑。
- 使用原 `GardenHUD` 的任务栏、撤销/主操作/提示栏、暂停、地图、设置、主界面与结算；不提供另一套样式或按钮体系。观察、休息与微光标记恢复原表现。
- 公共规划模型 `application/root_route_plan.gd` 通过领域模型的独立副本验证每一步，也支持实际撤销后从剩余芽节继续规划。
- 原型控制器继承常规应用，只扩展草稿与生长队列；行走、事务、菜单生命周期、提示容器直接复用。常规应用提供存档和舞台两个构造入口，默认实现不变。
- 提示仍在底部按钮上方居中显示：点提示打开、点内容切换、再点提示关闭。只有提示文字适配规划玩法。

## 恢复现有界面（2026-11-08）

首轮试玩误将玩法调整扩大为整套 HUD 重做。按用户反馈移除了自建页头、页脚、退一步/取消/暂停按钮及竖屏遮罩，改为复用正式界面与既有横屏阻断。保留四节根桥规划和中央岩柱，不再改变通用交互视觉。地图可以真实切换关卡，其他关卡沿用普通规则与表现；本试玩中的进度仅存内存。

新增 `native_root_weaving_hud_test` 验证草稿撤销、提示切换、暂停与地图往返、主页继续、未提交生长恢复、部分根桥重新规划、重开和跨关卡隔离。浏览器检查改为操作原界面，覆盖鼠标、键盘焦点、触屏点选及菜单滚动，不依赖被删除的自建按钮。

浏览器手机尺寸检查使用 Chrome 触屏模拟，设置长列表通过滚轮显露控件后再触摸按钮；不据此声称已验证真机手指拖动滚动条或真机音频。

## 中央障碍的体积修正

用户指出缩小后的石头仍像悬在缺口里的贴图。现将其改为独立岩柱：保留原石头图，下面补充不规则、向下收窄的真实岩体，顶部使用原苔藓纹理，并补少量垂藤。岩体占地严格收在中央阻挡格内，两侧保留空隙，不铺普通地砖、不添加落脚碰撞，因此不会形成跨越缺口的捷径。只更新 4218 试玩版。

## 将无目标的后排阶梯改为花境

后排两格原本是可走的高台，但没有机关、收集物或任务目标；六级横贯平台的阶梯反而暗示了一条不存在的主线。4218 试玩现采用独立后庭表现配置，将后排降到花坛所在的平面，保留通往花坛的入口短阶。网格、碰撞采样、人物落脚基准与步态高度使用同一配置，不只隐藏阶梯贴图。

后沿布置两组不对称的低矮苔地：一侧为原有浆果灌木、苔石和蓝粉小花，另一侧为原有石灯、蕨叶和淡黄花丛，中间留出空隙。装饰收在后沿，不占格心通道，不新增任务、灯光或碰撞体。正式关卡定义、四节预算、根桥两条解法、目标花坛和界面不变；其他关卡仍使用原表现配置。

新增后庭平面与碰撞高度一致性检查，并在两种浏览器尺寸的完整上侧解法中实际走到后排两格、返回花坛完成照料。场景继续复用原素材，没有引入新位图资源。

本轮针对规划与试玩集成执行 70 项无头检查（40 + 30），全部通过。后庭不在根桥方向提供额外入口台阶，避免将不可跨越的关卡边界表现为捷径。
