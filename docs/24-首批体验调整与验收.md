# 首批体验调整与验收

> 已撤回：用户于 2026-11-04 要求还原，本轮界面、镜头、输入与 1-1 教学改动已全部撤回；代码及本地 4174 预览恢复到调整前版本。本文件和截图仅保留为历史记录，下文的实施效果、188 项测试及复测命令不代表当前版本；当前版本恢复为原有 140 项测试。

日期：2026-11-04。范围：主线公共视觉/输入、1-1 教学、小屏至大屏适配。

## 已实施的变化

- 公共 HUD 改为紧凑标题和当前目标，详细步骤/收藏放入可展开区域。附近动作保持可发现，次要操作收进“更多”。
- 键盘/鼠标模式收起虚拟方向盘；触控可恢复至少 44px 的方向按钮。手机步骤入口也保留 44px 目标。
- 主角和伙伴适当缩小，减少遮住脚下格子的情况；背景弱化，镜头按实际 HUD 占位求可用区域。小地图保持稳定取景，大地图在紧凑窗口跟随人物。
- 短横屏使用独立紧凑布局，覆盖 568×320。反馈消息放在动作卡的独立行，避免盖住操作按钮；H、错误和成功反馈保留。
- 方向键/WASD 支持按住连续走，松开不继续重复；动画中快速点按的新方向可以在下一安全格执行。新目的地替换旧路线，每格重新验证。
- 动作缓冲只保留一个明确意图。E 绑定按下时的可用动作，缺少可用动作时显示反馈；执行前仍由规则检查，防止走近后误触另一个机关。
- 暂停、失焦和页面隐藏清理保持方向与旧意图。通关后“留下看看”把焦点交回可见按钮。

1-1 现在按“先移动靠近根台 → 向花床生长一节根芽 → 走到花床 → 明确播种”的顺序教学。三枚收藏位于主路线；回收支路不再是新手取得收藏的必要步骤。指引随真实状态变化，缺口尚未长出时也能在正确槽位显示轮廓与箭头。

## 公共模块与边界

| 模块 | 职责 |
| --- | --- |
| `garden2/input.ts` | 保持方向、单槽输入意图与释放/重置；不改变世界规则。 |
| `garden2/layout.ts` | 可用视口与相机变换纯计算，供主线复用。 |
| `garden2/firstLessonGuide.ts` | 1-1 的状态引导，供规则提示、目标和地图标记同源读取。 |
| `garden2/scene.ts`、`garden-experience.css` | 主线共享 HUD 与响应式布局。 |

公共变化覆盖主线 12 关。其他 11 关的地图、谜题与完成规则保持原有设计，并参与通关回归。云庭微光仍使用其独立链路，本轮未调整。完整命令类型迁移、全部机关模块化和引擎替换未纳入本批。

## 复测命令

已安装项目依赖和 Playwright 的环境，可通过环境变量选择服务和独立输出目录，不需要修改测试脚本里的端口：

```powershell
$env:QA_BASE_URL = 'http://127.0.0.1:4174/'
$env:QA_GARDEN_DIR = 'docs/qa-experience-20261104/layout'
node scripts/check-garden-experience.mjs

$env:QA_GARDEN_DIR = 'docs/qa-experience-20261104/journey'
node scripts/check-garden2.mjs

$env:QA_GARDEN_DIR = 'docs/qa-experience-20261104/interaction'
node scripts/check-garden-journey-ui.mjs
```

如使用独立安装的 Playwright，可把其模块路径作为脚本的第一个参数。本地测试使用独立浏览器上下文，不读取日常浏览器的存档。
