# 2-2 镜叶地图引导

2026-11-03，针对反光叶搬运与放置只有文字、目标不明确的问题，增加直接呈现在地图上的引导。

- 当前需要操作的镜叶或花床始终有柔和光圈和下指箭头；减少动态模式保留静态标记。
- 两片镜叶标记为①、②，目标槽改名为「② 镜叶光槽」，增加发光叶形轮廓。中央阻挡石改用低矮苔石素材，保留原有阻挡关系，让后方光槽可见。
- 搬起镜叶后显示预期光路和方向箭头；点击底部「提示」也会显示20秒光路预览，手机自动切到全景。
- 地图附近的按钮按实际机关状态依次提示搬起、放置、转动①、转动②、前往花床。远处点击先走近，走近后点击才执行操作；底部E操作同步优先显示当前步骤。
- 引导读取实际镜叶位置、携带者和角度，撤销或读档后即时更新，无新增存档字段。原光线计算、道路开启条件和通关条件保持原样。
