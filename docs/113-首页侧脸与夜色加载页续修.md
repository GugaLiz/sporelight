# 首页侧脸与夜色加载页续修

2026-11-18，`dev`。用户新反馈：首页严格侧脸不自然；loading点阵太整齐，希望增加漂浮光点、若隐若现的夜间建筑和中心动效。延续GQ-025/028；112号共享角色接入不代表本次侧脸已被用户认可。

## 修改

- 首页站立侧向与行走改用参考现行正面/播种形象重绘的四分之三侧面，保留双眼、柔和鼻颏、红菇帽/棕发/橄榄披肩/象牙裙/棕靴身份。新稿只覆盖封面槽，游戏内共享侧面动作不变。正面与蹲姿仍复用共享角色。
- 新稿3×3，首格侧站、其余8格步态；完整姿态统一等比1.1612903225806452，按帽中心与靴底平移配准至512画布、脚锚[256,472]。保留软alpha，不拼接身体、不逐帧缩放。原24秒路径、60px步幅周期与单人物切换保留。
- loading删除铺满背景的规则圆点纹理，增加为64个位置/大小/速度/负延迟/方向各异的浮动光点。新增低对比月夜遗迹背景，中央留空、两侧苔藓拱门与远塔隐于雾中；竖屏取景保留左侧遗迹。
- 人物、岛体、花草、灯全部置于同一浮动容器，7秒轻缓起伏与小角度摆动；灯与微光4.8秒呼吸，避免角色脚底与岛面分离。错误态停止岛体起伏；减少动态媒体规则覆盖新增动效。未实际切换系统减少动态设置。

原始生成稿保留于`assets/images/home-loading-refine-20261118/masters/`；配准、各帧SHA与输出见`registration.json`，处理入口为`tools/godot-migration/prepare-home-loading-art.mjs`。夜景以现有背景作视觉参考新生成，再由loader同步脚本输出WebP。本轮不修改玩法、存档、岛体碰撞或关卡镜头。
