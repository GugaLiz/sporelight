# 素材制作与交付规格

2026-10-19 / v1.0

## 当前可执行方案

复用项目已有透明PNG进行裁剪、对齐、缩放、导出图集和背景调色。原始图保留，新增产物在`assets/images/production/`。这属于已有素材加工，不属于全新AI绘图。内置image_gen在本会话不可用；未调用付费API或CLI。

## 美术规范

统一柔和三维插画、低多边形微缩遗迹、奶油光与莫兰迪色；主角沿用已有蘑菇帽少女，红色菌盖为焦点。植物与角色使用真alpha透明PNG，禁止棋盘格烘焙。物件画布256×256，内容底部中心为锚点(0.5,0.9)，周围至少8px留白；最终绘制维持宽高比。背景1280×720，不含文字、UI、角色或游戏操作节点。图中文字全部由HTML提供。

| 分组 | 内容与状态 | 交付 |
| --- | --- | --- |
| 角色 | idle×3、roll×3、sow×3、bow | 对齐PNG与横向/网格图集 |
| 世界 | 土地空/播种、花苞/盛开、苔藓暗/亮、藤蔓种子/桥、睡莲闭/开、水洼、遗迹 | 独立透明PNG |
| 反馈 | 孢子、光虫、生长环 | 独立透明PNG，动态由程序组合 |
| 场景 | 山谷、池塘、洞穴 | 现有无UI背景调色变体；独立章节美术待补 |
| UI | 按钮、弹窗、HUD、数值 | HTML/CSS与真实文字，沿用已有小图标 |
| 缺口 | 鼹鼠、蝴蝶、独立水晶花、完整过场 | 后续AI或美术制作 |
