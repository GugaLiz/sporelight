# 首页伸手托住微光动作恢复

2026-11-18，`dev`。用户指出首页蹲下后应伸手托住微光，当前只是抖动。此反馈延续GQ-025，113号侧脸通过不覆盖蹲姿动作语义。

## 原因与修复

112号统一角色时，将`crouch-lower`、`crouch`、`crouch-happy`全部指向共享`interact`，开心阶段仅旋转整体Sprite，原先托手姿态丢失；微光仍沿独立路线悬在人物面前。旧`menu-walk-redrawn/crouch-happy.png`确有双手向上托举，与新反馈相符。

以内置imagegen参考当前共享蹲姿与已接入的四分之三站姿，新增六张完整动作：手靠膝、半伸、张掌、抬手、托光微笑、闭眼微笑。使用原生透明alpha、单一0.94等比尺度，帽中心/靴底配准至512画布与[256,472]脚锚；不切割身体，不叠化两个角色，不改变世界角色素材。原稿、提示词及帧SHA/手锚见[生成记录](../assets/images/cover-palm-20261118/generation.json)与[配准](../assets/images/cover-palm-20261118/registration.json)，运行图位于`godot/assets/images/cover-palm-20261118/`。

首页保留24秒与原行走路径：先蹲下，再伸手接光，8500–11350ms保持掌心托举，随后微光飞离、手收回、起身返回。去除整体开心旋转与蹲姿呼吸缩放；微光绑定每帧真实手锚与人物同一镜像/缩放/脚锚变换，掌上微光稍缩小，中心在掌面上方6个首页逻辑像素。进入/释放混合至原飞行路径，避免释放跳点。减少动态仍回到共享正面并停止处理。
