# 共生之歌：自然机关与元素比例调整

2026-11-14，用户要求3-3元素大小协调、像3-2一样使用自然元素表达，而不是靠场景文字。依据57号原玩法契约，改动局限于3-3美术、局部硬底座匹配和状态呈现。

## 发现的问题

修改前真实GPU普通视图确认：分水轮只有0.34米外径、中心写“转”，升降轮用“↕”区分，轮与石灯/主角相比显得细小；初态清露约0.99米宽，比控制器突出很多。根芽盆旁又叠了一座小花坛，容易把交露稳定根系误看成另一个种花任务。原根装饰格为f:0:-4，实际生长与交露仍在f:1:-4。

没有发现需要修改通关逻辑的证据。根路四节连接、取露、下降送回、交露稳定、转庭重新分水、升台到终点仍保持原59步流程；原菜单动作和主动提示保留。

## 最终修改

- 分水庭使用木质轮辐、青铜轴和苔石根脚的新手绘道具，移除“转”字。
- 水力花台使用竖向水管、叶形把手和铜槽浮子，与圆手轮形成明显不同轮廓；移除“↕”字。浮子随真实平台低/高状态及运动进度移动，不提前显示目标高度。
- 根芽和交露点共用一只自然根碗，保留两处原交互锚及真正根尖。交露前为空碗，原root标志成立后才显示蓄水与新芽；不把连通根路当作已经稳定。
- 初态清露仅在3-3缩至原比例72%，取下后的叶包及角色携带比例保持。核心花床、角色、其他关已确认比例保留。
- 新机关底座仍是原半径0.19米的实体阻挡，压为0.025米低矮承托，避免在原画石脚下叠出粗绿圆柱。根碗硬占地为0.60×0.60米；源图接地根颈中心(794,740)与末端根须脚(794,887.5)分开，按30度相机地面反投影中心，相对旧脚锚两轴各后移约0.138米。细根须不整体变成硬墙。
