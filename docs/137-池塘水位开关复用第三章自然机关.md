# 137 — 池塘水位开关复用第三章自然机关

2026-11-20，用户反馈2-1水位开关的圆环/直杆造型粗糙，希望参考第三章同类操作复用。

## 修改

- 选择3-3升降控制器：苔石底座、铜质叶片手柄、玻璃水柱；2-1同属控制平台高度的机关，比旋转庭院木轮更贴近操作含义。
- 复用公共 `symbiosis-lift` 资源、裁剪、脚锚和0.9m可见高度，未生成或复制新图片。普通深度、原交互格 `m:float:0:0`、开关偏移 `(0.28,0,0)` 保持。
- 提取共同的素材内指示点定位函数，3-3继续使用原两档定位；2-1将低/中/高映射到下/中/上三个停点，升降过程沿同一铜轨连续移动。撤销/重进读取真实水位。
- 薄石座沿用3-3的0.025m接地层；原开关硬底半径0.19m、物理阻挡矩形及0.41m阻挡高度不变。人物、物品、关卡规则、存档和道路数据未改。

实现：[mechanism_props.gd](../godot/presentation/native/mechanism_props.gd)、[symbiosis_dressing.gd](../godot/presentation/native/symbiosis_dressing.gd)。既有素材定义仍在 `prop-elements.json/natural_assets/symbiosis/lift`，无需新增资源别名或改变目录身份。
