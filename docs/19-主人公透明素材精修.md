# 主人公透明素材精修

2026-11-03。按用户选择，采用原图程序精修，保留已有角色造型与动作。生成式试稿因边缘和造型不稳定未接入游戏。

## 处理内容

原 `char.png`、`role.png` 的棋盘格属于图片像素，原流程采用宽泛的浅灰颜色阈值，会误删接触轮廓的白色帽斑、裙边，并把底色带入缩放后的边缘。

新流程在源图分辨率建立前景/背景约束，通过 GrabCut 分离轮廓，仅在窄边缘重建半透明像素和前景颜色。保留内部白色细节，去掉脚边的烘焙阴影。旋转、变形采用预乘透明度插值，避免透明像素的 RGB 混入边缘。

跳跃拼接的旧颜色判断会把暖色手臂误判成红帽，现已限制为旧帽和面部区域。共生图将外围金色发光单独转换成柔和透明效果，保护中心人物，减少棋盘格和整块白色底。

新素材位于 `assets/images/character-refined/`，共 52 张：10 张基础姿态、12 张正向行走、12 张背向行走、12 张跳跃、5 张播种和 1 张头像。普通帧仍为 256×256、脚底锚点仍为 `(0.5, 236/256)`，沿用原动作时序和步幅；源图、旧素材目录均保留。

游戏渲染、角色预载、工具栏头像/跳跃图标、启动页、命名页、菜单和地图角色已切换新素材。Canvas 开启高质量图像平滑。

## 重新生成

需要 Python 3、Pillow、NumPy、OpenCV。脚本也会寻找项目 `.cache/art-tools` 中的 OpenCV。

```powershell
python scripts/prepare_material_assets.py --characters-only --output assets/images/character-refined
python scripts/check_character_assets.py
$env:QA_GARDEN_DIR='docs/qa-character/in-game'
node scripts/check-garden2-walking.mjs
```

浏览器检查需要开发服务器、Playwright 与 Chrome；可将本机 Playwright 模块路径作为第一个参数。素材预览位于开发服务器 `/images/character-refined/index.html`，动作预览为该目录中的 `motion-preview.gif`。
