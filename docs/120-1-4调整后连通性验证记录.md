## 二、问题详情

### 🔴 连通性：露薇在中间通道走不到左平台

**现象**
露薇在中间通道（约 f:3:3 附近）时，无论按方向键（上/左）还是点击左平台目标格，角色**原地不动**，提示"**这边还没有可走的连接**"。左平台（含 home f:-4:0 / 鼹鼠 / rest）与中间通道之间**没有可走通路**。

**复现**
1. 完成"固定门闩 + 收门铃 + 放置门铃"（旅程 1/4）。
2. 控制露薇，从中间通道尝试走向左平台（鼹鼠 / home）。
3. 角色走不过去，提示"这边还没有可走的连接"。
4. 切全景确认：左平台是**孤岛**，与中/下平台无连接。

**代码分析（`godot/core/garden_world.gd:542-545`）**
```gdscript
"1-4":
    if flag("latch") or lever_held():
        _line(base, [-2, 0], [2, 0])   # 固定门闩后打开 x=-2..2, z=0 横线（连接左平台↔中平台）
    if flag("latch") or state.actors.buddy == cell(3, 5):
        _line(base, [-3, 1], [-3, 4])   # 固定门闩后打开 x=-3, z=1..4 竖线（连接左平台↔左下平台）
```
设计意图：固定门闩后应打开 `x=-2..2, z=0` 横线，让露薇从中间通道 (3,3) 走到 (3,0) 再过桥到左平台。

**疑似根因（需开发确认）**
1. **`flag("latch")` 可能未真正生效**（界面显示"固定归途 ✓"，但内部 flag 未置位）。
2. **`_line` 打开的横线与角色所在 z 不匹配**：`_line(base, [-2,0],[2,0])` 只打开 `z=0` 一行；若角色在 `z=2/3`，需要先走到 `z=0` 才能过桥，但**中间通道到 z=0 的路径也可能断开**。
3. 角色所在位置与桥接格之间缺少过渡格。

**建议修复**
1. 确认 `flag("latch")` 在"固定归途"操作后**确实置位**。
2. 检查 `_line` 打开的横线**是否与角色的行进路径连续**（尤其 `z=1→z=0` 的过渡）。
3. 在断连处给出**方向性提示**（如"需要先走到上方通道再向左"）。

**验收标准**
- [ ] 固定门闩后，露薇能从中间通道走到左平台（home / 鼹鼠）。
- [ ] 可完成"归还门铃 → 两位到花床 → 种微光"，1-4 通关。
