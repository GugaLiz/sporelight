# 首关解谜逻辑优先的回退与调整

日期：2026-11-05。

> 已撤回：用户确认本批把原E/主按钮的种芽开路入口改成仅提示，破坏了其要求保留的玩法交互。本批应用文案、主操作与脚轨改动已全部回退到`9ae1da5`，新增代码和测试归档在本地忽略的`godot/build/rejected-puzzle-controls-20261105/`。以下仅保留为被撤回方案及测试历史，不代表当前版本。此前测试把“E不种芽”当作正确预期，不能用这些通过结果证明玩法保真。

## 反馈与回退

用户指出：上轮只按视觉净空优化，没有理解路线设置的目的，解谜游戏不应把所有元素都摊到明面。原方案虽保持规则快照，却改变了空间遮掩与信息发现顺序；“规则没变”不足以证明体验保真。

已将上轮四个跟踪源码/工具文件恢复到`9ae1da5`，移出新增的编排、脚轨及其测试，恢复花床110宽、装饰原位、原标签条件和原地形。被否定源码保存在本地忽略目录`godot/build/rejected-visual-20261105/`，历史报告保留并标明撤回，审计记录不删除。4185先恢复基线包，然后才开始本轮实施。

## 当前谜题的代码事实

当前主线是Garden2规则，不能继续采用旧“线性移动教学”的资料作为首关事实。

- 根台在`f:0:0`，预算只有一节根芽。东、南两个方向都合法。
- 南侧低岛有可选孢子与观察点。玩家可以先探索，再回根台回收根芽，重新向东接路；参考解法恰好覆盖这一过程。
- 东向连接先到右岛h1前排；花床在`f:3:0/h1`，后排为h2，不能把画面修成从根桥直接跨到后排。
- 全收集不是通关门槛。直接东行与南探后改道都是有效玩法；必须靠近花床、让伙伴到位并主动播种。
- 首关没有规则迷雾。需要保留的是原构图遮掩与探索空间，本轮不添加新的迷雾、发现锁或隐藏奖励。

证据：`godot/content/levels.json`、`godot/core/garden_world.gd`、`tests/garden2Solutions.ts`及未修改的`godot/tests/fixtures/reference.json`。

## 重新调整的边界

| 原因 | 调整 | 必须保留 |
| --- | --- | --- |
| 常驻任务直接调用完整提示，说出向右引芽 | 首关常驻任务只描述当前状态，不主动给出方向或返程/回收/改道步骤；明确方向解法留给主动提示 | 核心hint契约、原文档/fixture、玩家主动求助能力 |
| E默认执行第一个可用命令，替玩家选东向 | 多个合法生长方向时要求明确选择，数字/地图＋仍可选择；单项操作仍可E | 南侧探索的价值、根芽预算与回收规则 |
| 点击不可达目标自动拼接完整hint | 首关只说明未接通/高度限制，不自动吐出解法 | 不可达仍不可走，提示按钮仍可用 |
| 脚底线性高度与原四级阶面不符 | 仅当前已接受的合法楼梯连接采用对应脚轨；行进时平滑收拢同格队形 | 原阶梯`.1… .9`几何与地形绘制顺序、花床/装饰/标签/岛屿/相机、未到达区域的遮掩 |

不采用全局透明地形、角色永远置顶、常亮完整路线、挪动收藏/花床、增加根芽预算或永久便道。

局部承托面拆片与排序曾在本轮尝试，但代码审查发现整面换层在`p=0→ε`不连续、阶片也可能被随后绘制的完整侧墙吞掉，因此已全部撤下。`garden_landscape.gd`恢复与`9ae1da5`相同。原完整高台与楼梯重叠的几何/排序限制仍存在；本轮不将脚轨修正包装成“全部穿模已解决”。如后续修复该结构，需先明确原路线、楼梯入口/内壁结构，再单独验证，不能靠排序让人物全露出来。

## 验收方式

除画面采样，还必须验证选择权与规则状态：

1. 开局E不能替玩家选方向；两个方向都能由玩家明确选择。
2. 南探收集后可返回、回收、改东并完成；直接东行零收集也可完成。
3. 桥上回收不能收走人物脚下道路，未连接的缺口不能靠走动/跳跃越过。
4. 撤销与读档保留所选方向、资源、收藏和伙伴状态。
5. 常驻文案和不可达反馈不提前提供方向答案；主动H仍可获得原提示。
6. 静止场景保持基线构图；楼梯动态采样检查脚底、伙伴、携带物与前景遮挡，不以“人全露出来”作为通过标准。

## 仍需处理的体验问题

原高台与楼梯的重叠及整体遮挡排序没有在本批修复。当前脚轨只减少脚底与原阶面不吻合，场景遮掩完全保留，不能宣称“人物不再被所有台阶/平台遮挡”。后续应先为原路线定义真实楼梯入口、承托面与内壁结构，再对这一局部结构单独实施；正常空间遮挡与错误穿体必须分别判断。
