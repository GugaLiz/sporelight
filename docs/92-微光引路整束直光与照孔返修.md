# 微光引路整束直光与照孔返修

2026-11-14，用户连续反馈3-1光柱无反射物却出现折角。本次反馈覆盖[91号](91-微光引路光学机关可读性与原玩法验证.md)的光源连接结论；归入GQ-014，不改原解谜。

## 原因与修复

上一轮仅将首段起点接到实际携带/落地灯，其余段仍沿逻辑格中心延伸。真实叶包与格心有偏移，于是首个接缝形成折角。旧测试只验证起点贴灯，漏掉整束共线；上一轮通关通过不能证明光学表现正确。

`lightwell_dressing.gd`现缓存本关全部灯光段。起点使用真实灯源；规则命中接收叶时以叶心定轴，否则以原裁切终点定轴。所有分段在同一条直线上，与原端点沿规则方向的横截平面求交，闭窗终点仍落在窗平面。保留原分段索引、显隐和节点复用，不每帧重建网格。灯的四向操作、接收判定、探索、道路、遮挡规则和存档均未改动。

真实携带点、接收叶、窗中心不共线，不能同时要求它们精确过心。直光精确穿过接收叶，并在窗有效开口内通过或停止。柔叶照孔为容纳持灯、落地与同格偏移，中心局部改为`(0.10,0.32,-0.29)`，内孔半轴`0.28/0.24`、外轮廓`0.36/0.32`，软茎随孔口连接；没有新增碰撞、支撑或放置条件。

## 防复发与证据

- 无反射/折射介质的连续光束必须整束共线，不能用首段斜接格心掩盖灯源错位。
- 同时检查实际灯源、接收面、遮挡面、所有段接缝和孔口净空；检查不能只比较逻辑点或节点存在。
- 覆盖双方持灯、四向、落地/拾取、同格偏移、窗开闭；原流程与用户截图对应状态分别看GPU原图。
