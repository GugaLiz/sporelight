# 图鉴分类与阅读位置规则

2026-11-07。Web入口：http://localhost:4185/。

用户截图中图鉴标题不见、分类栏顶在裁剪边缘，来自旧版整个页面都在ScrollContainer中且自动聚焦首个交互控件。Godot的follow_focus会滚动以显示该控件，初始阅读位置因此不是页面顶部。分类按钮重建图鉴时没有显式的阅读位置规则，返回故事详情又仅立即写滚动值，容易与容器布局先后竞争。

本次规则：

1. 首次进入图鉴、切换到另一个分类，内容从顶部开始。
2. 点击当前已选分类不重建界面，保留当前阅读位置。
3. 从故事详情返回，恢复原分类和离开时的滚动位置。
4. 图鉴标题、分类栏、返回按钮固定，仅素材内容滚动；键盘默认焦点在当前分类，不再让正文中的“读故事”按钮决定初始位置。
5. 返回地图恢复地图原来的位置，不把地图与图鉴的滚动值混用。

地图与图鉴共用原生VBox/HFlow/Scroll固定菜单框架。分类Tab复用menu_button_styles.gd，统一44px点击高度、单选状态和无矩形焦点外框。滚动请求绑定当前页面与ScrollContainer，等容器布局完成后应用；页面替换后旧请求自动失效。

最终运行源：`d90aaebf1f72a9d7277cbc3a669ae6d71a909ba3f8d13f2f4ed621bcdec46889`，404文件。运行代码只修改garden_hud.gd、menu_button_styles.gd；关卡、素材、解锁、存档格式与移动规则不变。
