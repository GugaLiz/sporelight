# 关卡表现与伙伴画风二次细化

2026-10-29。重新对照「关于游戏/游戏关卡初步设计.md」与「关于游戏/游戏关卡细化设计.md」，延续已有12关的空间谜题，加强“收集—播种—生命回应—核心苏醒”的表现。

## 伙伴的材质与动作

小苔灵使用珊瑚红菌盖、奶油色菌柄、暖棕色小脚和苔叶，补充菌褶、斑点边缘、细小表面纹理、眼睛反光和柔软接触阴影。站立菌盖复用已有 `journey-gardens/buddy-ball.png` 的明暗与纹理，保持站立与滚动的材质联系；图片加载前使用渐变绘制的后备外观。普通行走不再突然变成球，滚动模式才使用蘑菇球；等待时略微坐低并抱叶，跟随跳跃有较小的起落。云庭样章共用新版绘制函数。

鼹鼠改为暖灰棕色绒毛、奶油色口鼻、小耳朵、亮鼻尖、细胡须和浅色爪尖，加入苔叶围领及苔土洞缘。与小苔灵采用相同的左上暖光、柔和边缘和落地阴影。鼹鼠作为有前后遮挡关系的场景角色绘制，打开花园门闩时随蝴蝶移到花园，完成后抬爪致意。它不承担额外碰撞或新的胜利条件。

## 动画、存档与设置

一般关卡到达终点后停留约1.4秒；终章停留约3.6秒。暂停会冻结这段时间。减少动态时缩短为0.25秒，并停用飞行收集、扩散光环与庆祝粒子，保留静态状态和现有操作便利。粒子与柔和光晕开关分别控制对应效果。

新反馈只读取已有局内状态；撤销恢复原有机关与角色位置，续玩不重放过去的收集特效。为避免新增通关停留期间刷新丢失本关进度，庆祝结束前保留最后一个尚未通关的稳定步骤，刷新后可直接重走最后一步；结算仍由原有完成回调统一记录。

本轮没有改动地图拓扑、孢子数量、关卡解法或存档格式。原稿的强制限时连跳、鼹鼠引诱谜题与多光源投影属于规则改造；此轮继续沿用现有节拍、伙伴协作和日月影桥规则。没有新增音乐或分层花瓣骨骼动画。
