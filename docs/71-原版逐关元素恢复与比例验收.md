## 3. 每关必须交付的清单与比例表

每个可辨认实例一行；同材质连续墙面可按面组登记，粒子按发射器/效果实例计数，不逐粒计数。固定装饰、规则物件、条件生成物与界面覆盖分开计数。素材相同但职责不同不能合并，生成/携带/开花不是新建多个逻辑物件的理由。

| 必填字段 | 内容与单位 |
| --- | --- |
| 身份与类别 | 关卡ID、实例ID、角色/装饰/拾取/机关/建筑/地表/水/天气/光效/UI、原素材与原实现定位 |
| 数量与存在条件 | 原版逻辑实例数、当前实例数、待补/多出数；各状态应出现数量、实际可见数量、被遮挡数量分列；未核实填“待盘点” |
| 对应位置 | 原支撑格/区域、当前支撑ID及物理位置、固定或随动父级；已变更地形的安全映射及理由 |
| 主体与效果 | PNG尺寸、主体alpha框/阈值、脚锚、独立光晕范围；网格记录有效包围盒；悬浮/悬挂/平放/落地语义 |
| 原版比例 | 原图主体像素宽高、邻接地块两轴投影长度、同深度主角主体高度；主体宽/局部格投影、主体高/主角高、基部沿两轴占地；不能混用世界单位和屏幕像素 |
| 当前与目标 | 相同方法测新图，记录当前比值、原版目标、差异与具体实现调整；未测量不填推定比例 |
| 状态与动效 | 初始、拾取/持有/放下、激活/完成、运动、撤销/读档；动画振幅/周期/方向/随动、暂停与减少动态行为 |
| 对照来源 | 原站URL、取证时间、资源版本/哈希或无法获得的说明；当前源码SHA与构建模式；截图路径、视口、DPR、普通/全景、镜头位置与状态 |
| 结论 | 缺失/比例偏差/锚点偏差/遮挡/行为差异/已对应；修改范围、独立复核者与待解决项 |

比例方法：原站与原生先使用相同视口、DPR、普通镜头和对应状态；因2D/3D投影不同，优先在各自画面中将同深度邻格两条轴和人物作局部参照，再比较归一化比例。全景图用于核对分布与数量，不能与普通图混算。软光晕不计入实体主体；被挡住的轮廓不能靠猜测补齐像素。测量噪声与原站动画范围要随表记录，不预设一个适用全物件的任意误差百分比。
