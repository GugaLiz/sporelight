# 第二关第二节镜叶朝向与反射光路优化及状态复核

2026-11-13。用户确认本次异常对象是**岩石左侧的①号镜叶 A**，不是左上石灯。按现行57号契约保留固定光源、A可转不可搬、B可搬及两次反射绕壁机制；用户反馈原图见[原图](qa-godot-native/pond-optics-20261113/user-feedback.png)。本轮修正模型朝向、镜面材质和光路过渡，不改关卡布局、角度存档含义或解法。

## 原因与修正

原模型使用 `PI/4 + angle*PI/2`，镜面真实法线与规则反射方向相差90°。这使用户截图中已经转过的①号镜叶接近侧对镜头，看起来只有一条竖杆。现统一使用 `MechanismProps.mirror_yaw()` 的 `-PI/4 + angle*PI/2`，并用实际 ReflectionFace 法线反射入射向量验证结果，期望方向表独立于此yaw函数。

固定A与可搬B保留原镜叶尺寸、四边框、52px叶片及叶包携带表达。2-2镜面改用冷色天空渐变和窄高光，避免原材质受环境染色后像哑光绿板。它是风格化玻璃，不是实时世界镜像；镜面仍真实随机关旋转，角度0从等角相机观察可能正常侧视，不用始终朝向相机的假镜面掩盖方向。共享3-4地面镜也使用正确yaw，已单独检查两角法线和高槽支撑；新玻璃与软光只应用于2-2。

转镜从原来的整面跳变改为落地镜体的连续90°旋转，复用stage的eased进度；拿放、携带和跨支撑移动分别处理。镜座仍留在真实支撑面，不把固定底座一同塞进叶包。

2-2光束采用0.035m亮芯、0.145m柔晕和渐隐端部。光源与真实受光镜面增加微光接点，接点位于可见表面；光层与接点不投影，正常深度测试保留。光线继续来自 `GardenWorld.rays()`，经过实际遮挡/端点裁切，不借加亮或关闭深度穿过石壁。

动态过程中保留before/after一致的稳定入射前缀；尚未对齐的下游光束隐藏，新增落镜接点等落稳再出现。拿走B后下游失光，合法撤销后恢复。其他章节仍采用原Cylinder光束及原对齐合同。
