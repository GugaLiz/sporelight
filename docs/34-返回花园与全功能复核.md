# 返回花园与全功能复核

日期：2026-11-06。

后续澄清：用户所说“回到花园”是返回主界面。本页记录的恢复关卡操作不等于满足该导航目的；实际主界面与明确按钮语义见[文档35](35-主界面与继续关卡的导航语义.md)。

用户反馈设置底部“回到花园”仍没有生效，并要求复查其他操作和功能。本次把“按钮收到点击”“弹层关闭”和“返回后确实能继续游戏”分开验证。此前文档33的通过结果保留，但不能代替本次新增的状态组合。

## 1. 复现与旧验证缺口

旧版运行源为`681a2c16c40532fdce7d29e07cf42dff4ebcf359f586cba62287da5711ba023f`，332个运行文件。

594×462、普通桌面鼠标的真实输入pilot执行5项：普通设置返回、地图进入设置后返回通过；弹层打开后缩放、通关后从地图设置返回、成功导入后返回3项失败。因此不能把现象归结为每次点击都没有触发。

旧验证主要漏掉以下组合：

- `close()`只等`paused=false`，没有证明原弹层和按钮实例消失，也没有继续实际操作验证。
- 每个用例开始的QA快照重置会强制清理界面，可能掩盖上一页遗留的遮罩、焦点或动作锁。
- 鼠标用例也开启触摸能力，没有覆盖普通桌面环境；未覆盖594×462或弹层打开后调整视口。
- Headless中的信号调用和直接关闭方法不经过真实滚动命中；通关后的一般返回、回看及导入切场景也未形成完整用户操作链。
- 原命令覆盖清单只列集合，没有断言实际通过的代表命令与可用命令族相等。

原失败、状态和截图保留在[旧版浏览器基线](qa-godot-migration/full-function-audit/baseline/browser/checks.json)；旧版239项生命周期套件未通过，日志位于`qa-godot-migration/full-function-audit/baseline/lifecycle.log`。239是套件检查总数，不表示每项都失败。

## 2. 本轮修复与代码责任

| 修复 | 实际处理 |
| --- | --- |
| 已完成花园的一般返回 | `Main._on_command("resume")`为已完成状态建立`strolling`并同步HUD；保持当前花园及完成纪念，不再留下已解除暂停却仍被完成状态锁住的操作栏。 |
| 弹层仍存在时禁止恢复 | `resume`先检查真实`hud.is_modal_open()`；弹层拥有输入期间不能只改暂停标记。 |
| 切关、重开与成功导入清理 | `_enter_level()`以`close_overlay(false)`移除旧弹层，不恢复即将离开的旧场景；新场景清理路线、意图和输入，并恢复画面、音频。成功导入应用设置后走同一入口。 |
| 完成纪念回看可操作 | `_enter_level(review=true)`读取真实完成快照后直接进入浏览状态，保留`reviewing`及原纪念，不反复弹出完成界面或阻止行走。 |
| 弹层适应视口变化 | `GardenHUD._resize_overlay()`在布局时重算视口可用空间和StyleBox真实内边距；滚动容器使用剩余内容尺寸，替代固定减42的假设。QA按钮与控件都裁剪到实际窗口。 |
| 完成态撤销可用性 | 浏览完成花园时明确禁用Undo并说明原因；不因底层仍有历史而显示一个会被控制器拒绝的按钮。回到未完成关后恢复正常可用性和提示。 |
| 末关下一步文案 | Main按实际关卡目录传入`has_next_garden`显示属性；末关按钮显示“看看一路的纪事 ↗”，保留原`next`导航，不把显示属性写入规则关卡。 |

`GardenHUD.close_overlay(resume_game=true)`统一清理弹层、纸面和滚动容器引用；更换界面及切场景可明确选择不恢复旧场景。`ModalOverlay`、`ModalPaper`和`ModalScroll`具有稳定名称，便于核对真实界面状态。

调试参数`?qa=1&unlockAll=0`只关闭QA的全解锁覆盖，便于观察正常进度门槛；正常游戏规则、种子开路、连续行走、地图及素材不因此改变。

## 3. 后续可复用的返回合同

| 情况 | 必须满足的结果 |
| --- | --- |
| 一般关闭 | 实际弹层及其旧按钮实例消失；应用、画面和音频恢复，剩余界面可接受输入。 |
| 已完成花园返回 | 进入同一花园的浏览状态，操作栏可用；不取消完成、不伪造新解法、不覆盖完成纪念。 |
| 回看返回 | 可行走且回看身份保留；移动不把归档纪念替换成新的进行中存档。 |
| 成功导入或切场景 | 旧弹层、焦点、待执行输入与旧场景一起结束；实际显示、可操作世界和存档选择一致。拒绝导入保持现状。 |
| 暂停未提交动作 | 暂停时钟冻结；返回后原事务只合法提交一次，不能重复播种或重放旧输入。 |
| 视口变化 | 弹层打开期间也重算真实内边距与滚动范围；可见按钮命中区域取窗口和裁剪容器的交集。 |
| 测试闭环 | 用可信鼠标/触摸事件点击实际按钮，关闭后不做QA重置，继续点模式、走合法邻格，再用真实键盘返回；核对完整快照和准确提交次数。 |

复用处理时先区分命中失败、弹层残留、暂停标记和世界动作锁，再修对应职责，不能只让按钮显示反馈，也不能通过移除种子规则或改关卡路线绕过问题。

## 5. 测试扩展与边界

`check-buttons.mjs`新增`lifecycle`阶段，默认尺寸增加594×462；mouse上下文不再声明触摸能力。关闭检查要求可信事件命中具体按钮实例，并检查弹层消失；实际恢复动作由生命周期用例独立证明。

新增组合覆盖设置和地图入口、返回按钮不同位置、快速滚动、弹层打开后的缩放、暂停生长、开关和滑块拖动、设置重载、通关/回看返回、无中途QA重置的跨页链，以及拒绝/成功导入。命令清单现比较可用命令族、代表族和本行实际通过的族，集合不一致会失败。

该矩阵的生命周期行走使用1-1已知合法几何；后续关卡机制与通关由独立功能流程核对。长列表滚动使用真实鼠标滚轮，不能当作触摸惯性滑动；中文IME、系统剪贴板和原生文件窗口继续单列，不因Web自动化通过而视为已覆盖。失败报告保留，不用后续重测覆盖原证据。
