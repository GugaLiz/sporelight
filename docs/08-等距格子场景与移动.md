# 等距格子场景与移动

2026-10-27。根据用户提供的实际游戏画面参考，替换游玩页面的圆形节点连线图，新增可行走的等距石砖世界。本页描述当前游戏场景；早期文档中的节点移动描述以本页为准。

## 现在的操作

- 方向键 / WASD：每次走一格，按住可以连续逐格移动。
- 空格 / J：向最近的行进方向跳跃；方向盘中间或工具栏也可以触发跳跃。
- 点击石砖或植物：按真实可走路线逐格前往，途中会收集孢子，不会直接传送。
- E：走近植物后互动；数字1–4或右侧选项选择机关用法。
- 撤销：退回上一格或上一次机关操作，恢复相应收集与机关状态。
- Esc / 右上暂停：冻结移动与动画，调整设置后继续。

方向键对应格子的前、后、左、右。由于采用等距视角，画面中会呈斜向移动。普通跳跃可越过一格缺口，不能跳穿石墙或绕过未开启的机关。站在睡莲上时，跳跃可使用已有的固定落点能力；右侧仍可明确选择落点。

## 地图与规则

全部12关都有格子坐标布局、平台高度、连接道路与障碍物。石砖不是装饰：只有真实铺出的格子才能踩；墙壁格不能进入；台阶承接高度变化；未开启的藤桥、光桥与伙伴通路没有可走地面。

原有播种、回收、藤桥转向、日月切换、反射、节拍、引水、护送及终章规则继续生效。交互选项在人物走近相应植物时出现，走远后无法远程操作。第一关增加一处单格断路，引导使用跳跃；点击目标寻路时会安排合法的逐格跳跃。

## 画面与 UI

使用material/supplies.png中的石砖、草地、岩壁、台阶、石碑、植被及道具，结合已有遗迹拱门构建分层世界。远景从现有无UI场景图的上部裁切，避免背景中的道路与实际可走道路混淆。地面、墙体、道具和人物按深度分层绘制。

左侧展示章节、当前关卡与孢子收集，右侧展示机关说明与当前选项，右上提供暂停和设置。底部使用已有纸质素材工具栏。手机竖屏使用完整画布与跟随镜头，方向盘独立于画布缩放，按钮实际尺寸保持44px。

这是Canvas绘制的等距立体场景，使用现有栅格素材和高度/碰撞规则；没有引入WebGL三维引擎或生成新的AI插画。

## 代码与数据

| 文件 | 职责 |
| --- | --- |
| gridLayout.ts | 12关平台坐标、道路格、障碍、缺口、高度与等距投影 |
| GridWorld.ts | 单格移动、跳跃落点、碰撞、机关通路约束、格子寻路、邻近互动 |
| GridRenderer.ts | 石砖、岩壁、道具、人物的分层渲染及手机跟随镜头 |
| CanvasGame.ts | 输入、逐格队列、动画、暂停、触控与状态保存 |
| grid-game.css | 全屏场景、侧栏、方向盘及响应式HUD |
| prepare_grid_assets.py | 从既有素材导出地形、岩壁纹理和远景 |

地形资源位于`assets/images/grid-world/`，共18项资产，含manifest和预览。导出脚本需要Pillow、numpy及OpenCV，原素材不被覆盖。

存档增加可选字段`gridPosition: {x,z}`。老存档没有该字段时，从对应逻辑平台中心继续，保留收集、机关、通关、图鉴与角色设置。之后每一步都保存实际格子位置。越界、错误房间或被锁住区域中的异常坐标会回退到对应安全平台。
