# 第二关第二节银色镜架重设计与光柱美化验收

2026-11-13。用户要求光柱更优美，并重新设计一眼无法认出是镜子的镜叶。[本次原图](qa-godot-native/pond-silver-mirror-20261113/user-feedback.png)为两镜初始角度的侧视。此次授权局部重设计2-2镜子外观，替代旧四方框/绿叶背；3-4原镜构造和其他关布置保持。

## 设计与实现

2-2现为双面银色椭圆镜，实际反射载体仍为0.53×0.42×0.025m、中心高0.37m、原真实法线。镜面按局部顶点裁成椭圆，用天空色层次和两道白色高光表达银镜；绿叶背移除，正反面均可显示玻璃。它是风格化镜面，不是实时世界镜像。

内镜新增0.496×0.444×0.08m倒角银边，随真实镜面旋转。首批只有厚内框，实际看图仍是暗窄条，故未直接交付；最终另设固定世界45°、无玻璃的金属外万向框，0.54×0.50×0.025m。内镜在框中绕竖直轴转动，顶/底实际轴承分别连接内框与外框，短轴连接原叶座；外框不跟随相机，不伪造光学面朝向。

外框内孔半宽/高0.255/0.232m，与内框留0.007/0.010m净距；内框、外框在合法角度的XZ包络半宽均小于原0.205m硬座范围。银材metallic降至0.15，避免无环境反射时变暗。初始光学面仍真实侧对镜头，外框提供完整椭圆轮廓，不声称各角度都能看到镜面正面。

光柱径由0.14收为0.115m，外晕0.28m/alpha0.14，浅金边、奶白细高光，自发光降至0.035；截面高光按垂直实际光轴的视向计算。保留不透明圆柱主体、真实端部聚焦、正常深度、无内部端盖及镜面接点，避免重新退化为淡黄雾。反射、拿放、稳定入射和下游落稳合同不变。
