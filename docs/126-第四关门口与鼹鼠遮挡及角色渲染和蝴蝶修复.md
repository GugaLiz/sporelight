# 126 - 第四关门口与鼹鼠遮挡、角色透明渲染和蝴蝶反馈修复

日期：2026-11-19。分支：dev。以本次截图和动图为新反馈，不用旧报告的通过记录关闭问题。

## 处理范围与原因

- **门边微光**：1-4 的 `spore-0`（门铃格 `f:-2:5`）按用户要求单独使用最高 Sprite 优先级 127，并关闭该拾取本体的深度测试。其他微光保留正常深度；原逻辑格、浮动锚、点击命中、实际走近收集及撤销语义不变。这是局部明确授权的例外。
- **门口人物截断**：角色使用竖直深度图面，门的图面却倾向镜头；两者靠近时会相交，出现帽子/身体与石柱交错。1-4 门闩拱门以及内园门框、门封采用与角色相同的竖直深度方向，补偿投影高度并保留原脚锚、大小、正常深度。门闩双人默认站位改为门前左右两个真实合法端点，未对人物全局置顶。
- **鼹鼠旁遮挡**：原居民位于唯一西入口，角色可进入其占位；直接补碰撞会堵住通关路线，首轮候选已否决。最终将居民移到原庭院北侧的同层完整石地（保持原尺寸），为其设置共享物理碰撞/路径规划占位，两位在问候时走到前侧分离端点；NPC 保持不透明，不以整只透明掩盖穿入。没有增减道路、降低谜题高差或修改交铃/开门/会合/主动种植条件。
- **切换提示**：底栏与按键说明使用“切换角色”，桌面显示快捷键 T；小横屏/竖屏按钮保留完整文案，桌面为加长文案分配少量宽度。
- **蝴蝶**：用原生 shader 重绘完整的前后双翼、身体、触角、暖金边、细翼脉与浅色斑点，采用奶油白/浅苔绿配色。扑翼最窄时仍有完整轮廓；四只使用独立飞行节奏，避免原来最后两只重叠成碎片。保留原环境数量、停落/飞行动作、暂停、减少动态与粒子开关。
- **动态横线**：旧角色材质使用不透明深度预写入再透明补画；改成单次 alpha 裁切，并保留 MSAA 边缘抗锯齿、真实深度和原动作比例，减少两遍绘制自竞争的风险。原生旧版没有稳定复现用户 GIF 的横线，GIF 本身也含压缩网点，因此**双遍深度竞争是本轮修正的嫌疑路径，尚无精确旧版 Web A/B 证据证明它是 GIF 的唯一原因**；最终多时相画面和网页复测结果见下文，不能把压缩网点直接归因于游戏。

## 验收与证据边界

生产最终源码：`440b472bd32965e3798c0df88e0c1380f34eea6f144eb7251e3444984f93b5bd`，933 个文件。官方 release Web 模板，变体 `fourth-visibility-20261119-final`。

证据根目录：`docs/qa-godot-native/fourth-visibility-20261119/`。

- `baseline/`：初始复现、取消预写入和竖直图面的候选比较，不是最终证据。
- `route-1-4.log`、`route-final.log`：使用参考意图、真实物理电机、内存存档完成原 50 步路线；最终 191 项、1840 个运动采样通过。路径首轮被 NPC 占位堵住的候选未采纳；最终路线包含交铃、进入内园、两人会合、主动完成。
- `headless/`：角色深度/地面接触、门铃恢复、双人花床、共享环境与真实 HUD 定向检查。两个旧断言失败分别是新增 NPC 碰撞和已存在的道具碰撞层不再符合旧静态预期，不是放宽物理验收；随后更新为检查明确的居民占位与“地形/道具碰撞保留、角色不互撞”。`headless-final/` 保存修正后的通过结果。结构测试中的大量计数是重复采样，不能作为视觉评价。
- `gpu-verified/`：27877363 候选 161 项/28 图，真实走近居民、西入口、内园门、花床、门闩，两位各自带队；微光指针命中后真实走近收集，再撤销恢复；三尺寸 1280×720、844×390、390×844。后续仅拆开最后两只蝴蝶的飞行周期及清除文件空行，地形/角色/站位不变。
- `gpu-release/`：最终源码对应同一套 GPU 复测。内存准备的是“交铃后”关卡状态，之后才用真实电机行走/切换/跟随；不能将准备状态说成从新游戏完成全部流程，也不冒充浏览器输入。
- `butterfly-release/`：最终源码的额外近景看图及显式毫秒时钟验证，0/175/350/700 ms 分别覆盖张开/中间/收拢/循环返回；暂停保持时钟不动。第一组全场景采图的时间单位过小，不用它代替完整扑翼验收。
- `gpu-delivery/`：测试脚本漏接视图点击信号，导致新增指针拾取断言失败；修复采图 harness 后由 `gpu-verified/` 及最终 `gpu-release/` 取代，不作为产品失败或通过证据。

所有原生画面均为真实 GPU（RTX 5060 / OpenGL Compatibility）绘制，非重新合成的示意图。使用 AudioStub，不宣称音频或性能验收；运行时动效与 Web 条纹仍以相应画面范围为准。
