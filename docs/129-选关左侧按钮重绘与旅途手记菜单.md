# 选关左侧按钮重绘与旅途手记菜单

2026-11-19，dev 分支。用户指出选关页左侧按钮模糊、比例有拉扯感，“更多”展开面板过于简陋。沿 GQ-030 记录本轮界面反馈。

## 原因与修改

- 原地图背景烘焙了返回、品牌标题和世界总览，随整图放大变模糊；原生返回框的尺寸又乘了地图非等比摆放系数，导致旧底图与新按钮叠影、比例失衡。
- 使用内置 imagegen 清理左上及左下旧界面。实际运行只采样两处清理区域，其他地图原像素、地形、节点位置、角色和玩法保持。池塘／洞穴沿原图实测 RGB 色调变换匹配清理区域。
- 新的返回、世界总览、更多按钮放在独立屏幕层，统一 48px 高度，比例不随地图变化。用原生纸面边框、矢量图标与实时文字替代旧烘焙字。品牌标题改为实时文字与叶枝，洞穴配浅色文字。
- “更多”变为“旅途手记”：暖纸纹理、细双层边框、花枝与分隔纹样，设置／图鉴／花园纪事／云庭为双列图标入口；继续关卡使用绿色主按钮，导入导出独立一行。云庭专属故事入口仍保留。
- 菜单按视口限制高度，内容可滚动，关闭按钮固定。展开时阻止地图后台点击和键盘误触，关闭后恢复地图选择；首页与玩法数据未修改。

## 文件和素材

- `godot/ui/chapter_map.gd`：屏幕层、菜单布局与交互。
- `godot/ui/map_menu_skin.gd`：原生按钮和 SVG 图标；`map_menu_paper.gd`：纸纹、细边与既有重绘花枝。
- `godot/ui/map_left_cleanup.gdshader`：局部清理边缘与章节色调。
- 内置 imagegen 输出：[clean-left-map.png](../godot/assets/images/map-menu-20261119/clean-left-map.png)。完整提示词和参考来源：[prompt.md](../godot/assets/images/map-menu-20261119/prompt.md)。原地图未被覆盖。
