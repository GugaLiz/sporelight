# 雨滴琴无字叶键与木质琴托造型调整

用户指出2-3琴上的“转／升／歇”文字不美观，不如最初设计图。[本次截图](qa-godot-native/rain-leaf-instrument-20261113/user-feedback.png)重新打开造型问题；87号的玩法恢复继续有效，但文字叶不能作为用户认可的美术基线。误发LizMusic歌词请求已被用户撤回，本次没有处理该项目。

## 美术依据与实际调整

已实际查看仓库原设计总图`assets/images_old/sporelight_sliced_assets_web/00_reference/reference_full_design_sheet.png`、池塘章节参考图及旧2-3雨景截图。未找到可直接复用的雨滴琴独立成图；当前三叶实体是原生补充设计，本轮参考原稿的叶片、木质与柔和色调，不声称精确复原一件原稿乐器。

- 琴上的“转／升／歇”以及“琴”字全部移除，不再依赖字体。开口转弧箭头、上升箭头、双竖停拍改为3mm几何浅浮雕，沿真实叶面法线放置，离面1.5mm，正常深度、无图形投影、无独立碰撞。
- 去掉包围叶键的圆形强调框。叶键保持0.19×0.035×0.25m包络、0.23m间距、30°倾角及原按下状态；轮廓改偏心尖叶，补克制中脉，图案缩为首稿的0.75，配色收为柔和叶绿，减轻UI圆按钮感。
- 琴底仍为0.72×0.15×0.38m包络，改倒角木质琴托与深绿内面。每片叶下补与实际叶底接合的小支点，按原已奏状态压缩。原摆位、真实人物停步点、硬底座占地与导航包络保持，固定轮廓资源缓存，不逐帧建网格。
- 原三拍、全部操作、角色能力、交互距离、默认目标和主动菜单均保持。图形随当前玩家配置换位、已奏下压和重排恢复，不给正确顺序或新增步骤。
