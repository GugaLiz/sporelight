# Web加载页与首页风格衔接

日期：2026-11-06。初版已发布至 http://localhost:4185/。本文保留初版设计与验收，后续品牌坐标修复见 [加载页与首页品牌坐标对齐](40-加载页与首页品牌坐标对齐.md)。

## 设计与实现

用户反馈引擎下载时只有空白背景和进度条。本次使用 Godot 官方自定义HTML shell机制，加载阶段直接显示与首页同源的背景、Logo、露薇和微光，搭配中文阶段文案、暖色真实进度和进入首页的淡出。加载层不依赖引擎启动或PCK资源解包。

- 源文件：godot/web/loading-shell.html，export_presets.cfg 的 html/custom_html_shell 指向该文件。
- 四张网页专用素材来自现有首页，合计569913字节；与PCK分开导出，背景采用WebP。原素材不改。
- onProgress 提供真实下载字节；总量未知时使用不定进度，不伪造百分比。
- 下载100%只表示资源已汇齐，仍显示“正在唤醒花园”，直到startGame成功后等待两个显示帧再淡出。
- 成功后彻底移除status层并聚焦canvas；引擎JS或游戏资源下载失败保留中文提示、错误详情和刷新重试。
- 支持减少动态、无JavaScript提示、横竖屏、低横屏和窄窗口；错误详情使用textContent。

封面与加载页分别管理，不能用此HTML替换游戏内的动态封面。引擎品牌启动图仍关闭。

## 后续维护

修改首页素材后，可用带Pillow的Python执行：

    python tools/godot-migration/sync-loading-assets.py
    python tools/godot-migration/sync-loading-assets.py --check

普通Godot导出只复制已保存素材，不依赖Python。export.mjs记录四张网页图的字节数和SHA256；自定义HTML、图片和导出配置均参与运行源摘要，不能只改build里的index.html。

复验命令：

    python tools/godot-migration/check-loading-page.py --variant=loading-candidate

后续必须分别验收“HTML已可见、真实资源下载、下载完成但引擎未就绪、游戏已启动、错误与重试”。静态截图漂亮不能代替这些阶段检查，也不能为了展示加载画面人为编造进度。
