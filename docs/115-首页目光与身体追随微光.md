# 首页目光与身体追随微光

2026-11-18，`dev`。用户指出站立时眼神/头部呆，要求目光与肢体跟随微光、强化被吸引的感觉。续修GQ-025；114号恢复托光动作不覆盖此站姿反馈。

## 实现

原站姿始终用固定正面/侧面视线，转向按时间片切换，只有整体呼吸缩放，微光改变方向时没有对应的注意反应。本次只调整首页装饰演出，不修改关卡角色、玩法、碰撞或存档。

- 补绘同身份六种完整站姿：侧向抬眼伸手、平视探手、低头观察、近正面向左上/右上看及正面看头顶。方向根据微光相对面部的位置选择，上下左右不是独立的随机摆动；目光与手部反应发生在原2400ms迈步前。接近低处微光时先低头，再进入既有蹲姿/掌心托光。
- 原8帧步态及24秒脚点路径保留，行走添加轻微抬头追随。站姿身体向光源轻倾最多0.014弧度（约0.8度），以原脚点为中心；完整人物贴图上的头部区域在颈部柔和过渡，随目标微调最多0.045弧度（约2.6度）。没有独立头脸Sprite、双脸叠化或切割四肢；shader肩以下不作头部形变。
- 托光六姿势与实际手锚绑定保留，托光时不施加身体/头部追视变换，避免微光离开掌心。减少动态回到共享正面，清除头部与身体追随；原粒子/灯光开关继续生效。
- 微光离手后从帽子外侧升起，经过头顶再引向另一侧；避开五官及竖屏顶部标题。循环交界保持朝向光源的注意姿态，移除每24秒回到短暂呆立正面的间断。

新稿以已接入四分之三站姿/共享正面为身份参考，内置imagegen生成。首稿头小身长，已否决并保留为`attention-sheet-v1-rejected.png`，未作为交付资源。第二稿修正大头短身比例。包装完整角色、保留源alpha，六帧单一0.915缩放、靴底中心统一配准至512画布[256,472]脚锚，眼/颈锚单列。见[生成提示词与来源](../assets/images/cover-attention-20261118/generation.json)、[配准与SHA](../assets/images/cover-attention-20261118/registration.json)。运行帧位于`godot/assets/images/cover-attention-20261118/`，处理入口为`prepare-cover-attention-art.mjs`。
