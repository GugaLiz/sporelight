## 定点验收

工具 `tools/godot-migration/check-alignment-browser.py` 已完成语法、导入和主线 authored 前态核查，尚未执行新版 GPU 验收。QA 仅准备 authored 前态，机关、镜头切换和行走均使用真实输入；保留原始完整 PNG、状态 JSON、构建摘要、错误及输入轨迹。

- 首先执行 1-3 单关双尺寸：真实旋转覆盖四朝向，保存正常/全景。预期高差接岸数量为 0、1、2、1，并精确比较端点 ID；每个实际接岸执行向上、向下通行和角色/伙伴接触检查。
- cloud-1 使用 `stair:3:5` 与 `stair:3:4` 做真实双向通行。
- 20 个代表机关动作，覆盖转盘、升降、阀门、日月切换、节拍、持物、镜面、立柱、云庭旋转/升降等，保存操作前后原图并比较 authored 结果。
- 1-1/1-2 基准随每批保留；桌面 1280×720、横屏 844×390，DPR 1。
- 自动通过后仍须人工查看底座/圈、实际台阶上下平台接缝及运动中的圈跟随。静态前后图不能独立证明中途对齐，必要时复用 `check-motion-framing-browser.py` 的连续帧采集。

本文件是问题清单与验收准备，不是修复后通过证明。路径完整回归、几何哈希/接缝测试和 release 性能由对应任务汇总。
