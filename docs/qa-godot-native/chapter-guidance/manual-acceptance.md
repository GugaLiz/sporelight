桌面标题纸卡内应有2×2四阶段和进度，当前阶段、已完成与未完成可分辨。小横屏仅当前阶段一行和进度，不能继续占四行；标题、角色、微光计数仍清晰，地图落脚位置不被额外大卡遮住。阶段变化不得造成持续闪烁/伸缩。每尺寸静置至少120帧后操作一次持杆/切角，界面仍响应且控制台无错。

通过原提示按钮逐档查看第一/二/三档；每档内容不同，第三档最长文字不挤掉“下一条”和底部操作按钮。提示只在主动查看时出现；NPC台词不会抢占。切到其他关验证原HUD布局不被1-4阶段栏带过去。

至少“走近初态→真实拉杆触发help→切到远处伙伴隐藏”用真实输入验证；不能只准备相同逻辑格。身体在同一逻辑格内远离NPC也应按真实距离决定是否问候；不同高度不隔空触发。stage回调已有CPU覆盖，GPU仍看人物和NPC确实在合理可交流距离。

显示约8秒；同阶段站着不重复。20秒冷却内离开重进后继续站着，冷却结束也不自动重播；再次离开重进才可重新问候。机关阶段变化时近处允许新台词。主动提示、操作错误反馈、物件选择菜单优先；关闭提示后可恢复尚未说过的阶段。暂停期间访客计时冻结，恢复后没有一帧闪现或连续重播。关卡快照/进度不能因对话改变。

## 动态、设置和暂停策略

| 情况 | 期望与取证 |
| --- | --- |
| 普通地图 | 原梯田路径轻微流光、20点小环境微光；已解锁花床旁少量低幅花粉。固定相机相隔约1秒两帧应有变化，不能像新机关线路 |
| lowMotion开启 | 路径/花粉/环境微光停在静态表现，详情插画保留；同一稳定界面相隔两帧应一致，鼠标移出且不切焦点 |
| particles关闭 | 20点环境微光和花粉隐藏，路径提示保留；不删除原背景、花床、选中卡或入口 |
| 世界总览 | 原地图仍作为背景，但其动效时钟冻结且背景按钮不接受输入；关闭后恢复选择和普通动效 |
| 进入设置/图鉴等子页或隐藏地图 | 隐藏的地图不继续动画更新；返回原章节/选择，设置已经生效 |
| 从游戏打开地图 | 底层游戏暂停；地图属于菜单，其允许的轻量动态继续，这是预期。不能误把“游戏暂停”判成地图必须完全静止 |
| 显式地图暂停 | `set_paused(true)`冻结动态，解除后恢复；该接口CPU已验，当前普通UI没有单独地图暂停按钮，不伪造用户输入证据 |

最后用真实鼠标/触摸走“选关→总览→切章→设置返回→入关”，核对热区、焦点、解锁、存档和正文。截图采集运行不用于性能结论，不以20Hz绘制上限声称流畅或关闭GQ-011。
