## 1-4 提示和对话

`fourth_garden_guidance.gd` 按真实规则状态提供三档提示：保持重杆、伙伴穿拱、固定门闩、寻找门铃、露薇归铃、伙伴交接、接回伙伴、完成。使用 `lever_held()` 而非旧残留hold标志；保留露薇扳杆、伙伴穿低拱、门闩永久化、露薇交铃、两位到内庭后主动修复的因果。

HUD沿用既有提示按钮/提示面板。主动提示、操作反馈、局部选择优先于自动对话；离开NPC范围时隐藏其台词。提示与计时只在表现对象中，未新增教程存档标志。

接入接口：`hud.set_dialogue_proximity(Callable(view,"mole_dialogue_near_actor"))`。回调每帧返回当前角色实际身体是否靠近NPC的布尔值，应检查水平距离与高度；未绑定时，纯HUD/规则测试退回 `world.near(home.tile)`。main/stage集成及实际走近证据由统一验收负责。

随后按用户原图补回始终可见的1-4阶段栏。旧 `HUD.set_journey` 会清空所有步骤，而通用 `Journey.describe` 只有“花园复苏”，所以仅恢复NPC与主动提示不等于阶段栏已恢复。现由 `FourthGuidance.journey(world)` 纯读四阶段：固定归途、归还门铃、两位到花床、种下微光。桌面在既有标题纸卡内显示2×2紧凑阶段与0–4进度；小横屏只显示进度与当前阶段一行，未新增悬浮卡。其他关仍保持原布局。

阶段条件：固定归途读latch，归铃读home；合法替代路线若先到home且无latch，则第一阶段改为“已到家门”并承认里程碑，不强制补做门闩。花床会合需home且两位分别按原 `world.near(core,who)` 在合法同高花床近邻、同时满足原together；初态两人站一起不会点亮。完成读completed，已完成时四阶段保留完成表现。没有新增玩法门槛、教程存档、自动操作或自动通关；三层解题提示仍需主动请求。
