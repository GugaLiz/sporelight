# Release 显式关卡性能与画面复核

日期：2026-11-11。离线复核范围为 [1-2 原始记录](release-performance-1-2/checks.json) 与 [1-3 原始记录](release-performance-1-3/checks.json)，未重新启动浏览器、修改运行时代码或改写原始记录。

结论：这些记录确认了实际键盘操作及相应画面变化，所查画面未见新增明显脱离支撑面、旋转后连接错位或 UI 损坏；但首轮行走和首次旋转仍有明显回调延迟峰值，**GQ-011 保持开放**。两组均为 **explicit-level diagnostics（显式指定关卡的诊断）**，不是从首页开始的完整用户旅程，也不是全部 15 关的性能认证。

## 1-2：单次延伸与短行走

脚本分别按一次 `1` 测量首次根路延伸，再按 `z` 等待 700 ms、重按 `1` 测量重做。两次结果截图均显示“根路 1/4”“芽节 3/4”，确认单次延伸反馈一致；这不是四段根路完成或完整过关的性能样本。walking 采样中有 8 次交替左右键、每次 600 ms，约 4.8 秒输入置于 6 秒窗口内；行走后人物位置与朝向改变，收集数从 0/3 增为 1/3。

## 验收边界与下一步

本复核通过的是“所采集操作确实发生，所查前后画面未见新增明显渲染破坏”的有限结论。它不替代全关卡路径/通关测试、旋转动画逐帧连续性检查、小屏适配或触屏真机验收。

GQ-011 后续应继续以同构建、同输入、区分首次与重复操作的方式定位 1-3 首次旋转约 280 ms、首次行走约 171 ms 回调峰值；再次采样时仍应保留 rAF、实际回调、长任务及前后画面证据。性能结论目前不得写成“全部 15 关已优化完成”或“已无卡顿”。
