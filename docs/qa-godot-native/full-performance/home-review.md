# 普通首页与首次动作复核

`final-home-optimized/` 使用实际交付候选源码 b8980c78、scene-demand release 模板，1280×720 / DPR1，独立 Chrome，QA 发布器不存在。引擎构建和其他 GPU 用例均已停止后才开始采样。正常画质、光照和粒子设置保持默认。

人工复看首访与同上下文 reload 的完整场景：Enter/Enter 关闭首页并进入 1-1；第一生长后桥完整接岸、芽节 0/1；撤销后桥消失、芽节 1/1；再次生长与再次撤销结果一致。所有阶段人物保持地面支撑，未见材质丢失或光照变亮。两轮无浏览器/Godot 错误。

首访加载 6727.1ms、reload 2682.6ms。首访首次生长最大主线程长任务 216ms、重复生长 61ms；reload 两次分别112ms、56ms。这些仍属于短暂停顿，不据此声称每帧达到60FPS或所有首次材质都零停顿。完整 rAF、实际回调交付间隔、长任务和阶段边界见原始 checks.json。

`home-scenario-validation/` 是引擎构建期间的场景准备检查，不能用作最终性能数据。初始工具只等待固定墙钟时间，首个 shader 长任务消费了等待时间，阶段末截图仍在播种，后续撤销实际上取消未落稳动画。没有把该数据认定为完成动作的性能通过。

采样器已改为在输入后先交付两个真实 rAF，再开始收尾等待；这两个帧与其中的阻塞仍包含在该阶段计时内，不把首次停顿排除。`home-scenario-verified/` 确认首生长真正落稳后才撤销。最终新旧性能对照均使用修正后的同一采样器。
