# 1-3 无 QA 长时动作基线复核

源码 `5411b2264b38f7577f596a45d817b5800250ce39506caabc53ac227fc32f84bb`，4222 release，1280×720 / DPR1，GTX 1660 Ti，独立浏览器上下文，以 `--level=1-3` 诊断入口进入。不是普通首页/地图进入证明，没有修改存档、QA 恢复或 GL 包装。无浏览器/Godot 错误。此轮允许与另一 agent 的 headless CPU 测试重叠，因此不作为最终严格隔离对照。

## 实际操作

三轮交替持方向键均产生真实位移：首轮结束位于庭院西臂，第二轮回到西岸外侧并自然取得一颗可选微光；第三轮后点击中心，人物和伙伴抵达转庭机关。图片证据保存在 `0/`。

首次转庭确实从西/南连接变为西/北连接。一次撤销后平台仍保持该朝向，随后两次转庭实际依次进入后续朝向。因此本次“重复”证明重复转动动作执行，**不能**当成三次完全相同的 `0→1` 几何变化。原因候选是伙伴落稳产生了更近的行走检查点，需进一步验证；不能仅由图片断言规则出错。

后续场景已改为真实连续旋转四次回到原朝向，再重复 `0→1`，最后单列两次撤销检查，不假定历史深度。原 JSON 场景已内嵌在本次 `checks.json`，不会随场景文件修订改变。

首次转庭有56ms长任务，后续两次有59/64ms长任务；rAF中位/95分位大致仍在31ms。重复走路仍有长任务尾部，不能全部归因于首次 shader 编译。此轮没有 CPU 调用栈或 GL 分项，不能将具体函数标为已证明的根因。

初次进入到遮罩消失约15.5秒。它是显式关卡入口，不能与普通首页的首开耗时混合。

阶段截图在测量外，开始前额外排出两帧；报告只统计阶段边界内/相交的帧。原始 rAF 时间戳与 PerformanceObserver 长任务时长不总呈一一对应关系；新工具已额外记录回调实际送达时间 `performance.now()`，后续分别报告帧时间戳和回调延迟。本次原始记录没有该新增列，不追填推算数据。
