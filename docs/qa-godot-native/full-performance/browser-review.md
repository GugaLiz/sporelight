# 动作比例与运行表现独立复核

本轮在引擎编译期间串行执行 GPU 功能验收，不用这些采样声称性能改善。测试通过 QA 准备初态，此后用真实输入触发动作；读写的都是独立浏览器上下文。源码版本逐项列出，不能把后续未测版本算作同一次验收。

## 动作与脚底

`final-actor-action-browser/` 的源码为 `90f268f20f659639c83adec3eb5b6fea2dc6f5954a8c7d4433f9501ce6e79670`，官方 debug，入口4233。1280×720与844×390两尺寸均通过真实首关播种、过桥、走上台阶抵达当前花坛及主动完成，保持零收集直接通关。

- 两尺寸均观察到 sow 帧0、1、2、3、4，实际动作结束回到 idle_front；repair 实际使用 complete 姿态，而不是另一轮 sow。
- 为避免每50ms发布一次的 QA 帧标签与 GPU 当帧相差一个渲染间隔，另外保留逐 rAF 的原始人物裁图序列。标签明确写 `observedFrame`，不把它当 GPU 内部帧编号。
- 桌面保留19张播种连续裁图、22张完成裁图；手机保留21张播种、23张完成裁图。原始全幅截图和状态 JSON 同时保留，不只交裁图。
- 人工对照站立、前四帧蹲姿、第五帧起身及完成姿态：帽子/头部尺度连续，蹲姿降低的是姿态高度；第五帧没有突然放大。脚底留在相同地面锚点，未见横向跳位、穿台或抬离地面。生长结束截图恢复正常睁眼站姿，手机完成面板可读。

## 引擎像素对照准备

`compare-template-pixels.py` 审核两个验证专用 release PCK 字节完全一致，核对当前运行源文件集合与逐文件 SHA，并逐字节验证隔离 main 的允许差异（保留原始换行字节）。

对照在独立浏览器内通过真实设置控件启用低动态、关闭粒子，保留标准画质、灯光、材质与 MSAA；恢复固定时间1200ms的相同关卡状态并隐藏HUD。默认复用15关×4个已记录状态；这些是状态恢复的渲染对照，不是动画中段或真实通关。

每个状态保存官方A/B自对照、候选A/B自对照以及跨引擎全幅像素差。全图零遮罩、零容差；任何自对照不稳定都使该项不能通过，不拿噪声区域排除人物或水体。

首轮设置导航误以为 Esc 后还需打开设置，实际上 Esc 已直接到设置页；工具已据真实控件调整。原失败保留于 `template-pixel-probe/`，未进行像素比较。

`template-pixel-probe-ui-fixed/` 是第一次真正像素探针，15关扩展前被自对照阻止。1280×720下，1-1自差36/38像素、最大通道差1；2-1自差33/18像素、最大差5；3-4自差95/109像素、最大差1（数字分别为官方/候选）。跨引擎差与自噪声处于相同量级，但不能据此认定精确一致，更没有提高容差。

为排除固定状态后物理贴地与相机的亚像素漂移，总代理批准在隔离 fixture 的 QA snapshot 分支增加显式 `freezePhysics` 请求：暂停 native movement 并立即对齐相机。生产源码与运行方式不改，此能力只用于静态引擎像素对照，不是性能优化，也不参与真实动作验收。工具会独立重建这段精确允许差异并验证 main SHA，同时新增两次截图前后的 native/character/origin/scale 证据。重导出包 SHA 为 `86a2b5da74df18c3707220668fb275e9876ddc353add91af0acd2a7299578f85`。冻结探针仍有微量自对照差异，未宣称全图精确一致。
