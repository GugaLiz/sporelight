# 装饰比例候选与实测表

2026-11-11，依据项目 `game-scene-quality` Skill 与69号 GQ-001/GQ-003/GQ-009/GQ-012。**本页数值是供真实画面对照的候选，不代表用户已认可全关比例。** 1-1 dressing 文件、坐标和尺寸不变；本次只调整第二关与后续章节装饰，地形、角色、相机、规则与存档不变。

## 素材及尺度

测量对象为 Godot 实际使用的原 PNG：alpha≥64 的全部实体连通部分（粉花的多个小簇合计，不只取最大连通块）。这些素材已经紧裁切，主体 bbox 均为 `(0,0,W,H)`，主体宽/画布宽均为1.000；没有凭空补偿透明边。脚部保守足迹采用图像底部20%内 alpha≥64 的 X 包络，保留其相对图片中心的不对称性。脚锚由共享 Sprite 创建入口处理，dressing 不叠加新的竖直 offset；垂藤保留专用向下锚点。

下表世界宽高单位均为一格基本台面的边长；当前章节外缘与1-2装饰所在 x=-1/x=0/x=5 固定格宽深均为1。高度是原图主体在 Sprite 平面内的高度，不冒充相机投影后的屏幕高度。

1-2 候选变化：石灯0.40→0.43；两朵装饰蘑菇0.24/0.30→0.27；粉花0.27→0.34；蓝花0.29→0.30；蕨0.42→0.44；黄花0.26→0.28；藤0.23保持。后排阶梯不容纳完整蕨/黄花基部，故将两丛保留并移至 `f:5:1` 东侧外缘，偏移分别 `(0.30,-0.30)`、`(0.30,0.30)`，不占中央行走轴。二者水平投影间隔超过两主体半宽之和0.04单位，仍须GPU核对叶缘与前后关系。

## 支撑与遮挡检查

- `scenery_scale.gd` 保存测量与候选宽，按 `目标可见宽×PNG宽/主体bbox宽` 得到名义 Sprite 宽。运行时不扫描PNG、不按每帧更新时间。
- 放大后的脚部包络投到两条等角地面轴，并增加0.01余量。九点采样要求在真实固定格内且高度差≤0.008；替代原来所有物件共用±0.08的检查。
- 保留全部根槽/机制/出生点/收集物避让和独立挂藤规则。1-2仍有九个装饰，不静默删除未能落地的物件。
- 3-3石灯保持同一支撑格东北角；扩大到0.43后，对四个基部角的视线确认仍高于前方实际高台，旧位置的基准检查仍能发现被墙遮挡。
