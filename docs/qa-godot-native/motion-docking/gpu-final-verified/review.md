## 运动模型与承载

11 个代表动作 × 两尺寸，共 22 组，保存桌面 143 张、横屏 208 张逐 rAF 完整图像。操作前、实际最接近约 25% / 50% / 75% 的帧、首次观测到结束的帧，以及 700ms 后落稳图均保留。中段最大标签偏差分别为 0.03815 和 0.05433，均在预设 0.15 范围内。QA 标签是可观测发布状态，不是 GPU 精确时间戳。

已人工逐一查看全部 22 组关键帧表；1-3 另看先前同运动代码的全部连续序列、半转与落稳原图；云庭旋桥疑点另核对完整连续序列。

- 主线 8 种代表机制在两尺寸中未观察到运动中网格裂开、厚度突然改变或人物穿台：1-3 转庭，2-1 水位升降，2-4 船台平移，3-3 水庭旋转/升降，3-4 光庭/内庭旋转及升降。
- 1-3 活动 L 形顶面与侧壁在中段保持完整，固定岸保持原位；落稳才切换接岸版阶梯。这里有有意的接岸造型切换，不能描述成所有网格顶点全过程连续。
- cloud-2 升降可以看到人物随平台抬升；低位被前方较高固定地形遮挡，上升后逐渐露出，是需要保留的深度关系。本轮落稳承载断言通过，不能把自然遮挡直接判为穿模。
- **cloud-1 / cloud-3 的 `rotate` 未通过连续旋转视觉要求。** 操作前桥为起始方向，而首张 `observedProgress=0` 的动作图已经变成终点方向，之后约 0.081～0.887 的桥几何方向不再变化，仅人物仍有动作。两种尺寸均复现。逻辑后态与承载检查通过不等于桥有连续运动。直接证据见对应 `000-before.png`、`all-frames-00.png`、`frames.json`，不能用已有自动通过结果掩盖。
