# 角色动作比例与脚锚验收

## 原因与调整

原图均为 256 × 256，站立与蹲姿的有效高度却都约 216 像素。画布尺寸一致没有保证人体尺度一致：站立帽子宽 116 像素，交互蹲姿宽 139 像素，播种宽约 134–135 像素，播种起身与庆祝宽 126 像素。原生渲染此前统一使用 `pixel_size = 0.00625`，因此蹲下时帽子和头部明显变大。

`native_actor_pose.gd` 按帽子尺寸校准交互、播种、播种起身和庆祝动作，保留蹲姿本来应有的身高下降；不按整张图或整个人的高度归一。站立、所有走路方向、12 帧跳跃与滚球尺寸保持原值。全部原 PNG 保持字节不变。

播种图带有地面植物，不能把植物最低点当脚底。校准以人物真实脚底为锚，并对左右镜像同步修正横向偏移。动画切帧信号立即应用当前帧规则，播种第 5 帧起身也不会沿用前 4 帧的蹲姿比例。所有变更只影响精灵像素大小和绘图偏移，不改变角色位置、碰撞体、路径或动作判定。

## 已完成验证

- `native_actor_pose_test.gd`：606 个断言通过；读取实际源图像素，遍历全部原生动画纹理并比对原 SHA256；检查帽子尺度、蹲姿变矮、站姿恢复、切帧回调、四个朝向脚锚、滚球尺寸、碰撞不变。
- 实测站立帽宽 0.725 世界单位；交互、起身与庆祝约 0.725；播种上半帽宽约 0.7196（134 像素采样窗口，完整帽沿 135 像素），差异小于 1%。
- `native_actor_depth_test.gd`：原有 24,948 个断言通过，包含楼梯、全部章节站位、深度遮挡配置与落脚点回归。
- 两份原始日志保存在本目录。测试使用 Godot 4.7.2 的 `--headless`，未启动 GPU/浏览器，不把坐标与源图检测当作实景视觉验收。
