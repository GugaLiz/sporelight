## 结论与待修正项

地图及详情主体可读，12 张详情的小景和文案能区分各关的核心概念；保留了原站地图构图与纸质面板风格。小横屏标题、微光数量、主操作按钮及底部工具栏未见截断，左右留边可见，副标题按小屏策略省略。小景图标较小，适合作为关卡提示，不能替代关内机关教学。洞穴主题标志偏暗，但本批仍可辨认。

**仍有一项轻微布局问题，应在最终版重验：** 每章第 4 关被选中时，金色选中框顶部进入章节标题卡范围。桌面约从 y=85 向下，与标题卡底部约 y=130 重叠；小横屏也有同类交叉。见 [1-4 桌面](final-guidance-map/1280x720/map/1-4-map.png)、[2-4 桌面](final-guidance-map/1280x720/map/2-4-map.png)、[3-4 小横屏](final-guidance-map/844x390/map/3-4-map.png)。操作仍可用，但高亮线不应穿过标题/副标题区域；可约束地图绘制裁剪或调整高亮顶部，不必重做原地图。

三个章节背景构图相同、色调不同，属于原有 map-valley / map-pond / map-cave 资产的特征，不能误报为错用同一张背景。当前章节身份主要依靠色调、环境点光、详情小景与文字；本报告不要求为增加差异而破坏原作构图。

## 动效与交互证据边界

采集记录使用实际鼠标点击原地图地标、章节预览、设置与世界总览。两个尺寸均记录：正常动效前后不同，低动态前后相同，关闭粒子后环境区域静止，关闭粒子仍保留路径变化，总览期间静止，返回地图恢复变化；设置页无残留地图控件。人工查看未见闪烁残片、控制重叠或异常遮罩。配对间隔 1 秒，只证明该采集区间的可见结果，不等于长时间性能验证。

`hiddenClockVerified=false`：设置页截图和控件消失不能证明后台内部时钟停止；显式暂停 API 只有 CPU 证据，没有普通 UI 按钮可触发，因此不写成实机已覆盖全部时钟暂停路径。

本批是新进度状态：仅 1-1 可进入，其余关锁定。已完成标记、继续旅程、后续解锁和跨页存档状态需要另引用导航专项。鼠标事件也不能替代真触控设备验收。此报告不覆盖 1-4 六阶段引导截图、关内通关、正式导出、音频或帧率。
