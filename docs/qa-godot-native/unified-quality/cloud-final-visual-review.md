## 边界与疑点处理

- cloud-2升高后的画面，下岸召回牌的上半部被台侧遮住，台上当前操作牌完整可见。该组没有从下岸实际操作站位拍召回，因此记录为观察边界，没有凭上层视角把高低台关系判成穿模，也不声称下岸所有站位完全无遮挡。若后续真实召回站位出现只剩符号/杆体不可读，需另外回归。
- 云庭伙伴使用当前跟随偏移，几张图里与主角左侧轻微重叠，仍能识别帽、面部和主体；没有在这批中看到伙伴完全消失。截图不能证明两胶囊始终无碰撞。
- 小横屏仍是正常跟随视图，远塔/非当前岛和瀑流下段可能在屏幕外或HUD后。这不等于地图缺失；完整地图应另走全景验收，不能借本批宣称所有地形同时可见。
- before-completion/恢复完成态属于QA准备状态。虽然可看完成前后造型差别，不能称为本分支用真实输入完整通关。
