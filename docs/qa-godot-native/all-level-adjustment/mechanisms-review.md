## 审查发现并退回修复

1. stage 预览目的态使初版水位刻度提前跳档。改为复用已有指针，按同一 eased 进度移动，清理/撤销恢复。
2. Label3D 默认字体不含箭头/日月符号，项目 Noto 也不含顺时针箭头和月牙。已显式使用项目原 Noto，改用支持的「转」「日」「月」与箭头；全部符号验证 `has_char`，不新增字体资产。
3. 候选 3-4 中段提前画出完整目的态反射束。现在只在真实光路发生变化时暂隐藏，物理对齐后恢复；没有模拟规则外的连续角度射线。
4. 最终矩阵暴露原日/月柱顶默认黑描边过粗，主 agent 已将两柱统一为 4 号灰绿描边及日暖/月冷色；桌面实际图复核见下文。

首轮水位专项两项失败来自测试直接淹没仍留低路的清露，被领域保护正确拒绝。测试改用真实取露交露后的前态，没有放宽规则。
