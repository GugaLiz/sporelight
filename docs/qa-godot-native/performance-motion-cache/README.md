# 机关动画查询缓存验收（2026-11-10）

本次只缓存一段动画期间不变的前、后世界快照的 tile 查询。旋转中心、圆弧、直线插值、缓动、生长方向、缺失 tile 回退、地形碰撞和域规则保持原算法。切换动画重建两张索引；清除动画或跨关切换释放快照和索引。独立采样保留原来的 fork 查询回退。

## 可重复 CPU 对比

`native_motion_cache_test.gd -- --baseline` 使用继承 Stage 的未缓存查询实现：每次查询继续调用原来的 `world.point_for(id)`，其余动画逻辑相同。测试从 authored/3-4 真实 `world.act("turn:light")` 获得 native 快照，包含 70 个实际 surface。初始化不计入测量；每批重复 60 次 `set_motion`，每帧额外采样两个角色。计数来自覆写 `tiles()` 的世界对象，包含前、后快照和原世界。

另测 120 次角色采样：未缓存 147.958 ms / 240 次 tiles，缓存 1.313 ms / 0 次 tiles。该轮动画剩余每帧两次查询经后续分项审计确认来自水流固定端点展示（先前误归因于光线）；后续审计及修复见 performance-walk/README.md。计数下降约 99.35%；时间为本机 headless CPU 测量，会受并行工作影响，不能当作浏览器帧率承诺，也不解释冷启动 shader 编译停顿。

原始记录：[未缓存对照](baseline-uncached.log)、[最终缓存与几何测试](final/native_motion_cache_test.log)。最早直接使用 JSON 夹具的试跑曾因数值类型规范化触发独立采样回退；上表全部使用真实 native 动作快照，已排除该测试输入问题。

## 正确性

缓存候选 [checks.json](final/checks.json) 为 `passed=true, stable=true`，6 个测试套件共 7937 项通过，其中 motion 专项 7538 项。该候选曾含下述已撤回的阴影实验，最终交付以[最终源检查](../loading-startup/final-headless/checks.json)为准：摘要`5411b226…`，7套9912项通过，全15关实体路线完成；60帧查询仍为120次，耗时169.925–189.387ms。覆盖：

- 3-4 内圈与光台旋转、2-1 升降、2-4 平移、3-2 模式变化、1-2 生长；正向与反向。
- 进度 0、0.25、0.5、0.75、1 的全部 tile 采样，以及实际 surface 的缓动位置，独立对比保留的旧数学公式。
- 不存在的 tile、动画清除后独立采样、同关重新进入、活动动画中跨关切换、返回原关后的重建。
- 缓存不会改写传入快照或真实世界状态；warm 动画不再按 surface 重建完整 tile 数组。
- 原机关提示 178 项、光路展示 95 项、水呈现 43 项、根路径规划 40 项、根编织 HUD 43 项继续通过。
