## 仍不能从已有图可靠量的项目

- 多关原站终态核心被主角遮挡，原站1-1桌面终态还出现素材回退；不得补猜核心完整alpha轮廓。
- 29da动作图的地面清露、日柱、放下月柱与人物同格；不能用被挡部分反推完整主体。
- 主线莲池在原站小幅截图中与花、光晕、水面重叠，底叶外缘难以稳定分离；未据此填写一个看似精确的宽比，保留源47px与alpha账本证据。
- 全景缩放仅用于元素分布，不混入普通视图比例抽样。当前主体尺寸、alpha脚包络及源px换算已有CPU证据，但其性质与此屏幕抽样不同。
