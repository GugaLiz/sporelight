## 直接观察到的共同特征

- 主线第1章的墙体、花床、灯、蘑菇与垂藤都有明显体量和原画细节；根井与核心花坛并非同一种比例或身份。2D原图的厚花坛底座与活体植株一起构成主体，不能只恢复花尖。
- 第2章四关都呈现成片浅蓝自然池水，带柔和不规则边缘和水外小洲；岛外有灌木、石块、叶片、芦苇等景物，部分有青蛙与睡莲。它们是池塘整体构图，不是只在岛边加一条瀑布。具体实例数需结合源码逐一确认。
- 第3章是暗蓝洞庭氛围、岩石/苔藓竖面、蓝蘑菇及紫晶等装饰。3-1初始只显露起始岛是状态语义，不能拿该帧把尚未发现的区域登记成缺失。
- 云庭使用独立的浅奶油/粉彩建筑、简化方台、拱门、钟塔、盆栽、小凳与细茎小花；主角也是简化造型。它并非主线石砖、石灯与大型花坛的另一组摆放。当前原生仍需逐类映射，不能把所有云庭统一补成主线花园。
- 小横屏主线的左右HUD和底栏占幅很大，世界本身明显缩小；1-4对话、2-2提示又遮住中心。小屏适合复核对象存在与整体相对比例，但细小主体被遮挡时必须补普通走位或源码尺寸，不能编造像素比。恢复原版元素不要求复制原站HUD的遮挡缺点。

## 原图有效性结论与下一步

本批确认了原站可实际访问，初态15关双尺寸素材风格可观察，云庭初/终两态大部分场景可读；没有把历史纯色回退当作本次原版。**主线24张终态由于完成弹窗遮挡，仅能作为UI/外缘环境参考，终态比例参考不合格。** 集成者已收到此问题，应保留本批，另取“留下看看”后的主线终态；若采图较早导致缓存仍含弹窗，应等待实际场景图变化后再保存。

定量比例仍待测。应从原站实际渲染的邻格投影与主体alpha轮廓得到数据，配对当前候选；不能以本表的“大/小/醒目”当数值。尚无候选新图，因此本记录不表示原生恢复已通过，也不证明完整游玩、动画或路径。
