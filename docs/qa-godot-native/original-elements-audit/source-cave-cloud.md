## 5. 恢复顺序与验收建议

1. 先由远端核验确认本地源与站点一致，再把本清单中“存在/缺失/新增/语义不同”作为逐关登记，而不是把所有差异都当成应删的东西。
2. 洞窟优先补每关原装饰身份与位置、3-4灯塔和大核心，保留实时显隐。按同视口普通镜头记录主体/整格、主体/角色两个比值；各30/35像素变体不能统一成一种世界宽。
3. 云庭先恢复专属背景、建筑和修复前后场景，再对齐地标与比例。钟塔、花池、星灯串需要各自完整实现，不走通用章节花坛替换；程序/矢量原画适合repo内建模或代码绘制，无需用新生成图片猜原造型。
4. 任何原二维重叠移植到3D后，要测真实脚锚、底座、遮挡、机关运动，不把旧绘制顺序硬翻译成全局置顶。既有实体楼梯、接岸阻断、规则ID、存档、可选收集与主线/云庭完成条件均继续保护。
5. 每关至少保存初态、关键机制状态、完成态；3-1加迷雾/开窗，3-2加日/月/冻结，3-3加供水/取露，3-4加gift阶段与鼹鼠；云庭分别覆盖钟塔花开、池满/鸟/水帘、灯串点亮。桌面与小横屏普通图须逐项勾选，不能只截全景。
