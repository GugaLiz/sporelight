## 比例与测量口径

原版一格完整顶面投影宽70 px、深35 px；标准native一格水平投影宽为√2 world。若源完整PNG绘制宽为P：`canvas_ratio=P/70`，`native_canvas_width=P*sqrt(2)/70`。若alpha≥64包围盒宽为B、画布宽为W：`visible_alpha_ratio=(P/70)*(B/W)`，native可见世界宽为`native_canvas_width*(B/W)`。

这些是源文件和PNG解析比例，未重新进行屏幕人工尺量。多数预裁切装饰B/W=1只表示包围盒碰到画布左右边，不代表整张矩形不透明。阈值64与其他历史报告的128不同；遮挡、相机、DPR、动画和灯光仍需同视口原图验收。

1-1保留已认可专用profile，标准native公式仅作原版参照，不能说其实际大小已套此公式；其18件实际宽度另列。1-2原三件及四件保留额外使用30 px→0.6061 world，按现有安全物理位置放置。
