## 实现与位置规则

`original_scenery_positions.gd` 保存102个经过50状态回归的明确落点（98条主线来源条目＋1-2的4个额外装饰；首关6条来源对应认可手工场景，不改）。运行时读取并验证这些落点，测试覆盖状态中候选搜索/排序次数为0。`original_scenery_placement.gd` 以真实几何签名、核心实际矩形、交互/站位预留及前序装饰占地作为缓存键，复用位置与预留上下文；发现、照料等重建卡片时不重复搜索。将来未覆盖的几何才进入同高近邻后备搜索。

完整硬基座与植物根簇分开建模。拱门两柱、灯座、岩石、灯塔不再只使用最后5%窄底行；还考虑现有前脚锚相对基座中点的偏心。arch接触横向39…218px，相对160px脚锚按最大121px伸出量检查。石灯0…114px相对62px脚锚两侧均检查。蕨、花、灌木使用根簇支撑，叶冠允许外伸。这里只改变脚部验证范围，显示尺寸不变。

候选与缓存验证都要求来源所在同高连通固定岛的真实台面，排除临时根路、影桥、模块、水和未来逻辑格。位置同时避让实际core_planter的ground_footprint_center/span、其他装饰完整方形脚部、出生点、观察与机关站位、双人真实actor_rest_position、岛内步行主线、台阶进出、旋转四朝向/根路未来接岸和平移渡台两端。休息拱门与休息木灯保留rest建筑语义，不机械禁止共享休息格。

每候选5×5支撑采样，测试独立9×9加密；不每帧扫描像素或全图。旧允许跨一级高度、只按近邻平脚查找的函数已移除。

1-2 黄色花原站h2到revision2的h1属于历史地图映射，本批未改高度。元数据分别记录原站reference与当前layout reference，防止把历史跨高映射误写为此次同高移动。
