## 实现边界

`chapter_garden_dressing.gd` 的主线改走原逐件清单；原三色方案仅暂留为云庭独立适配接入前的 fallback。`second_garden_dressing.gd` 保留已确认的安全位置，按下列明确例外对应原三件。`first_garden_dressing.gd` 未修改。

所有新主线装饰完整 PNG 的宽度严格为 `原绘制px × √2 / 70`。不裁掉透明边、不裁切莲池底座、不把宽大的原 arch 缩成小灯。20 类 PNG 的 alpha≥64 主体及最后 5% 不透明底行已离线读取；运行时只消费常量，不扫描图像。脚锚的 Y 使用最后不透明像素中心，X 使用底脚跨度中心，修正木灯等偏心底脚及 arch 透明留白。

普通花草允许上部叶片视觉越格；底脚周围九个采样点必须落在当前真实固定地面上，且高度差≤0.012。莲池按完整底座宽度验足，因此三个莲池各内收 0.12 格。只改变显示节点的落点，不添加支撑、碰撞或规则边。
