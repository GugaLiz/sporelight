# 首关物件与地图融合

2026-11-07。用户确认楼梯处理良好，指出根台、花坛和南岛孢子仍与地图不协调。本轮只调整这些物件的表现；楼梯高度场、地图网格、行走控制器、关卡内容与操作代码保持。

## 原因与调整

- **花坛**：完整原图底座蓝灰色偏冷，原脚点又把前缘放到中心位置。分区调色让底座接近地图的暖色石材，同时保留植物色差、原图纹理和完整石座。原画前缘脚点放到地面接触范围的前角，避免悬空或把底座压进地面。
- **根台**：原藤根图带有很亮的光柱。保留全部藤根和嫩芽，降低高亮区域的强度，并按同样的前缘脚点规则落地。
- **孢子**：原图为带白边、外圈和卫星装饰的UI图标。仍从原图取种子及金色球心，材质中渐隐外圈装饰，降低悬浮高度至0.18；保持收集时的显隐规则。
- **接触与遮挡**：在实际地面放置轻微柔边暗部帮助辨认落脚范围。角色挡住根台/花坛时保留60%不透明度，其他植物保持原遮挡行为。没有新增物件碰撞。

`garden_prop.gdshader` 与 `garden_contact.gdshader` 只改变运行时采样和着色，不生成或重写图片。原图15项哈希保持，见 `docs/qa-godot-native/prop-integration/source-assets.json`。Shader透明预通过与深度测试参考 [Godot空间着色器文档](https://docs.godotengine.org/en/4.6/tutorials/shaders/shader_reference/spatial_shader.html)。接触暗部是美术效果，不宣称实时阴影。
