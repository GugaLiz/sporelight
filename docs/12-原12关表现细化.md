# 原12关表现细化

依据「关于游戏」下的《游戏初步想法》《游戏关卡初步设计》《游戏关卡细化设计》和《生动画分镜表和提示词》，补充当前12关的生命感、章节氛围和机关反馈。

当前版本以既有等距格子、转桥、升降、回收种子和小苔灵协作为玩法基础。原稿中的鼹鼠、蝴蝶、萤火虫作为场景叙事加入；本轮没有将协作关重写成引诱NPC或限时跳跃。装饰不产生新的道路、碰撞或收集物。

## 逐关表现

| 关卡 | 情感与场景 | 本轮已实现的反馈 |
| --- | --- | --- |
| 1-1 初生的孢子 | 晨雾中的第一次探索 | 起点至岔路的地面微光，蕨叶花纹、暖石旁漂浮光点，终点花苞光环。 |
| 1-2 第一朵花 | 一粒种子带来两次春天 | 未种花床呈褐色土纹；播种后出现花瓣与花粉光点；回收时恢复土纹。 |
| 1-3 苔藓山谷 | 向高处生长 | 藤桥根部叶瓣、飘浮光点；取回叶印后，对应山台出现叶瓣回应。 |
| 1-4 鼹鼠的家 | 帮助生命，认识邻居 | 内庭增加鼹鼠洞与探头鼹鼠；蝴蝶停留内庭，打开门闩后移至花园，蜜源花瓣同步转移。 |
| 2-1 池塘之声 | 被睡莲轻轻托起 | 三处睡莲带花瓣与循环水面涟漪；与原有花台升降、选点跳跃共同呈现水面活力。 |
| 2-2 涟漪之谜 | 把光送到暗处 | 静水池同心涟漪；双镜真正连通后，水晶周围出现苔藓花纹、光晕和光虫，断开则恢复。 |
| 2-3 雨滴节拍 | 雨天的专注与耐心 | 雨滴琴水纹与实际1200ms有效节拍同步，四个音符以光点记录；回声池、琴台、花台有局部落雨。 |
| 2-4 池塘守护者 | 伙伴与萤火虫的回应 | 踏板有芦苇色叶瓣；门闩打开前萤火虫停在高处，打开后移到花园并增加数量。 |
| 3-1 微光引路 | 从未知到安心 | 每盏已点亮苔灯增加局部柔光、光环与聚拢的光虫；未发现终点不提前显示光环。 |
| 3-2 影子的形状 | 日月两种光的诗意 | 石盘随当前选择切换金色日光、蓝色月光和天体符号；取回碎片后对应山台留下光环。 |
| 3-3 共生之歌 | 每种生命都有位置 | 从分水花向实际受水植物绘制流动水纹；切水后目标花瓣和柔光同步转移。水纹是供水提示，不是可走道路。 |
| 3-4 沉睡的守护者 | 归还星空的仪式 | 四处星座标记、循环花瓣光点、已点亮星座到水晶花的弧形光束；每点亮一处少一层藤蔓，四处完成后增加八瓣花纹、柔光、蝴蝶与光虫。 |

每关新增一句入场氛围提示与桌面章节卡短标题；明确操作说明、可用机关按钮和提示功能继续保留。手机竖屏隐藏短标题，避免挤占原有计数与操作空间。

## 设置与状态一致性

- 减少动态：水纹、昆虫、花瓣指示和流水停止运动，保留可读的静态反馈；节奏关按现有规则持续可操作。
- 粒子关闭：光虫、花粉和落雨停止绘制；保留水纹与必要进度标记。
- 动态光关闭：关闭新增径向柔光，保留轮廓与标记。
- 状态由现有激活、收集、朝向、节拍进度直接驱动；撤销和续玩不会留下错误装饰。

## 本轮范围与后续分镜

新增内容为Canvas程序绘制，复用已有场景与植物素材。原分镜中的完整电影式流程（孢子飞入计数器、分层花瓣骨骼动画、光球膨胀、动物群入场、新音乐编排）尚未实现。通关仍使用现有结算流程；终章的汇光、解藤与花纹反馈发生在星座仪式过程中，玩家仍需接回伙伴才可通关。
