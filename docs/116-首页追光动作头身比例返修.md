# 首页追光动作头身比例返修

2026-11-18，`dev`。用户补图指出新追光动作头身比怪。本次继续GQ-025；115号对生成第二稿“大头短身”的开发判断被新反馈否定，保留其检查事实，不再将其作为比例认可结论。

## 原因与修改

115号将第一稿头小身长返修时过度强调“大头短身”，第二稿帽子/头部比原站姿明显放大、身体缩短。既有自动检查只验证Sprite等比缩放、脚锚与方向，没有测绘画本身的内部比例，无法发现此类错误。

以内置imagegen参考现用`home-loading-refine-20261118/idle-quarter.png`和共享正面重新绘制六个完整追光姿势；上轮错误图仅提供动作方向，不作为比例依据。保留抬眼/平视/低头、左右上方/头顶追视及探手，恢复原帽子宽度、正常裙身与腿部长度。未拼接或独立缩放头、身体和腿，也未改变游戏关卡人物。

六帧统一0.9404117009750813等比包装，按靴底中心注册至512画布[256,472]。眼/颈锚重新测量，更新头部shader颈部位置；原视线方位驱动、24秒脚点路径、8帧步态、6帧掌心托光与减少动态行为保留。旧错误稿及上一版运行帧完整保留，新运行图为`godot/assets/images/cover-proportions-20261118/`。

原稿、提示词和参考角色见[生成记录](../assets/images/cover-proportions-20261118/generation.json)，尺度/锚点/每帧SHA见[配准](../assets/images/cover-proportions-20261118/registration.json)。包装脚本新增`--profile=proportions`，旧profile可复现115号历史资源。

## 后续反馈：动作组之间的角色身份仍不连贯
