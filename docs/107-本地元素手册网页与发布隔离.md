# 本地元素手册网页与发布隔离

2026-11-16。将106号元素库及相关规范做成可浏览网页。网页只读，读取现有维护文档与生成清单，不另外维护一套规则，不更改游戏或存档。

## 使用入口

本次已启动 [本地预览](http://localhost:4224/)，页面右下角“元素手册 ↗”在新标签页打开 [手册](http://localhost:4224/__standards/)。已有4222服务保持运行：自动审批拒绝了停止并重启该服务的命令（仅返回 `blocked by policy`），没有切换它。此次新增的4224用于查看网页与入口，原4222仍可继续游戏；不同端口的浏览器存档不互相迁移。

以后正常启动本地 Godot 预览或 Vite 开发服务，会自动提供 `/__standards/` 和入口，不需要重导出游戏：

```text
npm run godot:preview -- --variant=element-library-20261115-release --port=4224
npm run dev
```

Godot预览可显式关闭：`--standards=off`。关闭后页面没有入口，手册和数据路由全部404。Vite插件仅在开发服务生效，`vite preview` 与生产build不启用该插件。

## 本地与线上隔离

`tools/standards/portal.mjs`在服务响应中注入入口，不修改Godot导出的HTML。页面代码位于 `tools/standards/web/`，在Godot工程和Vite public目录之外。Vite配置通过 `apply: 'serve'` 接入；线上静态发布包不包含手册、数据或入口代码，也不需要上线后手工删除。

路由同时要求回环连接与localhost/127.0.0.1/IPv6回环Host；公开Host、远端连接、Forwarded/X-Forwarded-*/X-Real-IP请求被拒绝。文件与图片均按白名单读取，图片只能来自登记资源，不能通过URL读取任意项目文件。仅GET/HEAD；Markdown用安全DOM渲染，不执行HTML。手册页使用独立CSP。

游戏运行源保持 `0861f3e0…/668`，本次没有重导出Godot、修改场景或改变玩法。入口仅在本地服务的HTML响应中存在，正式HTML文件逐字节保持原样。
