# 章节封面作为关内背景的氛围试用

2026-11-19，dev；用户授权把133号新封面用于各章游戏背景，允许裁剪和透明度调整，以章节氛围一致为目标。本轮为可继续调整的视觉试用，不将技术检查称为用户审美认可。

## 实现

`presentation/native/chapter_backdrop.gd`共用三张 `assets/images/chapter-covers-20261119-v2/` 原图，主线12关按章节选择。等比cover后放大1.08倍，水平居中、竖向偏上裁切，不拉伸。分别叠加章节雾色：山谷暖灰金、池塘青绿、洞穴蓝紫；最终图像不透明度46%／50%／48%，让绘画远景退后、真实人物及平台保留对比。

仅替换 `native_garden_stage.gd` 的屏幕背景绘制入口。封面像素不生成碰撞、道路、可拾取物或点击区域；前景材质、机关、相机、天气、池塘水面和存档均不改。池塘现有水面覆盖画面较多，封面主要呈现在岸外与远处；云庭仍走专用背景分支。

原PNG没有修改，裁剪和透明度由运行代码处理。最初62%／56%／62%候选细节偏强，看实际合成后调淡至当前值。
