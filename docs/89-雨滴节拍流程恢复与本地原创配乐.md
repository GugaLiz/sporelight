# 雨滴节拍流程恢复与本地原创配乐

2026-11-14，范围为用户反馈的2-3流程混乱与游戏音景混乱。本轮保护[57号原玩法契约](57-全关卡玩法契约与优化清单.md)、[87号纠偏](87-第二关第三节原玩法恢复与元素清晰度纠偏.md)与[88号无字琴](88-雨滴琴无字叶键与木质琴托造型调整.md)，没有改动核心规则、默认叶序或原27步参考。

## 原因与修正

- 乘台地标`Mark_stage`没有种植功能，却通过共享`flower()`生成低岸花坛，升台后又被墙遮半。仅此实例改为随真实平台运动的脚印/环，移除其花坛和硬底座。实际目标花坛、平台高差和通路保持。
- 原TS已经提供的试奏`play/resetSong`被原生琴台距离裁掉，反向分工或两人在台上时实际入口可能为空。现在只在没有近处物理交互组时提供原本存在的这两项，保留原顺序、可用性和单项操作；未增加远程换叶或开闩。
- 自动播放时菜单仍显示打开瞬间的拍数和标签。现在同步已发生的拍数、当前配置及原动作标签，保留选中项、焦点和合法滚动，不暂停原时钟。
- 整段试奏reset误用“人物留在当前道路上”的占边保护，在台边与归途楼梯上拒绝恢复。恢复快照后`finish_mechanism.capture()`又用当前身体覆盖试奏前的细分站位。仅已接受的2-3整段试奏reset改为即时事务，先恢复原人物/平台/runtime；普通道路收回、松杆和机关运动保护保持。
- 旧配乐是14.4秒八音正弦短循环，环境声是固定C3音；多数操作共用0.7秒生长音，双人过格又可能重叠脚步。改用本地原创完整乐句、独立自然空气层与轻动作音色，按真实动作选音并做重复冷却。

高台与低岸未接通时的高差是原谜题的一部分，不新增楼梯、不降低花台、不添加解法指示。默认场景不增加角色分工、正确顺序或文字牌；原主动分级帮助保留。

## 配乐来源与试听边界

用户已选择本地原创纯音乐。此前Token Hub doctor确认音乐服务未配置，没有提交付费生成任务；本轮没有下载采样或调用音乐生成服务。`tools/godot-migration/compose-garden-music.mjs`以固定种子生成原创谱与合成音色，保留生成清单及音频测量，供重新生成和调整。

曲名《苔光间的慢舞》，112秒、60 BPM、28小节、立体声，使用疏朗键音、拨弦与温暖和声；独立环境层不混入旋律。音乐Ogg为744,491字节，32秒空气层为420,370字节；12项运行时音频共1,830,901字节，母带仅留QA目录，不重复打包。解码峰值分别为-12.0369/-23.4920 dBFS。生成谱与源码SHA对应，详见[编曲及测量清单](qa-godot-native/garden-music-20261114/composition-report.json)。

[纯音乐试听片段](qa-godot-native/garden-music-20261114/music-preview.wav)和[默认混音片段](qa-godot-native/garden-music-20261114/mix-preview.wav)均为32秒；游戏中为完整112秒循环。主观是否优美交由用户试听，不把数值检查表述为已经听感验收。
