# 封面画风统一与光束、木轮及地图标题修复

2026-11-19；当前分支 dev。用户最新反馈否决132号封面画风，旧报告的技术通过不代表审美认可。本次只调整封面、机关外观和地图页品牌／标题，保留现有卡片布局、谜题和存档。

## 修改与预防

1. **三章封面（GQ-030）**：以现用 `reference-scenes/map-valley.jpg` 与用户3-3实景截图为风格参考，通过内置 image_gen 分别重新绘制山谷、池塘、洞穴。使用有厚度的苔石台阶、微缩庭园、发光花草和柔和环境光；旧水彩稿不再作为当前素材。新版位于 `godot/assets/images/chapter-covers-20261119-v2/`，包含三张1536×1024 PNG及完整 `prompts.json`。原生成文件和旧版目录均保留。章节预览与世界总览共用新版；不能仅凭单张封面好看就认定与游戏一致，需在实际卡片中对照场景材质和光照。
2. **3-1光束（GQ-014）**：改为圆截面奶白光芯、暖金内晕与柔和外晕，随视角呈现径向明暗、两端柔化。所有层绑定同一真实光路，随灯移动、转向及石窗遮挡同步。保留普通深度测试、原照孔／接收条件；不增加假道路或改变谜题。最终半径为0.020／0.078／0.14m。预防检查必须使用实际网格半径，覆盖贴照孔边缘的连续站位。
3. **1-3把手（GQ-003）**：复用3-3同一自然木轮艺术资产和像素尺度，保留原机关锚点、低基座、碰撞支撑与旋转绑定。实际精灵透明区域命中仍由现有共享入口处理；验收包含走到木轮、旋转庭院及后续种植。
4. **地图页（GQ-030）**：左上品牌直接使用首页同一logo资源映射；星光洞穴的中间标题改暖白，并用轻阴影增加暗背景对比。章节及副标题同步调整，保留小屏品牌避让策略。禁止另造文字logo或以浓描边代替清楚的标题对比。
