# 125 - 通关弹窗紧凑布局与花纹按钮优化

2026-11-19，`dev`。用户反馈通关弹窗过大、按钮过宽高、底部留白过多，并要求按钮花纹及更紧凑的布局。

## 修改

- 原弹窗沿用普通菜单560×580的固定容器；通关页现单独按真实VBox／Label排版高度收紧，最大宽432。反馈图对应627×637视口，短文案弹窗约432×278，底部不再留大块空白。
- 标题、故事与统计居中，字号22／14／12；小横屏改20／13／11并减少边距。长结尾随真实换行增加高度，避免初版按字体估计高度导致滚动、焦点自动滚走标题的问题。
- 主按钮46高，浅鼠尾草绿配金边；两个44高次按钮并排，用浅纸底细边框。按钮两侧复用透明叶枝花纹，键盘焦点保留清楚的金色描边。文本、实际Button、下一关／纪事、漫步和地图的命令保持原语义。
- 改动仅在`godot/ui/garden_hud.gd`与`godot/ui/game_hud_skin.gd`，普通菜单、首页、设置和选关仍使用各自布局；未改关卡机制、通关门槛或存档格式。
