# 首页人物与跨页面角色形象统一

2026-11-18，`dev`。用户指出首页人物与 loading 不一致。本次归 GQ-025 的角色视觉续修；109号曾将完整原创封面角色列为保留项，其历史结论不覆盖此次跨页面形象反馈。

## 原因与修改

首页 `menu_vignette.gd` 仍使用独立的 `menu-walk-redrawn` 512px角色稿；loading 的播种图及关卡/地图已经使用 `full-asset-redraw-20261116` 的共享角色，二者脸型、帽子、身材比例不同。

首页现在通过 `ElementAssets.texture` 复用 `idle-front`、`idle-side`、`interact` 及12帧 `walk-side-*` 角色槽，默认主题与其他页面一致。原24秒路径、转身/蹲下/欣喜/返回时序、伙伴、微光、背景和设置保留；原封面转身与下蹲过渡改为共享站姿/蹲姿切换，欣喜使用轻微点头。没有新增人物稿。蹲姿整体等比0.8，避免共享蹲姿的大帽子破坏原演出站/蹲高度关系。

候选曾使用两张人物叠化，实看出现双脸与半透明重影，已否决。`gpu/` 保存该候选，不作为交付图；最终为单个不透明Sprite，保留原脚锚，不压缩身体或叠加人物。

| 0时刻站姿，1280×720，DPR1 | 旧首页 | 共享首页 |
| --- | --- | --- |
| 逻辑画布 | 512×512 | 256×256 |
| 可见alpha≥32包围盒 | 191×436px | 117×216px |
| 首页投影高度 | 约247px | 约245px |
| 脚锚 | 画布中心X、236/256Y | 相同 |

这保留了首页人物的整体高度，并采用其他页面的头身和宽高比例。loading 保留播种动作及其原构图。备用 `loader/hero.png` 也由共享正面角色生成，避免遗留另一身份；当前独立loading实际使用的是 `sowing.png`。动态消费审计更新为共享角色槽，旧封面素材保留但本入口不再消费。
