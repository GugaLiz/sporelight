## 四、🌟 1-4「鼹鼠的家」双人协作机制（进行中 1/4）

**机制**：
- **换手 T**：切换露薇 / 小苔灵两个角色
- **机关**：重杆（hold）、轻叶踏板（plate）、固定门闩（latch）、门铃（bell）、归还门铃（home）、种微光（core）
- **目标**："固定归途 / 归还门铃 / 两位到花床 / 种下微光"

**已验证流程**：
1. 露薇扳住重杆（保持）✅
2. 换手小苔灵踩踏板 ✅
3. 收好门铃 ✅（门铃进入挎袋）
4. 固定归途门闩 ✅（旅程 1/4）
5. 待完成：归还门铃 → 两位到花床 → 种微光

**发现的体验点**：
1. **双人协作需要频繁换手**，操作较繁琐，容易迷失当前控制谁。
2. **角色走不到某些平台**（如露薇走不到左平台 home），需确认连接是否依赖另一角色踩踏板；若依赖，建议加"桥已连通"的视觉/文字提示。
3. "此刻可以做"面板在"附近暂无可操作物件"时不够明确（不知道下一步该切哪个角色去哪）。

## 五、建议

1. **1-4 增加协作提示**：换手时提示"当前控制：露薇/小苔灵"，以及"切到小苔灵踩踏板"这类引导。
2. **修复后回归 1-4 及第二、三章 / 云庭样章**（本次因 1-4 未完成，后续关卡未能实测）。
3. 1-4 的"归还门铃 → 两位到花床"若存在连通依赖，建议在 UI 上明确"需另一角色协助"的状态。
