角色动作统一256×256画布，脚底锚点固定在y=236，21张动作均经过锚点检查。素材本身包含不同姿态与观察角度，未使用AI补帧。

## 人物动作

- 正常移动：使用6张真实行走帧，按运动方向翻转或切换背面；速度按路程计算，脚底保持稳定。
- 背向移动：使用已有背面姿势配合轻微摆动，源图没有完整的背向行走循环。
- 播种与引水：从动作触发时刻播放5帧播种，末帧短暂停留后回到待机，不再按全局时间反复切换三帧。
- 调整机关：使用互动或踮脚姿势；雨滴音符有轻微动作反馈。
- 点亮苔灯和仪式：使用共生发光姿态。
- 睡莲跳跃：起跳预备、腾空、落地压缩；影子留在地面，随高度变淡。
- 滚动：工具栏可以切换为蘑菇球模式，移动时球体转动并留下微光拖尾；可随时切回行走。
- 通关：切入鞠躬姿势后进入结算页。
- 低动态模式：使用稳定站姿和短位移，关闭跳跃高度和持续身体摆动。暂停时角色动作时钟冻结。

移动模式属于当前局的表现选项，不修改关卡解法、收集、通关或存档结构。角色移动可打断尚未结束的播种演出，已经完成的机关状态不回退。

## 页面 UI

主菜单使用btn_01的纸质纹理、叶片装饰和标题切图，菜单与命名页更换为高分辨率透明立绘。游戏工具栏使用btn_02的图形，播种和滚动有真实高亮态；主要操作的文本保留并随当前机关变化。

设置弹窗、命名面板、通用按钮、画质选项和图鉴分类统一纸质底图，开关使用素材中的开/关两态。音量滑轨改为暖色轨道与绿色手柄。通关按钮使用btn_03的装饰底图，仍显示真实文字并执行原有下一关、重玩和返回操作。

键盘焦点仍可见；禁用状态保留；开关通过aria-pressed表达；装饰图片不重复朗读。竖屏工具栏显示六个操作，按钮高度至少44px。
