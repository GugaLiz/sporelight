# 连续根路逐格搭建与第三章花坛比例修正

2026-11-14，用户要求连续地板必须一边前进一边搭建，同时指出3-3终点种植花坛太大，要求将类似问题分类记录。本报告覆盖这两项反馈；用户本次明确的逐格搭建要求替代旧的起点连续建造操作。

## 原因与调整

原逻辑从已建道路末端计算下一格，却始终使用根台作为操作距离锚。因此角色留在起点可以不断远程搭建，走到前端反而没有操作。现将首格与续建分开：首格保留原根台范围；续建须由主角站在最后一块已完成地板上进行。仅在其相邻旧格不算到位，同坐标不同层也不算。实际支撑的固定格/根路别名按坐标和高度匹配。

菜单、场景加号及执行事务共用同一站位判定，旧菜单或直接命令不能越过它。加号仍表示下一格将建的位置，交互锚位于现有末格。每次只建一节；原有预算、可选方向、浇水、交露稳定和完成条件保留。回收保留原起点入口，增加末节前一格的入口，人物或物品仍在末节时禁止收走支撑。主动帮助同步说明站位，不增加默认攻略或场景文字。

| 范围 | 处理 |
| --- | --- |
| 1-1 | 仅一节，保持原操作及已认可比例 |
| 1-2 | 四节绕石根路逐格前进，保留上下两条方向选择与四节预算 |
| 3-3 | 四节根路逐格前进，保留水向、清露、稳定根系及升降条件 |
| 3-4 | 三节根路逐格前进，继续验证真实落脚与完整后续流程 |
| 根路规划试玩 | 草稿仅在副本模拟合法走位；实际队列必须真实走到末格，不提供远程执行例外 |

旧档中的已建根路保留，重新加载后按当前末格续建；没有更改地形版本或重置进度。历史参考路线保留原文件，新验收在原操作意图之间插入真实行走，不重录参考答案来掩盖行为变化。

真实回归额外发现3-4第一块路无法走上：起点镜叶石基宽0.41米，加上人物导航半径0.18米后横断出口；此前站在起点连搭掩盖了此处通行问题。镜体与石基在原槽内向北移0.20米，保留镜子尺寸、逻辑拾取格、角度及反射条件，实际路径能沿南侧绕行。修前失败日志保留在`gpu-diagnostic-3-4/run.log`，不以放宽碰撞或允许远程搭建解决。

3-3核心花坛原画布宽约2.222米，本次局部调为1.65米，即原来的约74%。可见主体宽约1.444米，石基硬占地同步缩小；保留原同高支撑及后侧偏移。花蕾、开花与恢复共用底座尺寸和脚锚，角色、伙伴及其他关花坛不随之缩放。95号此前保留核心花床大小的结论已被本次用户反馈覆盖。

## 同类问题的统一入口

以[69号问题台账](69-游戏开发基础质量规则与问题台账.md)为统一入口，而不是在各次报告散列新编号：

- **GQ-001 比例**：记录可见主体、角色与所在台面比例；单独区分透明画布和硬底座；同时检查普通镜头、小横屏、初态和完成态。
- **GQ-003 / GQ-004 支撑与建模**：检查实际脚锚、完整底面、接岸归属、同高重复地板、硬碰撞及前进空间。尺寸正确不代表位置或可通行性正确。
- **GQ-022 连续搭建站位**：首格在起点，续建站末格；菜单、场景点击与命令执行保持一致；验证原地重复点击、行走后续建、错误方向回收、撤销和读档。

每条记录包括现象、适用关卡、预防动作、验收证据及状态。发现其他关同类问题时追加到对应编号；不因分类相同就批量缩放所有元素或改变机关玩法。逐关契约同步维护在[57号](57-全关卡玩法契约与优化清单.md)。
