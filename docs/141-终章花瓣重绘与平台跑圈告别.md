# 终章花瓣重绘与平台跑圈告别

2026-11-20，沿GQ-030。用户否定140号花瓣造型与动作活力，要求重绘花瓣，并先绕平台跑一圈、再居中微笑大幅挥手。本次替代140号静站挥手及矢量花瓣的表现，原逐行文案和终章导航保持。

## 实施

- 内置image_gen重绘四种柔粉卷边花瓣：有透光边缘、弯曲花面与暖白基部，取消旧平面多边形／画线叶脉。原始透明图集入库，Godot AtlasTexture按象限取图，无背景抠图或修改生成alpha。远近36片保持飘移、翻面与不同尺度，阅读区域减弱，原散点微光保留。
- 0～0.35秒停留；0.35～1.25秒从中央轻跑到右侧；1.25～7.05秒沿椭圆完整绕一圈；7.05～8.05秒回中央减速；8.05～8.5秒站稳；随后抬手微笑并循环挥别。跑圈只在每次入场执行一次，不反复打断文案阅读。
- 使用现有正面、背面与首页侧面动作帧，按路径切换朝向，配步频、轻微腾起与落地影。终章美术路径不参与实际关卡碰撞／导航。停留脚点对齐背景中央花纹，小苔灵移至环线外前侧；按脚点深度决定前后层，竖屏按画面宽度收敛横向半径。
- 告别身体与手臂采样同一透明原画，手臂在袖口处分层绕肩部刚性旋转，约63度往返范围；替换上一版小幅UV拉动，避免大幅挥手时手掌拉长。保持脸型、服装、头身比例和脚锚，轻微头部回应。
- 减少动态直接停在中央告别姿态并立即显示全文；正文仍可点击直接读完，所有出口保持可用，不改变旅程进度。
