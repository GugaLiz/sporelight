## 一次性整改的执行规则

1. **逐关实例账本**：原素材/数量/条件 → 当前支撑、完整底面、世界宽高与可见主体 → 默认操作及双人停靠 → 需要改动及原因。采用原版局部格占比与主角作参照，不只比PNG画布或同一个scale值。
2. **按语义处理实体**：硬石基、镜座、灯脚、柱脚等有真实局部防入；植物根与自由冠、光晕、水帘分开。拱门保留洞口、花草不整体做硬墙。新增碰撞同步点击绕行、伙伴、旧非法pose和动态拿放/撤销，不能留下顶墙循环。
3. **位置与比例分别锁定**：用户已认可的尺寸不借摆位再缩小。完整底面同高支撑，排除原道路、楼梯、未解缺口、未来靠岸和操作站位；投影遮挡独立看两人及道具，不以平面不相交宣称画面合格。
4. **提示绑定真实进度**：恢复1-4情境台词、分阶段可操作提示与正确动词。按hold/latch/bell/home等实际状态决定，不显示过时任务、不把提示变强制解法、不恢复“换手”术语或错误动作。
5. **章节地图共同风格与独立主题**：保留原插画、纸面UI、关卡ID/解锁/继续与触控热区。山谷根芽、池塘涟漪、洞穴星光分别表达，关卡标记体现该关机制；动效使用统一时钟及设置，暂停/隐藏/减少动态生效，不每帧重建控件或素材。
