## 关卡内容和保留边界

关卡 JSON 没有修改。起始岛保留根台、两颗孢子和休息点；东岛前排保留花床，后排保留三条可上下的邻接；南岛保留第三颗孢子与观察点。只有一节根芽，向东与向南互斥。直接向东、零收集修复合法；先向南探索、双角色返回后回收改向东也合法。本关没有旋转或升降模块，不新增机关或强制收集条件。

## 本版调整

- 恢复原 paving-valley / paving-grass / paving-moss 地面、masonry-valley 石墙、stairs 石阶纹理，以及暖色背景、花卉、藤蔓、石灯。15 项原图和引擎副本的 SHA256 与素材清单一致，详见 `qa-godot-native/material-preservation/source-assets.json`。
- 花床使用完整 flower/bloom 图片，保留原石底座；角色回到原 pixel_size=0.00625。移除上一版新增的圆柱根座与角柱。
- 南岛全部保持水平。只有种出南向根路后，连接本身才出现六级下行台阶；不再让整排南岛形成斜坡。
- 后排及接岸楼梯使用真实水平踏面与竖直立面，同一几何定义产生可见网格、碰撞和支撑采样。楼梯石面从原图采样，源图不改写。
- 踏阶动作限制在当前或合法相邻支撑，通过完整胶囊的上、前、下碰撞扫掠，保留缺口保护、即时停步及反向。南桥曾尝试将台阶挤在半格内，导致回程卡住和接触误差；最终沿整段连接展开，保留失败记录。
- 根台按钮明确显示“选择生长方向”“向东生长 · 1节”“向南生长 · 1节”“收回根路”。保留就近交互、占用保护、主动修复、撤销和存档。
