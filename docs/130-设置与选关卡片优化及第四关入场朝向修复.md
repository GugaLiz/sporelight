# 设置与选关卡片优化及第四关入场朝向修复

2026-11-19，dev 分支。对应本轮五张反馈图，沿 GQ-031（设置）、GQ-030（选关 UI）、GQ-025（图素呈现）追踪。

## 修改与原因

- 设置弹窗：粗多边形星纹／叶饰替换为项目现有的细线、渐变 SVG 星纹和弯曲叶枝；保留暖纸面，叶枝位于按钮以外的边角。顺带修复 320px 窄屏音量条横向溢出：说明与开关文字可换行，画质按钮取消过大的单项最小宽度。
- 世界总览：仅展示苔藓山谷、雨滴池塘、星光洞穴，三张卡片居中。按用户要求仅从此处隐藏云庭微光；更多菜单的云庭入口与存档不变。
- 选关右侧：原生纸面、文字、细边框、金星分隔纹、真实收集数量及章节进度条；屏幕尺寸绘制抵消地图非等比缩放。章节预览使用已重绘的花朵／莲叶／星花插画替代模糊地图裁片。高卡片增加花朵插画，短屏保留必要标题、计数和操作按钮。没有新增 AI 生成素材。
- 1-4 窗／花园门／鼹鼠首次入场变扁：`_upright_card` 读取相机基向量，但 `set_world` 原先先生成静态道具，后初始化镜头；首次进入时读取单位基向量，拾取等状态更新重建后才恢复。现于 `refresh_world` 前建立实际固定相机朝向，保持原尺寸、脚锚、真实深度及关卡规则。

主要文件：`godot/ui/settings_page.gd`、`godot/ui/chapter_map.gd`、`godot/presentation/native/native_garden_stage.gd`。预防：依赖相机的静态几何须在相机朝向初始化之后构建；验收包含全新场景的首帧，不能只看已切换／已刷新场景。
