## 1-1 到 1-2 应当教会什么

| 维度 | 1-1 | 1-2 |
| --- | --- | --- |
| 核心决策 | 一节芽选方向：东侧主线或南侧探索 | 四节芽保持连续，绕开中央岩石 |
| 空间阅读 | 根台、缺口、目的地、高低岛 | 起点、根尖、障碍、可延伸空隙、对岸接入点 |
| 结果反馈 | 选方向 → 长出路 → 亲自过去 → 花坛复苏 | 安排绕行 → 根桥接通 → 亲自过去 → 花坛复苏 |
| 容错 | 安全收回、改道、撤销 | 草稿回退、确认前修改、实际生长后的撤销与续接 |
| 可选内容 | 南岛、微光、观察与休息 | 微光、观察与休息；不应变成完成门槛 |

1-2 适合作为连续根路的巩固关。当前两条合法解法对称，主要分歧是最初选择上绕或下绕，之后的合法延伸较明确；四次点选不等于四次独立的策略决策。现阶段优先让玩家看懂路线与结果，不宜仅为增加时长加入花粉往返、钥匙、强制收集或额外高台。

规划版值得继续比较：它把整条路线与最终生长结果联系起来，草稿也方便修改。但它比 1-1 多了“进入规划”和“确认”两个概念，方向键在规划时用于选点而不是行走。因此进度、草稿与实体的区别、确认时机、退出方式必须清楚。不能只依据规则测试就认定它比正式版更好。

## 代码核对发现与本轮修改

1. **横屏进度缺失。** 公共 HUD 在屏幕高度不超过 500 时隐藏目标行；此前只有这行显示 `n / 4`，底部始终写“让根桥生长”。现在原主操作按钮显示“规划根桥 n/4”，路线完整后才显示“让根桥生长”，生长中显示实际已提交节数。不新增面板，也不修改通用 HUD。
2. **续接画出了错误的起点。** 已生长三节、撤销最后一节再规划时，旧绘制总从根台连接草稿，并把新节编号为 1。现从实际最后一节根尖连接，编号接续为 4；已提交的根路不再叠空白规划格。点草稿编号仍只删除草稿，不删除已经存在的根桥。
3. **帮助停留在过期阶段。** 旧提示在规划中仍要求“走近根台”，桥接通后又回到普通绕岩说明。现按探索、未完成草稿、可确认草稿、生长、过桥和完成展示帮助。只更新已经打开的提示，保留提示级别，不自动打开或提前选定路线。
4. **确认和终点缺少明确衔接。** 桌面目标行区分“路线已接到对岸，确认后才生长”和“根桥已接通，去照料花”。手机用原主操作按钮表达进度，并可主动查看同阶段帮助。

保留四节预算、上下两解、原图素材、现有花境/岩柱、共享菜单、移动、事务和内存存档。`levels.json`、领域模型、正式版控制器与 1-1 均未修改。

## 后续顺序

1. 连续试玩 1-1 → 1-2，观察玩家能否理解第二关先规划、后生长，以及最后仍需到花坛主动照料。记录是否误把方向键当移动、是否找得到确认、是否误认根桥已生长。
2. 以实际截图判断中央岩柱与两岸缺口是否清楚。已有岩柱和后庭花境先保留；需要修正时先处理轮廓、遮挡与接岸，再决定装饰。不要继续叠加植物来掩盖通路理解问题。
3. 试玩流程确定后再接正式旅程：处理已有部分根桥、草稿是否保存、确认途中退出如何恢复、完成纪念与跨关状态。内存试玩通过不代表这些正式存档语义已经完成。
4. 若需要更高难度，另行设计有实际取舍的路线，并重新验算预算、回程、撤回和两解；本轮不扩张谜题。
