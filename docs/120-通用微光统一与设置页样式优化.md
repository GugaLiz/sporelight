# 通用微光统一与设置页样式优化

2026-11-18，分支 `dev`。对应用户提供的 2-1 微光截图和暖纸色设置页参考。本次沿用现有重绘素材，设置页采用 Godot 原生控件与矢量装饰。

## 微光核查与修正

图中破碎斑块已在真实 GPU 下复现。它们绑定的已经是 `scene-redraw-20261116/spore.png`；隐藏花草/清露的诊断图中，原微光恢复完整。原因是同格近共面 billboard 的深度竞争，不能把这个现象简单归为仍加载旧图。

- 实际遍历主线 12 关和云庭 3 关，共 115 个初始/关键状态；资源审计发现 51 个使用重绘微光的渲染节点、97 个使用上下文，未发现旧微光位图实际绑定。完整清单见 [asset-usage.json](qa-godot-native/spore-settings-20261118/asset-usage.json)。这是状态资源审计，不是重新输入全部通关路线。
- 世界 `spore`、同源 `icon-spore` 和 HUD 计数通过共享解析器使用同一重绘稿；地面/携带种子的通用微光调用同一别名。默认 bitmap 映射补上旧源→重绘稿，即使重置外观主题也仍使用重绘微光。
- 对与 rest/observe/item/flower/lamp 标记同格的通用拾取，在原支撑内稳定错开 `(-.32,0,.20)`；原地面铃同格偏移及 1-4 的三个专项位置继续保留。1-1/1-2 原认可摆位不改，整体大小、浮动高度、逻辑格、收集条件和正常深度不变。
- 只有同语义可收集微光统一使用该稿。首页环境光球、环境星点、萤虫与云庭原生星形物件保留各自语义；旧 TypeScript 历史入口未宣称完成本轮迁移。

| 尺度/支撑 | 本次值与边界 |
| --- | --- |
| Sprite 画布世界宽 | 原 `35×sqrt(2)/70`，约 .7071 m，不变 |

| 对照 | 1280×720 GPU，15 关初态；2-1 增加特写及另一浮动时刻 |

修改前/诊断图保留在 `gpu-before/`、`gpu-diagnostic/`；隐藏道具只用于诊断，正式游戏花草与清露仍保留。最终图见 [2-1 特写](qa-godot-native/spore-settings-20261118/gpu-polished/1280x720-2-1-close.png)。

## 设置页

独立 `settings_page.gd` 绘制暖色纸面、双层圆角细框、金色菱星、淡叶角饰。桌面双栏，窄屏单栏；主体可滚动，恢复默认与返回固定在底部。

- 真实音量滑杆显示百分比；绿/米色胶囊开关对应光效、粒子、减少动态与触屏方向键。
- 柔和/标准/高清按钮连接现有 quality 设置；恢复默认只恢复偏好，不清空旅程。
- 保留首页存档导入/导出、游戏内形态/跳跃/本关重开，以及原返回层级和暂停恢复契约。参考中的尚无行为支持的昵称、震动、全屏开关未作为装饰性假控件加入。
- 修正首版百分比换行、页脚按钮继承省略策略造成裁字、旧/新滚动容器同时存在的问题；失败候选截图和日志保留。桌面收紧区块间距后内容完整显示；触摸控件保留至少 44 px 的主要操作高度。
