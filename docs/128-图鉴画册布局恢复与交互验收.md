# 图鉴画册布局恢复与交互验收

2026-11-19，dev 分支。对应用户旧版图鉴截图：原生图鉴过于简陋，要求参考旧版画册布局。

## 实现

- 新增 `godot/ui/gallery_page.gd`，原生 HUD 接入专用全屏画册。森林、书脊、旧纸、纸夹与压花背景；桌面左侧五类标签和 4×2 卡片，右侧插画、介绍、栖息环境和相遇足迹，侧边切换图鉴／故事。
- 每个卡片保留名称；未发现展示同一重绘素材的 shader 剪影与发现线索，不提前展示故事。选中卡片金色描边，已收集数量来自真实存档。五枚观察标记按相关已通关关卡的孢子收集完整度计算，与关卡三星评分分开。
- 所有藏品经 `Assets.texture_for_source` 使用现有重绘映射；没有换回旧抠图，也没有为截图伪造解锁。没有真实首次发现时间，故使用“相遇足迹”及已完成关卡，不声称是实际时间顺序。
- 宽度不足 1000 或高度不足 600 时采用滚动卡片、点击进入详情；手机双列，较宽小屏三列。返回先退出故事／详情，再回来源页；从游戏内进入时保留“继续当前关卡”。暂停、恢复与收集状态均沿用现有逻辑。
- 首页与其他场景未改。本轮无玩法、关卡拓扑、存档格式或解锁条件修改。
