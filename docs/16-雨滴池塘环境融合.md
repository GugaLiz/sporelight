# 雨滴池塘环境融合

2026-11-03，依据用户的雨林池塘参考图调整第二章的环境表现。保留关卡布局、机关、水位档位和角色素材。

- 池岸使用柔曲线、不规则苔草小岸、局部灌木、蕨叶及岸石，减弱原有均匀卵石边框和亮色围边；池面增加低对比的遗迹倒影、浅岸色差与接水轮廓，外沿有轻雾接触阴影。
- 远景沿用原有遗迹的方位与轮廓，补充边缘树冠、苔树干及湿润林下植被，中央保持留白。
- 雨丝分前后两层，屏幕边缘有少量叶尖水滴；落水雨滴按固定循环下落、溅起、扩散，不使用每帧随机位置。
- 荷叶上的小青蛙只作为环境生灵，不参与碰撞、寻路或任务。位置避开机关运动范围。
- 雨景只读取游戏时钟，暂停时冻结；减少动态模式关闭落雨和溅水，保留静态湿润环境。关闭粒子时也关闭雨丝、水滴及溅水。
