# 首页焦点样式与入口层级

日期：2026-11-07。Web入口：http://localhost:4185/。

## 调整结果

用户反馈默认焦点的矩形外框突兀，首页功能全部平铺、缺少主次。本次只调整首页呈现和入口组织。

- 首页只有一个纸纹主按钮：有可继续的旅程时突出“继续上次的微光”，地图显示为次级“选择花园”；首次游玩突出“开始旅程”。
- 尚未开始的“继续”保留弱化说明，禁用时设为FOCUS_NONE，避免Tab和方向导航停在不能操作的控件上。
- “探索与收藏”默认收起，展开后显示云庭微光、图鉴、花园纪事。从子页返回会恢复展开状态，重新进入首页默认收起。
- 设置是底部工具入口；导入/导出放在设置的“旅程管理”分组。存档工具返回设置，再返回首页，继续保留原有导入预览与确认流程。
- 首页主、次按钮都使用同一套hover和键盘focus表面。保留真实焦点与Enter/Space操作，清空单独叠加的矩形focus样式；移出焦点时恢复原来的静止样式。
- 首页默认四个按钮入口，只有一个使用大号纸纹。小屏通过既有独立滚动区和焦点跟随访问分类，按钮至少44px。

设置入口最小宽度为76px，避免两字被内边距截断。封面背景、人物动画、Logo与加载页坐标合同沿用已有版本。

## 范围与维护

运行源码仅修改 `godot/ui/garden_hud.gd` 和 `godot/ui/menu_cover.gd`。用当前全部运行文件及这两文件的修改前快照重新计算摘要，得到旧版本dd3ca26a，确认没有其他运行源码变化；见 [scope.json](qa-godot-native/home-menu/scope.json)。

MenuCover的style_primary、style_secondary统一处理首页按钮样式，_use_hover_for_focus提供公共焦点行为。新增首页入口应归入主要旅程、探索收藏或设置工具，并使用这些样式方法。不要全局禁用焦点，也不要用自绘图片替代可操作按钮。

首页展开状态记录在页面恢复回调中，与游戏存档分离。按钮继续发出原map、continue、settings意图，原谜题、种路规则、连续移动、存档格式均未修改。
