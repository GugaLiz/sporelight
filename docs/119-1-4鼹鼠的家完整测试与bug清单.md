## 三、Bug 清单

### 🔴 Bug-1（P0 阻断）：角色无法到达部分平台，平台间连通性断裂

**现象**
露薇在**中间平台**（约 f:3:0 附近）时，**走不到左平台**（home f:-4:0 / 鼹鼠所在）和**上方平台**。点击目标格或按方向键，角色原地不动，只提示"这边还没有可走的连接"。

**复现步骤**
1. 完成"固定门闩 + 收门铃 + 放置门铃"后（旅程 1/4）。
2. 控制露薇，尝试走到左平台（鼬鼠 / home f:-4:0）。
3. 角色走不过去，提示"这边还没有可走的连接"。
4. 换手到小苔灵（踩在踏板上），再换回露薇，仍走不到。

**影响**
- **无法归还门铃 → 无法完成 1-4 → 后续关卡（第二、三章 + 云庭样章）全部无法解锁**。
- 属于**阻断性 P0**。

**定位**
- 关卡 `godot/content/levels.json` 1-4 的 tiles 连通性：
  - 左平台 `(-4..-2, -1..1)`、中平台 `(2..4, -1..1)`、下平台 `(2..4, 4..6)`、左下平台 `(-4..-2, 4..6)`
  - 仅 `(3,2),(3,3)` 连接中平台与下平台；**左平台与中/下平台之间缺少可靠连接**。
- 交互：`garden_world.gd` 的 `path_to` / 连通判定。

**建议修复**
1. 检查 1-4 各平台之间的**固定连接格**（尤其左平台 ↔ 中/下平台），确保存在一条始终可走的通路。
2. 若连通依赖"小苔灵踩踏板"，则**换手后踏板必须保持踩住状态**（即另一角色停留原地不解除机关），并在 UI 上明确"桥已连通"。
3. 在断连位置给出**方向性提示**（如"需要小苔灵踩住踏板才能过去"）。

**验收标准**
- [ ] 任意角色配合下，都能从起点走到 home（鼹鼠）完成归还门铃。
- [ ] 断连处有明确的"需要协作"提示。

### 🟠 Bug-2（P1）：双人协作缺乏换手引导

**现象**
"换手 T"切换角色后，右上只显示"露薇·伙伴等候 / 小苔灵·伙伴等候"，玩家**不知道当前控制谁、下一步该切哪个角色、去哪个平台**。1-4 需要多次精确换手，容易迷失。

**复现**
1. 进入 1-4，扳重杆 → 换手 → 踩踏板 → 换手 → 收门铃……
2. 每步换手后，缺乏"当前控制：X"的强提示和"下一步：切到 Y 去 Z"的引导。

**建议**
- 换手时在屏幕中央短暂显示"**当前控制：露薇 / 小苔灵**"。
- "此刻可以做"面板补充"**切到小苔灵踩踏板**"这类跨角色引导。

**验收标准**
- [ ] 换手后有明确的当前角色提示。
- [ ] 有跨角色的下一步引导。

---

### 🟡 Bug-3（P2）：门铃放置后"道路变化"提示与视觉不符

**现象**
放置门铃后提示"稳放好了，看看光与道路有没有一起改变"，但画面上**没有明显可见的道路/光变化**，玩家不知下一步。

**建议**
- 若有道路变化，给出**高亮/镜头聚焦**；若无实际变化，修正提示文案。

**验收标准**
- [ ] 提示所述变化与实际画面一致。

---

### 🟡 Bug-4（P2）：方向键在断连时无反馈

**现象**
按方向键走到断连处时，角色原地不动，**没有"走不过去"的即时反馈**（只有点击世界目标才提示"这边还没有可走的连接"）。

**建议**
- 方向键撞到断连时也给出提示（如轻微震动 + 文字）。

**验收标准**
- [ ] 方向键与点击世界目标的行为反馈一致。
