# 原生角色楼梯接触与防穿模规则

适用于当前 Godot 原生 2.5D。旧文档31中的 Canvas 分片方法属于旧渲染器，不直接用于原生场景。

全关实体楼梯与生成、回收、离岸、接岸的现行合同见 [66：全关实体楼梯与显隐统一计划及验收](66-全关实体楼梯与显隐统一计划及验收.md)。本页保留首关尺度，通用关卡按下述适配执行；实施和验收状态以66号记录为准。

后续墙体美术恢复见 [67号记录](67-原版地图与关卡美术动效恢复及验收.md)：只更新墙画映射及环境表现，不修改本页实体阶梯、碰撞或角色深度规则。

## 实施规则

1. **一套几何定义**：踏面、立面、碰撞和高度查询共同使用当前关卡的 terrain profile；首关为 `FirstGardenProfile`，1-2使用独立配置，其余关卡由 `GenericStairGeometry` 与 `Surface` 的当前连接描述提供公共能力。所有楼梯必须具有真实水平踏面和竖直立面，不能用坡面横线替代。不得单独拉伸可见楼梯或更改碰撞高度掩盖问题。现行入口见 [全关卡规则](56-全关卡优化规则与首关验收基线.md)。
2. **按人物比例设计**：首关踏面深度至少 0.15，单阶升高约 0.1083；连续运动允许胶囊跨越多个踏面，不要求整个人的胶囊直径塞进单阶。后排六级台阶延长至0.90，保留花坛前方平台。通用连接在原0.60跨度内采用四级、每级0.15踏深，0.65总高差对应每级0.1625；保留原平台、梯宽和规则坐标，不直接复制首关六级。
3. **分清碰撞与视觉穿模**：分别查看胶囊实际接触位置、脚锚和图片遮挡。胶囊可接触相邻一级，中心正下方的地面高度差不等于接触侵入；须用真实胶囊扫掠检查接触面和侵入量。中心点落在地面也不能证明角色整个图片没有穿入台阶。
4. **角色深度保持直立**：首关人物使用竖直图片平面，按正交相机上方向补偿投影高度；原素材、脚锚和画面比例保留。禁止用全局关闭深度测试、永久置顶或整体抬高人物修复遮挡。真正前景仍需遮住角色。
5. **接触与移动分责**：物理根节点由连续移动器管理；视觉节点仅校准对应支撑面的脚底。不得为了脚底对齐擅自移动规则格、改变存档位置或放开缺口通行。
6. **动作与生命周期**：朝向变化、走停、滚动、跳跃、读档、切关都要复位临时变换；投影补偿不能每帧累乘。楼梯出现期间保持输入事务锁，完整生成后才提交通路。首关回收是立即移除消失格几何、事务结束后提交状态，并非倒放生长；其他关遵守同一语义。机关离岸时外接梯收平、两岸封边，同一刚体内部梯保留；运动中复用几何，落稳后按新合法邻接接岸。动作前按实际胶囊脚印检查将断开、消失或变高的支撑，不只检查人物中心。
7. **平台间距与坐标**：首关右平台外移0.65格，连接梯由1.0延长为1.65。`FirstGardenProfile.to_physical/to_logical`统一转换规则坐标与物理位置；网格与碰撞同时伸长，固定岛屿保持原尺寸。边界判定、点击命中、花坛与装饰跟随同一映射；存档保留原逻辑偏移，禁止把加长后的物理偏移直接写入旧存档结构。
8. **楼梯步态**：沿梯道行走采用普通速度的62%，沿踏面横向行走保持正常速度。视觉脚锚在阶缘前后0.10物理单位内平滑过渡，始终位于真实踏面上方且最多抬升当前一级（首关约0.1083，通用梯0.1625）；停止立即恢复真实踏面高度。通用视觉回落界限取至少0.20，且容纳一级高度加实际胶囊半径，读档采用同一界限；首两关仍为0.20。阴影独立贴地，物理碰撞继续使用真实台阶，不能拿平滑视觉高度代替碰撞。这是原有序列帧的步速与高度校准，并非骨骼逐脚IK。
9. **连接梯结构**：侧面上缘严格落在各自踏面高度，首两关底部保持已确认的连续斜截面与封闭实体；通用薄连接保持原0.20厚度，使用逐阶底面与闭合立面，避免斜底穿过平肩。不要再加高于踏面的连续斜顶侧板：它在朝相机上升的方向会遮住踏步，使楼梯看成平板。侧面UV2记录距当前踏面向下的物理深度，仅在约0.03厚度内表现石阶薄边；这属于材质明暗，不额外抬高、外扩可见面或碰撞。平面、立面、侧面分别处理纹理，阴影与边缘条纹不得跨越真实阶缘。

## 修改后的必检项

| 范围 | 验证方式 |
| --- | --- |
| 地形/碰撞一致 | `native_world_render_test` 的真实物理射线，`native_first_garden_material_test` 的踏面法线、侧墙和斜底检查 |
| 人物深度/脚锚 | `native_actor_depth_test`：双角色、三条梯道、五档高度、四朝向，检查竖直深度、投影尺寸、接触和重复更新稳定性 |
| 连续通行 | `native_first_garden_structure_test`：三梯道偏心上下行、停步、反向、双连接梯及读档 |
| 画面与操作 | 浏览器检查桌面及手机；截取踏面中间、阶缘、上下平台、上行/下行/停步，检查主角和伙伴；测试不能只依赖脚点坐标 |
| 生长与恢复 | 两向高到低延伸、撤销、回收、再生成，材质与碰撞无残留 |
| 通用实体梯与生命周期 | `native_generic_stairs_test`、`native_generic_stair_movement_test`、`native_stair_lifecycle_test`：四级真实踏面/立面、双角色接触、停步/反向、完整脚印占位、离岸收平/内部梯保留/落稳接岸；首两关独立基线保持 |
| 楼梯步态与石边 | `native_actor_depth_test`逐点检查双角色、三组阶梯和双向行走的高度连续性、抬脚范围、停步接触与阴影；材质测试检查侧面上缘与踏面一致、UV2石边深度及连续斜底，结构测试验证真实偏心通行 |

以上是必须执行的规则，不是所有未来场景都不会穿模的保证。新关卡、素材、相机俯角或角色尺寸变动，应重新验收；未经验证的关卡保持原方案。
