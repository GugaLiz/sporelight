# 123 - 游戏内顶栏与纸卡装饰及底栏留白修复

2026-11-19，`dev`。处理用户本轮三项游戏内UI反馈；122号历史界面验收不能覆盖本次新反馈。

后续用户反馈：本轮简化星纹／叶饰造型被否定，底栏需略放大并区分撤销／重来图标。已按[124号](124-纸卡装饰原造型重绘与底栏图标续修.md)续修；本报告保留历史版本与证据，不代表当前美术接受结论。

## 修改与原因

1. **全景／跟随位置**：所有屏幕均移到右上角，排列为全景／跟随、暂停、地图；沿用实际按钮、原视角切换与状态文案。
2. **装饰矩形色块**：旧金纹、叶饰从整张纸卡图裁出，裁片带着原纸底色，叠在当前纸面后形成较深的矩形。改为代码绘制的无底色金色菱星、细线与鼠尾草绿叶饰，移除重复裁片；保留纸纹与双边框。缩小底角叶饰，避免压到末行文字。
3. **底栏未包住按钮**：参考图2使用小图标、下方文字，次级按钮仅在悬停／按下时显示整块底色，主交互保留浅纸边框。普通单人底栏700×86、双人840×86，左右留24、上下留11像素；小横屏保留50高与44高按钮，左右留18、上下留3像素。窄竖屏使用原有多行布局，留足外框内间距。外框使用可随尺寸绘制的圆角纸面，取消其内部矩形纸纹叠层。

修改入口：`godot/ui/garden_hud.gd`、`godot/ui/game_hud_skin.gd`。共用现有重绘图标，没有新增AI图片或更换游戏角色／道具资源。真实Button及命令保留；关卡规则、碰撞、收集条件和存档格式未修改。
