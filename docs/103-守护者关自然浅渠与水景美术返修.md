# 守护者关水景美术返修草案（已并入104号整关重设计）

> **当前状态更正：** 104号整关方案随后被用户否决，已按用户确认恢复102号有旋转板块版本，见[105号](105-守护者关恢复旋转玩法与版本回退.md)。本文件保持历史，不自动重新实施；水景自然度问题仍待后续局部调整。

2026-11-15。本文件保留用户否定102号青绿色轨道式水景后的初始美术方向。随后用户明确扩大要求，重做3-4整个流程、玩法与空间；本草案因此停止单独实施和发布，内容已并入[104号](104-守护者整关流程与空间重设计.md)。当前合同与验证状态以104号、57号和69号最新记录为准。

## 保留的问题事实

102号水路虽表达对接与存水，却仍像整齐青绿槽条，功能可辨不等于自然优美；102号水利原图验收不覆盖用户新反馈，也不代表美术已获认可。问题沿用69号GQ-003实体支撑与对象辨识、GQ-008水源/唇口/落点链路。

最初候选方向为低矮苔石浅渠、圆润源池/接收池、池底与水面层次、柔和流纹与短落水。不使用发亮青绿实心条、无依据尺寸扩大、悬空假支撑或关闭深度掩盖问题。这些美术目标继续用于104号紧凑水岸。

## 被整关设计取代的范围

本草案最初只改水美术、保留旋转载人水庭和原拓扑；**这不再是实施限制**。104号已将远水庭移到升降台旁，改固定水岸和二态水闸，删除绕图长管与多余旋转，允许搭桥/供水任选先后，加入双岸召空台并实施layoutRevision 2旧档迁移。旧“旋转槽口四向对接”和“无需迁移”不继续作为验收要求。

仍须保护原桥的三格预算、主角搬重镜、伙伴水岸能力、真实蓄水和受光、双人主动照料；装饰不提供道路支撑。水闸关闭后停止流入但保留已存水，撤销/读档按真实状态恢复。具体新动作、碰撞、旧档映射和全流程回归以104号为准。

## 状态与证据

103号没有独立完成或部署版本；104号整关实施已完成并通过同源CPU、双尺寸原生GPU、独立原图与本地实发核验。最终结果和未解决边界统一见[104号](104-守护者整关流程与空间重设计.md)，本文件不另造一份发布结论，也不把102号旧画面或103号草案作为新美术证据。
