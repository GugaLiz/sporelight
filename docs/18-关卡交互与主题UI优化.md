# 关卡交互与主题 UI 优化

日期：2026-11-03。范围为当前主游戏使用的 Garden 2.0 十二关。在现有雨景、镜叶引导和地貌调整上增量实现，沿用关卡布局、已有素材和存档结构。

## 界面与反馈

- 三套章节配色：苔藓山谷的苔绿纸感、雨滴池塘的青蓝水色、星光洞穴的淡紫星光。标题、目标、操作、工具条和结算统一使用章节色。
- 十二关均提供实际状态驱动的修复步骤，撤销和续玩后重新计算；可逆的水路、光路和朝向不会被误记为永久完成。
- 就近操作展示对应的 1–9 快捷键，推荐操作突出显示；缺少条件的操作用虚线表示，点击后说明具体原因。角色换手和同行仍可独立操作。
- 明确提示保留 6.5 秒，行走不立即覆盖；走不到目标时结合本关提示说明后续方向。
- 邻近机关与可照料花床使用章节色光环，操作时出现短促光波与微粒。动态光效、粒子、减少动态均遵循已有设置，完成飘粒和原地跳跃也遵循减少动态。
- 完成面板显示真实收集数与故事，聚焦下一关并限制 Tab 范围；关闭面板留下游玩后恢复控件。完成面板期间不会通过隐藏的移动/撤销快捷键更改关卡。

## 流程修复

雨滴关开始试奏后，即使换到花台上的角色，也能暂停或恢复到试奏前。该入口在续玩后仍保留。撤销会停止自动试奏，避免刚撤销的状态马上被下一拍推进。方向键在试奏中明确提示先暂停。

数字快捷键与实际编号按钮一致；焦点位于按钮时空格正常激活按钮，不会同时触发跳跃。WASD 支持大写输入。无效寻路会停止旧的待行走路线。

手机操作面板与方向控制分置两侧，镜叶浮动引导置于面板上方；矮屏仅显示当前阶段，避免标题遮住引导。提示自动切全景时，全景/跟随按钮同步更新。
