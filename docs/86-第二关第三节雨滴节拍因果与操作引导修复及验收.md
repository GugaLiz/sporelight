## 玩法合同与问题原因

依据[57号2-3合同](57-全关卡玩法契约与优化清单.md)：安排乘台者和演奏者 → 逐拍改变花台方向/高度 → 登北岸开闩固定便道 → 接回伙伴 → 两人主动照料。三叶为转庭、升台、歇一拍，默认排列本来就可用，不强迫玩家先交换。

| 断点 | 原因 | 修复后行为 |
| --- | --- | --- |
| 三拍结束仍能点继续 | commands没有排除终态；play先开启playing，到后续时钟才停，造成短暂行动锁定 | 结束后不再提供play/beat；直接调用也准确拒绝且不改状态，保留观察和重新排练 |
| 第0拍暂停仍能换叶，重排又丢掉新谱 | 只按beat/playing锁换谱，忽略已生成的trial快照 | trial存在即锁谱；先回到试奏前，再编辑新谱，界面只解释一次 |
| 人在花台上找不到恢复操作 | 核心已提供当前trial的继续/重排，原生交互却统一锚到琴台并按距离裁掉 | 当前trial的play/reset可从试奏控制菜单进入；附近门闩/照料优先，单独剩reset时也先开菜单，E不直接回滚 |
| 不知道哪片叶生效、失败是否消耗拍 | 展示偏重命令名，缺少实际队列、已奏/下一拍和结果反馈 | 菜单显示真实三叶队列、已奏n/3、下一动作和上拍效果；高处限位会明确说明花台未转动 |
| 琴、乘台点与固定入口难辨 | 琴键偏平、细字难读；提示脱离实体或被微光遮住 | 琴键倾斜并标转/升/歇；乘台地面改大脚印；门闩未固定/已固定小签附着原实体 |

默认三拍、六种排列及升后转受限的因果保留。错误顺序仍消耗该拍，歇一拍不改变空间，也不新增为通关门槛。允许空台及其他分工探索，不硬编码成唯一步骤。重新排练恢复试奏前人物与平台，保留并去重新收集/观察；未改地图、存档格式、参考答案或其他关机关。
