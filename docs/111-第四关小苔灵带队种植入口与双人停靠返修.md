# 第四关小苔灵带队种植入口与双人停靠返修

2026-11-17。用户在110号交付后补图：当前为“小苔灵·伙伴同行”，两人位于可见播种台旁，进度2/4且没有种植选项，人物持续重叠。[用户原图](qa-godot-native/fourth-buddy-bedside-20261117/user-bedside.png)。本次延用GQ-027，110号只覆盖露薇主动接近的通过记录不能关闭此分支。

## 已确认原因

1. 原领域只允许露薇repair；110号新增的approach也只对露薇提供。小苔灵带队到花坛旁时，E上下文确实为空。直接切回露薇虽恢复接近入口，原switch会关闭follow；露薇独自到原操作位后，伙伴留在侧面，仍不满足会合。原14项诊断与快照保存在本批 `baseline-context.json`、`baseline-before-follow.json`，未改用户保存。
2. 普通跟随停点被花坛硬基挡住，回退为同一个物件旁可走点。两角色不互相推开，旧落稳水平距离仅0.033m，继续60帧仍重合。真实物理重叠已复现；当前native是单个AnimatedSprite3D，不能把疑似双帽直接归给旧2D WalkBlend，也未声称逐像素重现用户图每个重影细节。见[站位诊断与候选](qa-godot-native/fourth-bedside-stance-20261117/README.md)。

## 修正

- 在1-4已归铃、同层且实际靠近可见花坛或原操作位时，小苔灵的E上下文明确列原switch，标为“切换露薇来播种”；露薇已到操作位、伙伴未到且同行关闭时，列原follow“叫上伙伴同行”。接近、会合和原repair各自保留，不自动换人、召回、传送或完成。既有三级提示同步说明角色和换手暂停同行。
- 仅在已有同高 `f:-8:1` 支撑登记两角色真实停靠点：露薇 `(-.44,0,-.44)`、小苔灵 `(+.44,0,-.44)`。沿原电机走到位置，保留旧runtime起点后实际分离；没有改比例、地形、深度、全局碰撞或 `native_movement.gd`。左右相反、使矮伙伴更多藏在石基后的候选已否决。
- 通用双人验收补到Skill视觉合同：双方分别带队、换手后的同行状态、硬物迫使停点回退及旧档恢复，替代点还需检查主动角色占地；不能只从露薇准备快照证明可完成。
