# 图鉴书册设计稿还原

2026-10-27。此前图鉴主要是简化的卡片、详情分栏与纸质配色；本轮按用户提供的完整设计稿改成打开的自然画册。

## 布局与视觉

- 复用`设计稿_v1/图鉴页.png`的森林环境、打开的书、书脊、纸夹和花草装饰。
- 左侧为两行四列卡片，标题、图片、观察印记和选中金色描边独立渲染。
- 右侧为附在书页上的纸质详情卡，展示大图、简介、栖息环境和首次发现。
- 右侧书签在「图鉴 / 故事」之间切换，故事是各条目独立的文字内容，包含玩家的角色称呼。
- 左下读书的露薇单独提取为前景，覆盖在卡片前，延续设计稿构图。
- 图鉴里的光菇使用参考图中真正的发光蘑菇图，藤蔓桥也换成对应的斜向插画。

原图保持不变。新底图中的卡片区域和详情正文改为空白纸纹，避免旧标题、固定计数与插画透出。标题的固定题字保留在书册插画中，页面有对应的可访问标题。

## 数据与交互

当前游戏仍有8个实际图鉴条目，界面显示真实数量，不使用参考稿里的24/26示例数据。

| 分类 | 条目 |
| --- | --- |
| 植物 | 萌芽花台、发光苔藓、睡莲、光菇、星花 |
| 生物 | 发光小虫 |
| 建筑 | 遗迹拱门 |
| 奇物 | 藤蔓桥 |

已发现条目可查看资料与故事。未发现条目仍可选中，但只显示剪影和实际关卡寻找提示，不能提前阅读故事。切换分类会同步选择有效的条目，保留当前阅读模式。

五枚「观察印记」呈现已有的探索完成度：首次发现获得一枚，关联关卡孢子收集越完整，点亮的印记越多；全收集为五枚。计算使用已完成关联关卡的最佳收集比例，不新增奖励、资源消耗或存档字段。老档只有发现记录而无收集数时显示一枚，不推测未知成绩。

首次发现优先从实际已完成的关联关卡推导。只有发现标记而没有对应关卡记录时，显示「记于微光旅程」。分类、选择、阅读模式保存在当前应用状态，翻阅不会写入或改动关卡成绩。

## 手机与键盘

横屏保留书册构图。竖屏使用可滚动的两列卡片，标题与分类栏固定在顶部，详情与故事在卡片下方展开。选择条目后滚到详情，支持返回卡片；切换故事时保留阅读位置。较宽竖屏使用三列卡片。

分类支持左右方向键、Home和End；详情页签支持方向键切换，均保留可见焦点与ARIA状态。未发现条目也能通过键盘查看寻找提示。

## 实现与素材

- `src/app/scenes/galleryData.ts`：条目、分类、故事、真实进度、观察印记、首次发现与选择逻辑。
- `src/app/scenes/galleryScene.ts`：书册、卡片、详情、故事和剪影渲染。
- `src/app/createApp.ts`：分类、选择、页签、键盘与手机阅读位置。
- `src/styles/gallery-journal.css`：桌面书册和手机阅读布局。
- `scripts/prepare_gallery_assets.py`：纸纹重组、卡片/详情底图、前景角色与图鉴插画提取。
- `assets/images/gallery-journal/`：本轮导出素材与来源清单；既有素材文件不覆盖。

素材由现有设计图局部裁切、纸纹重构和透明前景提取得到，未调用AI图片生成。新页面采用相对资源路径，配合项目当前的`base: './'`配置使用。
