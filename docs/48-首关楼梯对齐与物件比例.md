# 首关楼梯对齐与物件比例

2026-11-07。用户确认楼梯出现/消失、操作与流程已自然，当前问题集中在楼梯错位倾斜、交互物件相对岛体过小。本轮在文档47的素材恢复版本上继续修正，保留原素材与玩法。

## 诊断与修改

1. **贴图重复透视**：stairs 原图本身是等角插画。此前矩形采样包含斜向石边，每个格子重新贴图后形成锯齿状错缝。现在把原图中踏面和立面的四边形分别映射到对应网格，源图字节不变。
2. **真实斜楔**：东入口延伸进岛体，入口升高与后排楼梯叠加，最左侧踏面因此横向倾斜。现在东桥在 x=0.58…1.48 内完成六级升高，到岛边即到达前排平台；后排八级踏面从 x=1.5 到4.5保持等高。
3. **压条斜接**：端点独立采样时跨入相邻台阶；外缘还可能取到另一分区。现在压条两端使用同一级、且属于本格内部的高度，逐级收口。
4. **比例**：不整体压缩平面格距，以免挤占角色与伙伴的通路。起始岛墙厚0.90→0.67，东岛前排1.07→0.80，南岛0.77→0.58，约收薄25%。花坛宽0.95→1.28（约+35%），根台0.62→0.82（约+32%），角色与装饰植物比例保持。

关卡内容、移动控制器、按钮和存档逻辑本轮没有修改。南岛仍为平地，根桥仍需种植，回收保护、可选南向探索、直接向东修复保持原流程。
