# 花门小花园与场景补景

本轮针对1-4门铃和任务收尾，以及十二关环境密度作调整。

- 门铃手持与地面共用铃铛绘制，手持时缩小并隐藏拾取标签，替换原先水晶的通用显示。
- 鼹鼠留在家门旁，核心花床移到独立小花园中央。交还门铃前，花门为实体阻挡；交还后播放开门过渡，接回伙伴后可沿石板花径进入花园。
- 小花园包含周边花坛、蕨叶、灌木、小喷泉与蝴蝶。喷泉有实体占位，中央花床留出操作与同行空间。
- 各章节沿边缘增加不同环境素材：山谷花草、蘑菇与灯笼；池塘花丛、蕨叶与睡莲池；洞穴光菇、水晶与遗迹灯塔。生长槽、收集物、机关接近区域优先留空。
- 新增素材来自现有 `material/supplies.png`、`material/world_02.png`，透明导出到 `assets/images/garden-scenery/`。可用 `scripts/prepare_garden_scenery.py` 复现，原图不变。
- 花门、喷泉、蝴蝶以Canvas绘制，与现有材质和光色配合；减少动态时静态呈现，粒子关闭时不绘制飞蝶和水滴。

旧的1-4局内位置保留。已经交还门铃的局面自动开放花门，原先已完成的花园记录仍可回看，新一局的终点则位于花园中央。

专项入口为 `scripts/check-mole-garden.mjs`，记录门铃手持、花门关闭／打开、刷新续玩、花园播种及手机画面，产物保存在 `docs/qa-mole-garden/`。

## 门塔与水景画风细化

花门改用 `world_02.png` 中的水晶遗迹门塔，保留金色尖顶、石阶、藤蔓与花朵。导出独立门框及水晶光幕两层，开门时光幕收拢渐隐，显示真实门洞；碰撞继续由门铃归还状态控制。

喷泉加入实际石板纹理、分块接缝、苔叶、分层石盆与透明水纹；蝴蝶采用有渐变、翅脉、斑点与触须的前后翅造型。轻叶踏板改为有厚度的石台与纹理叶片，踩下时轻沉并亮起暖金色轮廓，替换纯色椭圆。绘制沿用角色的左上暖光与柔和材质，减少动态时保留静态可读状态。

后续画面反馈调整：喷泉恢复更明亮的奶油石色与浅蓝水色，降低石材贴图的暗色覆盖；蝴蝶以约330ms的翅膀铰接周期开合，翅尖随拍动抬落，并按轨迹方向转身。操作杆有石座、转轴、杆身与暖红握把，拉起动画读取实际持杆状态。花园花坛改为明确轮换花型，修复原坐标奇偶规则始终选到黄花的问题，混排素材中的粉花、蓝铃花、黄花、白莲与发光花。

自然行为调整：蝴蝶扇翅进一步放慢为约1–1.28秒一轮，四只大小不同；它们以实际花朵位置为落点，分散停留十余秒，再沿连续缓慢曲线换花，两只偶尔结伴盘旋。周期与落点稳定计算，避免每帧随机跳位；减少动态时保持静态停靠。鼹鼠新增门铃丢失、协作、找到铃铛、道谢开门与花园完成等阶段台词，也可走近选择“和鼹鼠聊一聊”；对话不改变谜题状态，短暂气泡配合嘴部与挥爪回应，不锁定玩家控制。

## 靠近对话与底部操作整理

鼹鼠改为在当前操控的角色走近家门时自动开口，移除“和鼹鼠聊一聊”选项，避免聊天占用播种／互动键。远处获得门铃时不隔空说话；带回家门时识别门铃，归还后就地道谢。离开即隐藏气泡，短暂进出范围不会反复重播，稍后再次来访可重新问候。对话只使用会话内状态，不写入存档，也不产生撤销记录。

露薇与小苔灵的切换移入底栏独立分组，显示角色形象及当前操控高亮，保留 T 键换手。底栏使用按实际宽度绘制的奶油纸色、双层细边框与金色星饰，替代拉伸纸底图；桌面单行，窄屏将角色切换与互动放在第一行，其余六项操作放在第二行。320px 宽度下仍保留至少44px触控区域，单角色关卡自动收起切换分组。

## 露薇步态回归修复

修复每格155ms位移并重置走路时钟、导致反复只播放前两三帧的问题。普通行走恢复原版205ms每格，连续路线共用走路起点并播放完整12帧；跨格保持匀速移动，不再逐格缓入缓出。朝向使用实际等距投影，停下后保留最后朝向，并应用已有素材的身体轻摆、呼吸与落地缩放。通关后“留下看看”时的走路优先于鞠躬姿势；小苔灵独自移动、建筑乘载和减少动态模式不触发露薇原地踏步。

`scripts/check-garden2-walking.mjs` 在实际浏览器逐帧检查连续12帧、转向、通关后散步、伙伴独自行走、手机寻路与减少动态模式，截图与检查结果落在 `docs/qa-garden2/walking/`。

## 清露与贴身携带

清露改用 `supplies.png` 的露珠植株原画，摘取后改为同张素材表中的发光叶包，替换原来的水晶占位图。首次摘取状态随物品保存；放下后仍是叶包，撤销摘取会回到植株，旧存档中已经携带的清露会自动补齐该状态。2-1与3-3共用表现。

随身物品改为腰侧叶片挎袋，细编织带从肩部接到袋口；清露显示原画叶包，门铃露出袋口，其余物件也收在挎袋中。挎袋在角色身体的局部坐标内绘制，共享角色的翻转、轻摆、呼吸和跳跃位移，滚动时贴在蘑菇球上；小苔灵使用缩小尺寸。摘取、放下和交还时淡入淡出，移除角色旁的独立悬浮物件。

`scripts/check-garden2-items.mjs` 验证2-1摘取、转身、放下、撤销、刷新、浇灌及通关，同时验证1-4门铃交还与撤销，截图位于 `docs/qa-garden2/items/`。

挎袋位置细调：袋体缩至原来的65%，从衣裙外侧向内、向上移到腰部，肩带改细并降低明暗反差；拾取、播种的蹲姿及弯腰姿势单独补偿腰部位移，避免动作时袋子仍停在站姿位置。

后续挂法调整：保留小尺寸，袋体下移4个角色绘制单位，挂绳改从领口中央下方延伸，沿衣裙自然弯曲连接袋口，不再斜跨肩膀。

挂绳遮挡调整：露薇仅在正面站姿及正面行走帧显示挂绳；侧面站姿、侧面行走、背身与侧身互动时隐藏挂绳及连接扣，模拟手臂与身体遮挡，只露出小袋子。袋体大小与位置不变。
