# 玩法差异化改版 · 2026-10-20

本版替代旧文档中的12关具体解法和机关规则。页面、美术管线和无失败惩罚的基调继续沿用。

## 问题与改动

旧版大多数机关只设置一次`activated`，永久开放下一条边。玩家不需要选择路线或理解植物特性，重复移动和按E就能通关。此次删除共享的线性关卡生成器，为12关分别配置地图和目标，引入资源回收、可逆道路、显式跳跃、连续光路、音符输入、伙伴位置、水流方向和可见性状态。

E仅执行当前机关唯一的动作；存在多个选择时，需要点击机关面板或按数字1–4作出选择。可选择项展示目标名称、当前选择和实时状态。提示不扣分，撤销同时恢复机关、位置、音符进度、伙伴与收集。

## 每关现在需要思考什么

| 关卡 | 孢子 | 玩家决策 | 与旧版的区别 |
| --- | ---: | --- | --- |
| 1-1 初生的孢子 | 3 | 探索岔路和可选收集 | 保留简单移动教学 |
| 1-2 第一朵花 | 2 | 用唯一种子开启北桥→取花粉→回收→再种东桥 | 两处不能同时播种；种子和孢子分开计数 |
| 1-3 苔藓山谷 | 3 | 把藤桥分别接到两条支路，往返带回叶印，再连终点 | 一次只有一条桥；改方向会收回旧桥 |
| 1-4 鼹鼠的家 | 3 | 先用近处花铃吸引伙伴，再引到花园让出家门 | 伙伴有位置，不能跳过中间花铃；美术仍用现有光虫代理 |
| 2-1 池塘之声 | 2 | 选择睡莲落点，收集两枚水滴再跳往彼岸 | 水面不能步行；跳跃是显式动作，可撤销 |
| 2-2 涟漪之谜 | 3 | 同时保持两片叶组成完整光路，接光水晶才开桥 | 转错任一片叶，光桥立即断开；光线画到真实目标 |
| 2-3 雨滴节拍 | 2 | 在水膜开放窗口演奏「滴→咚→叮→咚」 | 既要判断时机，也要选择音符；三种音符音高不同 |
| 2-4 池塘守护者 | 4 | 沿金色轨迹逐站护送光虫回家 | 花铃只吸引相邻一站；能引回去，不能远程直达终点 |
| 3-1 微光引路 | 4 | 点亮灯后才看见相邻岔路，再探索未知 | 隐藏节点不渲染也不可点击；点灯改变可见地图 |
| 3-2 影子的形状 | 3 | 日光取日碎片→返回→月光取月碎片→走月桥离开 | 日月路线互斥，必须往返切换，而非按固定顺序开门 |
| 3-3 共生之歌 | 3 | 引水到藤蔓→播种取露珠→切水到睡莲→选择落点 | 水流决定能种哪株、能否跳跃；不同机制相互依赖 |
| 3-4 沉睡的守护者 | 8 | 集齐孢子，观察星图回放，再按叶→雨→星→月点亮 | 去掉编号顺序，按位置不同的图案完成记忆仪式 |

雨滴关每2.4秒循环，前1.2秒可敲击。错过时机保留已有音符；选错音符只重奏当前短曲，收集不丢失，且可撤销。低动态模式取消时间窗口，但仍要求正确音符顺序。

终章可无限次重看星图；正常模式逐个高亮星座，低动态模式提供静态顺序辅助。错序不清空已经点亮的星座。

## 工程变化

- `levels.ts`：12张独立地图、目标名称、伙伴路线、镜面目标、跳跃目的地、需要携带的物件。
- `model.ts`：资源预算、可逆条件边、显式动作、循环安全的光路追踪、视野开拓、伙伴位置、音符和仪式状态。
- `CanvasGame.ts`：机关选择面板、数字快捷键、实际跳跃、光路/花香路径/水流渲染、星图回放。
- `audio.ts`：滴/叮/咚三种音高。
- `tests/solutions.ts`：每关单独编写的全收集解法，无通用「一路播种」求解器。
- 当前局增加`puzzleVersion: 2`。旧版地图存档不能套到新地图，重新从本关起点开始；角色名、设置、已通关关卡、解锁和历史星光保留。

## 验证与边界

36项自动测试通过：12关全收集解法及逐步存档恢复；12关可达状态反向搜索验证都存在通关路径；资源不足、方向切换、跳跃限制、镜面回路、节拍时机与顺序、伙伴距离、迷雾、水流依赖、终章错序、撤销和旧档迁移。

额外断言：旧版「遍历能走的节点并一直按E」策略不能解决藤桥、睡莲、反射、节拍、日月桥和引水组合关。

本轮在内置浏览器实际验证种子回收再种、睡莲选落点、双镜完整光路与通关，检查了窄屏和桌面机关面板。旧`docs/qa/`的12关UI验证是上一版记录，不代表本次全套UI回归。新的独立浏览器回归脚本已经同步解法，可使用README命令运行；本轮未另外启动该独立浏览器脚本。

这是玩法逻辑改版，沿用现有场景和切图；连续几何反射、真实物理跳跃、鼹鼠专属动画仍未加入。视觉表现仍为节点地图，但玩家每关的动作、决策、胜利条件和可逆状态已不同。
