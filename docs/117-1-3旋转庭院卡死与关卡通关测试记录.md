## 二、P0 阻断 Bug

### Bug-1：1-3「转动庭院」机关不可达，关卡无法完成

**现象**
1-3 的核心机制是"旋转庭院"（`modules: [{kind:"rotate"}]`）。旋转入口是庭院中心的青色"转"字转盘（`marks.turn @ m:garden:0:0`）。但该转盘位于**独立小平台**上，与庭院主体、与角色起点之间**存在断崖缺口**，角色**无法走到转盘**，因此**无法触发旋转**，关卡死锁。

**复现步骤**
1. 进入 1-3「苔藓山谷」。
2. 尝试点击/寻路到青色"转"字转盘（右下独立平台）。
3. 角色原地不动（提示"这里暂时走不到"），转盘不可达。
4. 无论旋转到哪个角度（0°/90°/180°/270°），转盘都与可达区域不连通。

**影响**
- 关卡**无法完成**，后续 1-4 及第二、三章**全部无法解锁**。
- 属于**阻断性 P0**。

**定位**
- `godot/content/levels.json` → 1-3 `modules: [{id:"garden", kind:"rotate", shape:[[0,0],[-1,0],[-2,0],[0,1],[0,2]]}]`
- `marks.turn @ m:garden:0:0`
- 交互逻辑：`godot/core/garden_world.gd:906`（`if mark.kind == "turn" ...`）、`garden_world.gd:998`（`if id.begins_with("turn:")`）

**建议修复**
1. 确保「转盘」与庭院/起点**始终有一条可走通路**（不要放在独立断崖平台上）；或
2. 改为**走近庭院任意格即可旋转**（`_module_at(player_pos)` 非空时 turn 可用），不需要走到独立转盘；或
3. 旋转后实时重算可达性，保证转盘始终可达。

**验收标准**
- [ ] 任意角度下，角色都能走到「转动庭院」机关并触发旋转。
- [ ] 旋转后可连通到核心花床（`core @ f:0:-4`），完成关卡。

### Bug-2：rest 点劫持主按钮（B-05 复现，1-3 尤其严重）

**现象**
角色站在休息点（`rest @ f:-5:-1`，紧邻起点 `start f:-4:0`）上时，底部主按钮恒为"在这里坐一会儿·E"，**无法旋转庭院、无法交互核心**。而 1-3 的 rest 点正好在角色起步区域，角色一走动就被吸附，导致操作被反复打断。

**复现步骤**
1. 进入 1-3。
2. 角色起点 `f:-4:0` 紧邻 rest `f:-5:-1`。
3. 走到 rest 上 → 底部变"在这里坐一会儿"，旋转/核心交互全部消失。

**影响**
- 与 Bug-1 叠加，进一步加剧 1-3 卡死。
- 对应上一轮文档 `docs/116` 的 **B-05** 未彻底修复。

**建议修复**
- rest/observe 降级为**次级交互**（长按 E 或独立小按钮），**不占用 primary 槽位**。
- 站在 rest 上时，若存在可推进的 turn/core 交互，**优先显示主交互**。

**验收标准**
- [ ] 位于休息点时，主按钮仍显示"转动庭院 / 照料山顶花床"等主交互。
- [ ] 可正常离开休息点，方向键不丢失。

## 四、其它观察

1. **1-3 旋转庭院机制本身有创意**：L 形庭院旋转对齐不同平台，思路好；但**转盘可达性**是硬伤。
2. **rest 点布局风险**：1-3 的 rest 紧邻起点，极易触发，建议重新评估 rest 点的位置。
3. **关卡解锁阻断**：1-3 卡死导致后续全部不可测，建议修复后回归全 12 关。
