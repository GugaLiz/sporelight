# 微光苔原 · Sporelight

> 2026-10-20更新：以下为首版记录；当前关卡规则及本轮验证以[玩法差异化改版](05-玩法差异化改版.md)为准。

产品需求文档 / v1.0 / 2026-10-19

## 1. 产品定义

一款以「帮助生命生长，让生命成为道路」为核心的单人治愈解谜网页游戏。玩家陪伴微光孢子的守护者露薇，穿过苔藓山谷、雨滴池塘与星光洞穴，点亮归家的路。面向喜欢轻解谜、自然意象与短时放松的玩家；单关目标 2–5 分钟，完整旅程目标 30–50 分钟（设计目标，尚未经玩家测试）。

体验原则：安全感、微小的成就、温柔的陪伴。没有生命值、死亡、付费能量、排行榜和通关倒计时。操作错误不消耗资源；等待节拍不会丢失进度。收集用于探索奖励，不作为播种耗材。

依据：`关于游戏/游戏初步想法.md`、`游戏关卡初步设计.md`、`游戏关卡细化设计.md`、`生动画分镜表和提示词.md`。主角默认名统一为「露薇」，已有美术中的蘑菇帽少女形象沿用。

## 2. 首版边界与设计决议

| 原始构想 / 冲突 | 本版落地决议 | 后续扩展 |
| --- | --- | --- |
| 360°滚动、2000–3500px长地图 | 1280×720单屏、节点路径移动；角色平滑移动，不能穿越未生长的桥 | 自由碰撞、镜头滚动 |
| 首关无需全收集 vs 所有关卡消耗孢子 | 孢子不消耗；普通关抵达终点即可，最终关必须集齐8个 | 特殊孢子与可逆资源谜题 |
| 零文字叙事 vs 新手可理解性 | 剧情以画面为主，保留短目标、按钮文字与按需提示 | 完整开场、章节过场动画 |
| 无压力 vs 雨滴限时 | 3秒循环、开放窗口1.5秒；错过可等待；低动态模式窗口常开 | 更丰富节拍关 |
| 反射与真实物理 | 反光叶3个离散角度；正确角度接通光桥 | 连续光线追踪 |
| NPC复杂寻路 | 通过花与光虫的状态演出表达让路 | 鼹鼠、蝴蝶独立动画 |
| 多语言与社交 | 本版简体中文、本地单人、无账户无上传 | 本地化、云存档 |

本版为完整可玩首版，不等同于原案全部动画和物理系统的商业完成版。全新AI美术依赖图片生成工具；现有PNG可重新裁切、统一画布并复用，素材来源必须可追溯。

## 3. 核心循环与规则

1. 在地图选择已解锁关卡，查看主题、最佳收集及进度。
2. 点击路径节点移动；支持键盘方向键 / WASD，Enter或E交互。
3. 经过有孢子的节点自动收集，已收集的不重复计数。
4. 在土地节点点击「播种 / 互动」或按E；植物生长后开放指定道路。
5. 睡莲使跨越有跳跃弧线；反光叶按E旋转；节拍节点等雨滴亮起后激活；最终仪式按数字顺序点亮。
6. 进入终点触发结算，保存最佳收集，解锁下一关与对应图鉴。

每关可重玩；当前关中自动记住位置、机关和收集。撤销回到上一步有效操作；重新开始只重置当前局，不清空历史成绩。离开页面、打开设置、切换窗口与调整尺寸不应重置关卡。提示不扣分。

奖励：通关基础1枚星光；收集至少一半孢子获得2枚；全部收集获得3枚。最高纪录只增不减。最终关必须8/8孢子且4个光点依序激活，才可唤醒水晶花。

## 5. 页面与交互

| 页面 | 内容 | 操作与状态 |
| --- | --- | --- |
| 启动 | 标题、氛围图、加载提示 | 自动转入命名或主菜单；资源缺失有后备绘制 |
| 命名 | 主角、名字输入、随机、默认 | 1–12个中文/英文/数字，去首尾空格；错误就地提示；Enter确认 |
| 主菜单 | 标题、陪伴文案、总进度 | 开始旅程、继续上次、自然图鉴、设置 |
| 章节地图 | 3章节×4关，状态与最佳星光 | 已解锁可进入；已通关可重玩 |
| 游戏 | 地图、角色、孢子、目标、交互提示 | 移动、互动、撤销、提示、重来、暂停、地图 |
| 结算 | 本局真实收集/唤醒、星光、图鉴 | 下一关、重玩、返回地图；最终关显示终章文案 |
| 图鉴 | 8个条目，植物/生物/道具分类 | 未发现隐藏内容；发现后可阅读简介和栖息环境 |
| 设置 | 音量、画质、粒子、光效、低动态、全屏、重命名 | 即时保存；关闭恢复游玩；恢复默认有二次确认 |

普通交互目标≥44 CSS px为目标；横屏优先，竖屏游戏场景保留完整画布、独立排版HUD与操作按钮；非游戏页提示横屏体验。任何尺寸不裁掉核心按钮。关键操作使用可聚焦button，画布节点有DOM操作层和文字标签。弹窗支持Escape、焦点约束和关闭后焦点恢复。

## 6. 视听规范

基调：奶油白、苔藓绿、雾蓝、暖金；洞穴偏蓝紫。以现有圆润蘑菇少女和微缩遗迹切图为基础，柔和阴影，留白清晰。角色、植物、孢子分层；不可把UI文字、角色、可交互物烘焙进背景。按钮和数值用HTML真文字，确保清晰、可访问和可更新。

音频首版使用浏览器合成柔和音符与环境底音，首次用户手势后启用；音乐、环境和交互音各自音量控制。正式钢琴/弦乐录音、雨声采样属于后续音频制作，不伪称已完成。

## 7. 数据、异常与隐私

仅使用浏览器localStorage保存角色名、设置、关卡成绩、当前局和图鉴，无登录、网络上传或分析追踪。损坏存档回退默认值；旧v1山谷存档迁移到首关成绩。存储被浏览器禁用时继续内存游玩并提示本次无法持久保存。切换设备或清理浏览器数据不会自动同步。

素材加载失败时保留可操作节点与文字。后台标签页暂停节拍和声音。禁止未解锁关卡进入；重复结算不能重复累计成绩。恢复设置不清除关卡记录，重命名不清除旅程。

## 8. 验收标准与发布门槛

- 12关均有可执行解法；必须经过机关才能跨越对应断路，不可自由穿越。
- 实际收集与结算一致；普通关允许未全收集通关，最终关严格要求8/8与顺序机关。
- 下一关解锁、重玩、撤销、提示、继续、图鉴均有实际逻辑。
- 设置/resize/失焦不丢失本局；刷新可继续；旧档和异常JSON不会白屏。
- 桌面1280×720及移动横屏无主要遮挡；竖屏保留操作与横屏提示。
- 类型检查、构建、关卡可达性与存档单测通过；浏览器实测关键流程与截图留档。
- 无需外部服务即可运行；不能宣称尚未实测的跨浏览器性能、素材授权或全新AI绘制已完成。
