## 一、升级点：玩家重新安排花园

当前主要循环是：走到机关旁，选择现成目标，开放预设道路，取物，再返回。

新循环是：**观察整片花园 → 生长、搬运或转动其中一部分 → 观察道路与生态一起变化 → 安排两位角色和物件的位置 → 形成能持续帮助生命的连接。**

本次重点是操作对象与解题方式。UI继续沿用纸质按钮、清晰文字和44px触控目标；美术继续使用连续石板、柔和遗迹与蘑菇伙伴。增加粒子、剧情和走路距离不计作玩法升级。

| 当前主要行为 | 2.0主要行为 | 新增判断 |
| --- | --- | --- |
| 播种后开放固定桥 | 在有限芽节内逐格指定生长路径 | 怎样绕障碍、预算是否足够 |
| 固定机关选择桥向 | 转动整块庭院，角色与物件同乘 | 入口、出口、乘客将移动到哪里 |
| 伙伴守指定踏板 | 切换操控两位角色，利用能力差异 | 谁先过去，谁操作，怎样会合 |
| 固定镜叶选择照射目标 | 搬镜叶、放置、再调整朝向 | 位置与朝向怎样共同绕过遮挡 |
| 复述四个音符 | 安排庭院的短动作乐句 | 顺序为何改变结果 |
| 三段机关按顺序完成 | 同一模块同时承载通路、水槽与反光 | 改变一处会失去什么、得到什么 |

**差异门槛**：从1-2起，如果把机关都换回固定位置的“选择目标”按钮后，参考解法仍基本不变，该关重构不合格。1-1允许保留简单教学。

底线：无死亡、无通关倒计时、不要求同时控制两人、不考验精确跳跃。有效操作可撤销，错误布局提供信息，不扣收藏或伤害生物。治愈感来自帮助真实发生，再由画面与声音补足。

## 二、三组能反复组合的能力

### 2.1 引芽：决定路长在哪里

根种长在明确的根台上。玩家从生长端选择相邻空槽，根系逐节顶起石板；一节占用一份芽节预算。用完后可从末端收回重排。

- 四向生长，先预览再确认；槽位、岩石、固定落台有不同轮廓。
- 第一章由1节学到4节，首次不加入分叉。预算不是收藏孢子，试错不消耗收藏。
- 不能穿岩石、跳槽、与自身重叠或跨越未标明的高度。
- 后续根线也能承接水或光，画面必须显示它当前承担的连接。
- 有角色或关键物件站在将收回的路上时，阻止操作并标出占用者；可撤销到上一个安全布局。
- 收回是植物合拢休息，成熟后的固定石阶不再占预算。

### 2.2 搬园：改变位置与朝向

可搬物件包括镜叶、灯与任务物；可动庭院则是一整块石板模块。物件采用明确放置槽，模块采用轨道平移或90°旋转。

- 模块上的地面、角色、物件、植物、沟槽共同移动，使用模块内部坐标。
- 出入口和水槽随旋转真正改变；不是播放转动动画后再打开一条无关的预设边。
- 操作点在模块中心或相连的固定控制台，每关明确采用哪一种。
- 允许乘完整模块移动；不允许站在收回中的根桥上。
- 预览同时显示端口、乘客与受影响的水／光，确认后一次执行。
- 不模拟连续旋转、惯性、自由投掷或真实流体。

### 2.3 换手：主动安排两位同行者

从1-4起可以切换操控。一次只操作一位，另一位原地等候；在已连通安全区域可恢复自动跟随。

| 角色 | 操作能力 | 通行差异 |
| --- | --- | --- |
| 露薇 | 引芽、搬重镜架、操作重杆 | 普通石板与宽拱门 |
| 小苔灵 | 操作轻叶踏板、携小灯 | 能过清楚标出的低矮通道，不能搬重镜架 |

切换不消耗回合，不推进机关。原地等候不会自动把角色送到踏板，必须亲自带它走过去。角色互不推挤，可同乘模块。分开的角色必须有实际会合道路，不能靠远程召回穿过断路。

新增控件仅为角色头像、位置小图与切换按钮。跨区域切换时镜头移动可缩短或取消。

### 2.4 生态读取玩家的布置

- 水沿实际沟槽连续流动，断开后进入可见回流池，没有隐藏损耗。
- 光经过实际位置与朝向的镜叶，并受到石壁遮挡。接收器区分持续供光与一次成熟。
- 萤火虫只在可见停靠点间活动，关键移动由主动邀请触发，不随机择路；停在模块上时随模块移动。
- 成熟植物能固定道路、蓄住水或留下光，改变后续约束。

水真的到达花池、虫真的完成授粉、伙伴真的走回来，才是本轮治愈反馈的基础。

## 四、十二关重构

以下为设计参考解。精确坐标与全部状态尚需灰盒验证，不预先宣称所有地图已经被证明可解。

### 1-1 初生的孢子：第一段路，由你决定

**核心差异**：沿预设路收集，改成第一次亲自指定连接方向；仍保持短教学。

**布置与规则**：树根窝连接中央根台，根台有向前、向侧两个槽。根种只有1节。前方连接核心花床，侧面连接可选暖石；根台始终可返回。

**参考解**：学会移动 → 点击空槽看预览 → 确认长出一节石板 → 沿路到花床播种。也可先看暖石，回根台收回，改向花床。

**选择与变化**：玩家决定第一段路的方向，理解芽节可以取回。侧边是合法探索，不是错误答案。

**治愈与支线**：花朝新路倾斜，伙伴回头等候；暖石可并排坐下，侧路有第三粒收藏。最后原来的树根窝也亮起一点暖光。

**完成与保护**：核心有实际连接，露薇到达并播种。不能远程点花通关，不能收回脚下石板。

### 1-2 第一朵花：在四节芽里，绕过一块石头

**核心差异**：取消北床取物、返回回收、东床再种的固定顺序，改为有限长度的路径构造。

**基础棋盘**：3×3槽位，S=(0,1)为根台，T=(2,1)为花床，岩石=(1,1)，其余槽位可长。每进入一个新槽占1节，预算4节。

```text
  (0,0) —— (1,0) —— (2,0)
    |                  |
  S(0,1)    岩石      T(2,1)
    |                  |
  (0,2) —— (1,2) —— (2,2)
```

**规则**：根线从S连续延伸；水与花粉沿完整根线送到T，露薇也沿同一路径前进。进入T的最后一节根须也占预算，因此两条绕行路线均为4节。接不到T时花床保持等待。

**两条明确合法解**：上→右→右→下；下→右→右→上。两条都恰好4节。

**参考流程**：观察岩石 → 试种看到预算 → 规划四节根线 → 真实走到T → 花成熟固定出口 → 核心播种。

**选择与变化**：比较路线长度，在预算内构造路径。用完预算可收回末端，无需重开。

**治愈与支线**：上路经过蝴蝶，下路经过小蜂，留下不同花纹纪事；不评价哪条更优。通关回看可重新布置，不要求同局反复走两路。

**完成与保护**：T收到连续供给、出口修复、核心播种。无效槽不能确认；撤销恢复角色与根线的同一稳定状态。

### 1-3 苔藓山谷：站在花园里，让它转向远方

**核心差异**：整块庭院旋转，角色、盆花与物件随它移动，改变进入与离开的方位。

**布置**：四岸围绕中心旋转庭院；西岸为入口，北岸为主线花床，南岸为可选水洼，东岸为观景台。庭院有直角通路和中心控制点。

| 庭院角度 | 接通岸台 |
| --- | --- |
| 0° | 西、南 |
| 90° | 西、北 |
| 180° | 北、东 |
| 270° | 东、南 |

**参考解**：从西岸进入0°庭院 → 走到中心 → 预览角色与出口的新位置 → 连人带园转90° → 从北口离开 → 修复花床。

**变化段**：花床固定北岸回入口的便道，再允许玩家乘庭院转180°去东岸观察，不强迫探索四边。

**关键判断**：现在能从哪边进入，转后自己会在哪，出口在哪里。只写“桥接北边”不能替代这个谜题。

**治愈与支线**：伙伴扶住菌帽，盆花朝暖光倾斜；南岸可玩水，东岸能看到上关花纹。

**完成与保护**：经模块到北岸并播种；模块中角色保持本地位置，不留在旧世界坐标，不能从缺失出口走出。

### 1-4 鼹鼠的家：这次，换你来帮我

**核心差异**：实际操控小苔灵穿另一条路线，再切回露薇，形成不同能力的配合。

**布置**：外庭A有露薇专用重杆H，持杆接通A—B短桥。内台B的低拱仅小苔灵可过，通向C。C轻踏板打开A—D门；D重门闩能永久固定两处连接，旁边有丢失的门铃。

**参考解**：

1. 露薇留在A持杆，短桥开放。
2. 换手，操控小苔灵过桥、穿低拱到C，站上轻踏板。
3. 换回露薇，松杆，经A—D门到D。
4. 固定重门闩、取门铃；操控小苔灵沿已固定的连接返回。
5. 两人会合，给鼹鼠装回门铃，进入共同花园播种。

**关键判断**：谁能操作什么，谁该先到哪里；切换角色不会让持杆者自动离开，无需同时按两个按钮。

**治愈与支线**：伙伴第一次独自帮到露薇，鼹鼠主动邀请两位。屋前蜜花、落叶小窝是可选生活互动。

**完成与保护**：门铃归还、两人会合、核心播种。松杆前小苔灵必须已到固定C台；固定门闩后的返回路真实存在。

### 2-1 池塘之声：水位变了，整片池塘都变了

**核心差异**：同一水位同时改变低路、浮台与落点，而非只升一座台。

**布置**：低、中、高三档水位；中心浮台有随台花阀，低岸有呼回点。低位露出通往清露的石阶；中位浮台与核心岸相平；高位通向可选芦苇湾，但与核心岸低拱错开。

**参考解**：低位走石阶取清露 → 回浮台照料睡莲 → 带伙伴升至中位 → 选择与核心岸连接的落点 → 固定岸阶 → 播种。

**关键判断**：何时应走低路，何时该乘浮台，为什么更高不一定更接近目标。高档是合法探索。

**治愈与支线**：清露让睡莲愿意完全舒展；可去高湾把搁浅叶舟送回水中，看伙伴照倒影。

**完成与保护**：睡莲被照料、核心岸接通、播种。阀门所有高度都可用；会被淹没的石阶上有人时先提示回浮台，不以坠落处理。

### 2-2 涟漪之谜：先把光的路摆出来

**核心差异**：反光叶的位置与朝向一起决定光路，不能在固定叶片上选择目标结束。

**基础布局**：光源O=(0,1)向右，第一镜叶A在(1,1)，石壁(2,1)挡直射，花床T=(4,0)。第二镜叶B在侧台，可由露薇搬到固定槽(1,0)，另设支线试验槽。

**参考射线**：O(0,1)→A(1,1)向上→B(1,0)向右→T(4,0)，绕过石壁。

**参考流程**：观察光被挡 → 沿固定岸阶找到B → 搬到上槽 → 调A与B → T接光，光阶出现 → 保持光路到核心。

**变化段**：先照侧花圃会留下成熟花朵，但不能代替T的持续供光；玩家可照料后再搬回镜叶完成主线。

**关键判断**：镜叶朝向正确、位置错误为什么仍无效；移动物件后射线实际经过哪里。

**治愈与支线**：花逐朵朝光抬头，水面显示落点。可借光唤醒侧边小苔窝。

**完成与保护**：T持续接光、核心播种。一次搬一件镜架，搬运走固定岸阶；有人站在光阶上时阻止搬走维持它的镜叶。

### 2-3 雨滴节拍：写一段花园会跳的舞

**核心差异**：从复述音符改为安排已知空间动作的顺序。

**规则**：三个谱位放“转庭、升台、停拍”三片叶，各用一次。试奏后逐拍执行；可暂停、单步、恢复试奏前布局，无须抢拍。

**场景约束**：低位时庭院可旋转，把升降槽对准上岸；升高后旋转轴被上层限位挡住，“转庭”只轻响并标出阻挡，不能执行。

**合法乐句示例**：转庭→升台→停拍；停拍→转庭→升台。停拍位置自由，核心是先转后升。

**参考解**：观察三个动作 → 排乐句 → 露薇上花台、小苔灵留琴台启动 → 查看执行结果 → 到高岸固定便道 → 两人会合。

**关键判断**：先后顺序改变结果；玩家能比较两段乐句，不必记标准答案。

**治愈与支线**：庭院跟雨声轻轻起舞，最终接住高处等雨的花；结束后可自由改节奏与音色。

**完成与保护**：正确岸口接通、两人会合、核心播种。错误试奏保留安全站位；“重新排练”恢复试奏前快照，不删除收藏。减少动态用静态单步呈现因果。

### 2-4 池塘守护者：让小花园载它回家

**核心差异**：运输一片带生物的花园，让授粉改变路径，而非逐站点击花铃。

**布置**：花粉岸A、浮动花园B、核心花岸C。B沿轨道停在近A或近C位置，A与C无法直接飞达。B有蜜花和中央移动控制点，可随台操作。

**规则**：萤火虫携A花粉，只响应主动邀请，飞向接近且开放的停靠花。停到B后与B绑定移动；B靠近C后才能邀请它去C。没有随机择路或限时截击。

**参考解**：在B种蜜花 → 移B近A → 邀请虫落花 → 两人、花和虫共同乘B近C → 邀请虫给C授粉 → C固定石阶 → 共同到核心。

**关键判断**：先邀请还是先移动，当前位置谁才在有效停靠范围。可先近C观察需求再回A，不把观察顺序当作失败。

**治愈与支线**：伙伴坐在花边看光虫；C成熟后光虫留下同伴，形成栖息地。可调整花园位置观察不同水面倒影。

**完成与保护**：花粉送达、C成熟、两人到达并播种。花园移动不使生物脱落，轨道两端均可返回，不能遗失关键生物。

### 3-1 微光引路：把光交给你，也把一段路交给你

**核心差异**：搬灯与两人分工决定照明，光源不再只有固定机关位置。

**布置**：入口一盏暖灯，两人均能携带。低通道通往照孔B，仅小苔灵可过；露薇主路被光感门隔开。B能照到接收叶R，但石窗遮住通往深处灯井的后续光路。

**参考解**：用灯确认固定走廊与反光标记 → 灯交小苔灵 → 换手携灯穿低拱到B，朝R照明 → 换露薇通过门 → 移开石窗遮片，让光经既有镜叶进入灯井 → 灯井自亮、归途固定 → 伙伴带灯回来。

**关键判断**：谁能带光走哪条路，何时可以把灯拿走；位置与遮挡决定光路。

**治愈与支线**：露薇信任伙伴留光，再亲自接它；影虫只在稳定光域聚拢，不追赶玩家。已探索固定地面保留浅轮廓，可停灯边看影子。

**完成与保护**：灯井自亮、两人与灯回主路、核心播种。灯不可丢入虚空；提前撤灯关闭光感门时，两侧仍有安全位置与重新照明／返回方法，不能把灯关在无操作点的一边。

### 3-2 影子的形状：把两种时刻拼成一条路

**核心差异**：保留一段投影，再把另一时刻的路接上，不再切日月各取碎片。

**基础几何**：S=(0,0)，固定落台J=(2,0)，终点T=(2,2)。日光投出S—J两节路，月光投出J—T两节路；影柱在预设槽中调整，必须在J对齐。

**新增规则**：一簇留影苔只固定一段投影；切光后该段保留，另一段由当前光照生成。留影与影柱控制点在中央固定台，先布置再走。

**两条策略**：固定日影S—J再切月光；或先固定月影J—T，再切日光。两者均能形成完整S—J—T。

**关键判断**：保留哪段，柱的位置怎样对齐交点，切换后哪些路还在。简单切换不能直接得到全路。

**治愈与支线**：日月两色花同时留在花园；伙伴试着踩影子的边缘。可留住另一段影，观察侧湾叶画。

**完成与保护**：两段实际相接、两人经路到核心并播种。有人站在将消失的影路上时阻止换影，先回固定台；光束本身不能行走。

### 3-3 共生之歌：转一下，路与水都会变

**核心差异**：同一庭院同时承载步行通道与分水槽，转动一次会同时改变两者。

**布置**：水从中心模块上方进入，两条相邻槽各输一股水。北V为藤根，东L为花台，南M为苔藓，西为回流池。模块有中心操作点和随模块旋转的人行通道。

| 角度 | 两股水去向 | 结果 |
| --- | --- | --- |
| 0° | 北V、东L | 可引芽到花台并升至露珠台 |
| 90° | 东L、南M | 可升台、照亮终点，但初期缺V连接 |
| 180° | 南M、西回流池 | 一处受水，一股安全回流 |
| 270° | 西回流池、北V | 能养藤根，花台无上升动力 |

**共生变化**：露珠交给V后，V形成自蓄水根系并固定石阶，不再占外来水量。

**参考解**：设0° → 在V引芽接到L → 乘L取露珠 → 返回V照料、固定石阶 → 回中心转90° → 沿保留的V石阶到L → 升高，经M照亮的路到核心。

**关键判断**：转动会同时获得与失去哪条路、哪股水；先固定怎样的成果，才允许改变整套布置。不能在菜单里独立勾选两个供水目标代替真实水槽。

**治愈与支线**：藤根学会照顾自己后，把水让给其他生命；伙伴在根边放下小叶子。可用已固定石阶绕到侧苔，试一种不影响主线的光照安排。

**完成与保护**：V自给、L与M持续受水、实际道路接通、核心播种。中心始终可达；失动力花台可安全下降。四个角度都必须能恢复到可解状态。

### 3-4 沉睡的守护者：把一座花园安排成一个家

**核心差异**：取消四间独立小考场，改为一套互相影响的整体花园；结束时路、水、光必须同时成立。

**布置**：中心花外围三块可动庭院，分别以通行、送水、反光为主，但每块至少关联两种功能。水庭转动同时改变水槽与桥口；外庭移动同时携镜叶与改变到达控制点的路。另有一片可引芽固定根台，以及需要运上高槽的重镜叶。

| 花瓣成果 | 对整体解法的作用 | 微光 |
| --- | --- | --- |
| 叶：根台成熟 | 固定外侧石阶，内圈转走后仍能去外庭 | 2 |
| 雨：水庭接入蓄水池与花台 | 形成运送重镜叶到高槽的条件 | 2 |
| 星：镜叶送到高槽并接光 | 固定镜架位置，不要求角色一直拿着 | 2 |
| 月：两人协作后会合 | 最终共同播种可以开始 | 2 |

**参考解的阶段关系**：

1. 全景看清水源、光源与核心的需要。
2. 把内圈与水庭接向根台，完成短引芽，固定叶阶。
3. 露薇沿叶阶搬重镜叶；小苔灵穿低拱操作轻阀，把水接向花台与蓄水池。
4. 露薇携镜叶乘台到高槽，放下镜叶，调外庭，首次接光。
5. 借叶阶与固定高槽安排回程，再调整三庭，让供水、中心光路和回中心的步行路同时成立。
6. 两人沿实际道路会合，确认完整花园仍在工作，共同播种。

这里的四瓣不是完成标记钥匙：镜叶必须经叶阶与水台送达；后续转动仍可能断开光或水，最终必须重新安排整体布局。

**关键判断**：什么成果会留下，怎样运输重物，谁在另一侧操作，怎样满足多个当前条件。允许最终只有一个结构解，不虚称未经验证的多解。

**治愈与支线**：四瓣映出一路帮助过的生命，鼹鼠、蝴蝶、光虫回到花园。完成后可与伙伴坐看全景，碰花瓣回听章节声音，不追加最后一轮记忆测试。

**完成与保护**：四项成果、8粒主线微光、两人会合、路／水／光同时有效、共同播种。每项成果可续玩；固定叶阶与高槽不能无提示消失。具体三庭朝向和端口表必须在灰盒中交付并验证。

## 五、难度和治愈同时成立

### 5.1 每次试验要提供信息

第一次只试一种主要变化，后半关再考虑第二个影响。错布局要看得见原因：水回哪个池，光被哪面墙挡住，哪位角色过不了低拱。

提示依次给观察对象、关系、下一步操作。使用提示、撤销、静音、减少动态均不扣分。新手无需等待失败若干次才获得帮助。

1-2、2-3、3-2已有明确的不同合法策略；其余关的解法数量需验证。仅允许先拿A或先拿B不计作有意义的多解。

### 5.2 把反馈放进因果

| 操作 | 规则变化 | 治愈回应 |
| --- | --- | --- |
| 引芽 | 自己构造的石板可通行 | 花沿这条路逐节开放 |
| 转庭 | 角色与植物被共同托住 | 伙伴扶菌帽、盆花朝光 |
| 换手 | 一人的动作让另一人通过 | 伙伴也能主动照顾露薇 |
| 搬镜 | 光真正绕过遮挡 | 暗处花朵抬头 |
| 试奏 | 排列生成可行的动作顺序 | 花园跟雨声跳舞 |
| 运输花园 | 光虫完成授粉 | 一处地方成为可居住的家 |
| 改变供水 | 成熟植物不再抢占水量 | 被帮助的生命开始帮助别人 |

每关保留一处纯生活停留与一处本关能力的可选小支线，不增加强制货币。普通互动尽量短，模块过渡约0.8–1.2秒，大演出约3–6秒且可跳过；不能靠等待凑时长。

### 5.3 完成与重玩

修复成果可靠保存后，可选择下一关、留下看看或返回地图。收藏不绑定演出时机，刷新不会重复发奖，也不用再走最后一步才能保存。

图鉴保留既有主条目，增加每关纪事；基础故事由通关完整获得，支线补生活细节。不要把理解主线所需的故事藏在全收集中。

## 六、实现上必须真正改变的基础

当前静态格子与单一玩家位置不足以表达本稿。必要改造如下：

- 固定地块与模块内地块的稳定身份；统一变换位置、朝向、连通与命中。
- 两个角色各自的位置、操控状态、携物与所属模块。
- 根线生长端、路径、预算、临时与固定状态。
- 可搬物的持有者、放置槽、朝向，避免同时出现在背包和地上。
- 实际端口的水流与光路，区分持续条件和成熟成果。
- 乐句排列、执行进度与试奏快照。

不得只给旧模型加完成标记、再播放假转动动画。布局变化后，真实能走的路必须变化。

### 6.1 统一保护规则

| 情况 | 处理 |
| --- | --- |
| 收回占用中的根桥 | 阻止并标出角色／物件，可撤销 |
| 移动完整庭院 | 连同角色、物件、生物一起变换 |
| 水位将淹没角色脚下路 | 先回安全台，不以坠落处理 |
| 换影将删除脚下路 | 先回固定台，或撤销 |
| 乐句错误 | 给出被挡原因，恢复试奏快照 |
| 同伴或物件在另一侧 | 提供实际返回途径，不远程传送补洞 |
| 变化中刷新或退出 | 恢复前一稳定状态，不提交半套连接 |

### 6.2 UI、美术与工程边界

UI增量集中在生长端／芽节、放置槽、角色切换、布局预览、三个乐句槽；关系尽量显示在场景内，详细说明按需展开。

保留连续石板和纸质UI。模块以台基、花槽、转轴表示边界，水、光、根线用不同形状表达，关闭动态也能辨识。

不要求自由转镜头、视觉错觉道路、真实流体、投掷物理、战斗、经营或在线系统。物件与庭院采用可预览的离散位置。

### 6.3 存档与旧版兼容

本稿关卡2.0不等同于现有代码的`puzzleVersion:2`，需独立内容版本。保留旧称呼、设置、解锁、历史成绩与图鉴；旧未完成布局不套进新地图，首次进入说明从本关起点开始。

新局保存两人、物件、模块、根线、供水／光路、试奏、修复成果与收藏。至少保留每关最近稳定进度。56粒为新设计总数，不机械映射旧计数；历史星光保留，新成绩记录内容版本。主线奖励必须有唯一标识。

## 七、怎样验证玩法真的升级

### 7.1 先做三个核心原型

| 原型 | 必须可玩的部分 | 核心问题 |
| --- | --- | --- |
| 1-2 | 四节预算、岩石、上下两路、真实通行 | 玩家是否会先规划并尝试另一条路 |
| 1-4 | 两人分别移动、持杆、低拱、轻踏板、会合 | 换手是否产生配合，而非多按一次按钮 |
| 3-3 | 同一模块同时改路与分水，V成熟后约束变化 | 是否需要理解整体关系，旧解法是否还能套用 |

先做灰盒与最小生命反馈，再拓展其他关卡。如果试玩仍主要在找下一个亮按钮，先重做原型。

### 7.2 每关灰盒交付

必须包括布局、完整端口表、角色能力、占用规则、物件位置、参考序列、完成条件、错误尝试与恢复方式、生活场景。

1-2、2-2、3-2先落实本文的简化几何，再做美术扩展。3-4必须补齐三庭的朝向／端口表，验证最终路、水、光能同时成立，不能以四个历史完成标记代替。

### 7.3 规则验收

- 穷举小规模根线路径、模块朝向、水位、留影与关键角色分布，排查不可恢复状态。
- 测试角色、物件和光虫随模块移动后的一致性。
- 验证1-2两条路、2-3两种乐句、3-2两种留影策略均可完成。
- 验证3-3四种角度可恢复，成熟前后资源条件真实变化。
- 终章检查当前同时接通，不能把“曾经接通”算作“现在接通”。
- 在桌面、手机、静音、减少动态、暂停与刷新续玩条件下完成全程。

### 7.4 试玩观察

制作前不宣称时长、难度或多解已经验证。重点观察：玩家能否解释一次操作为何影响别处；是否比较过两种布局；错误是否带来信息；伙伴是否真正参与行动；生命的需要能否从画面看懂；修复后是否有人愿意停下来。

**2.0完成标准**：十二关分别从路径构造、整体空间变换、主动协作、物件布置和生态连接中形成不同问题；后半程一次操作必须影响多个系统。剧情与美术让这些决定更温柔、更清楚，但不能代替决定本身。
