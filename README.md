# 微光苔原 / Sporelight

陪露薇探索、播种，让植物成为前进的道路。基于现有设计与美术完成的12关可玩首版：3个章节、8项自然图鉴、真实收集与结算、本地续玩、撤销与提示、音景及画面设置。

## 云庭微光 · 全新独立样章

主菜单点击「云庭微光」，与小苔灵一起修复三座粉彩几何庭院：转动拱桥、乘坐升降花台、协作开门并点亮星灯。包含原创矢量建筑与角色、六处探索、三张故事页、完成场景回看、手机控制和独立续玩存档。原12关继续保留。详见[样章说明与验证](docs/10-云庭微光样章.md)。

## 2026-10-20 玩法改版

12关已改为独立谜题：种子回收、藤桥转向、睡莲选落点、双镜光路、雨滴演奏、伙伴护送、迷雾探索、日月切换、引水共生和星图记忆。详见[玩法差异化改版](docs/05-玩法差异化改版.md)。到机关旁后点击选项，或按数字1–4选择；E只执行单项互动。

旧版已通关和解锁记录保留，旧的未完成局因地图重做从本关起点重新开始。

## 启动

Node.js 18+，建议20或更高。当前系统默认Node 14不满足Vite 5要求，请先切换版本。

```sh
npm install
npm run dev
```

浏览器打开 `http://127.0.0.1:4173/`。生产构建与检查：

```sh
npm run check
npm test
npm run build
npm run preview
```

若在当前Codex环境使用已提供的运行时，可用PowerShell直接启动：

```powershell
& 'C:/Users/liuli/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node.exe' node_modules/vite/bin/vite.js --host 127.0.0.1 --port 4173
```

## 部署到 GitHub Pages

仓库已包含自动部署工作流。首次使用时，在 GitHub 仓库的 **Settings → Pages → Build and deployment** 中将 **Source** 设为 **GitHub Actions**，然后推送 `main` 分支：

```sh
git add -u
git add .github/workflows/deploy-pages.yml
git commit -m "chore: configure GitHub Pages deployment"
git push origin main
```

Actions 完成后可通过 `https://gugaliz.github.io/sporelight/` 访问。后续每次推送 `main` 都会重新检查、测试、构建并部署，无需提交 `dist` 目录。

## 操作

方向键或WASD每次走一格，空格或J向行进方向跳跃。点击石砖会沿可走路线逐格前往；手机可用方向盘和中间的跳跃按钮。走近植物后按E或选择右侧选项互动。Esc暂停；「减少动态」同时解除雨滴节拍的等待。普通关可不全收集通关，最终关需要8粒孢子并按回放的星图次序点亮。撤销回退上一格或上一次操作，提示不扣分。

每一步自动存入浏览器localStorage，刷新后「继续上次的微光」恢复。每个浏览器独立保存；存储不可用时仍可游玩但无法跨刷新保留。v1旧档自动迁移，原v1键保留。不同关卡共用一个进行中存档，进入另一关会替换上一次未完成局。

## 素材

`assets/images/production/` 包含31项资源、透明PNG图集、manifest、预览页和联系表。访问开发服务器的 `/images/production/index.html` 可查看。运行 `python scripts/prepare_assets.py` 可重新导出，需要Python 3和Pillow；脚本不覆盖源文件。

素材来自当前项目既有美术，经重新裁切、透明背景处理、锚点对齐和背景调色导出。本次没有调用AI图片生成服务；全新独立场景/NPC/过场的制作要求已写入素材文档。

## 回归测试

`npm test` 执行77项规则、存档、人物动作、格子移动、图鉴和云庭样章测试，包括每关物理格子解法、障碍、跳跃限制与样章可达状态验证。浏览器测试额外需要Playwright和本地Chrome，先运行开发服务器，再执行：

```sh
node scripts/browser-check.mjs
```

也可将已安装的Playwright模块绝对路径作为第一个参数，`PLAYWRIGHT_CHANNEL=msedge`可选择Edge。该脚本使用独立的无头浏览器会话，通过实际UI游玩12关，不修改日常浏览器存档。全旅程截图和结果写入 `docs/qa-reference/full-journey/`。格子输入与响应式专项检查运行 `node scripts/check-grid-ui.mjs`，结果在 `docs/qa-grid/`。
