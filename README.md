## 启动

Node.js 18+，建议20或更高。当前系统默认Node 14不满足Vite 5要求，请先切换版本。

```sh
npm install
npm run dev
```

本机浏览器打开 `http://localhost:4173/`。同一内网的同事可通过终端输出的 `Network` 地址访问，例如 `http://10.11.176.213:4173/`。生产构建与检查：

```sh
npm run check
npm test
npm run build
npm run preview
```

若在当前Codex环境使用已提供的运行时，可用PowerShell直接启动：

```powershell
& 'C:/Users/liuli/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin/node.exe' node_modules/vite/bin/vite.js --host 0.0.0.0 --port 4173
```

## 部署到 GitHub Pages

仓库已包含自动部署工作流。首次使用时，在 GitHub 仓库的 **Settings → Pages → Build and deployment** 中将 **Source** 设为 **GitHub Actions**，然后推送 `main` 分支：

```sh
git add -u
git add .github/workflows/deploy-pages.yml
git commit -m "chore: configure GitHub Pages deployment"
git push origin main
```

Actions 完成后可通过 `https://gugaliz.github.io/sporelight/` 访问。后续每次推送 `main` 都会重新检查、测试、构建并部署，无需提交 `dist` 目录。

## 操作

方向键或WASD每次走一格，空格或J向行进方向跳跃。点击石砖会沿可走路线逐格前往；手机可用方向盘和中间的跳跃按钮。走近植物后按E或选择右侧选项互动。花台可在台上升降；协作关需要伙伴守踏板、玩家开永久门闩，再亲自接回伙伴。Esc暂停；「减少动态」即时应用建筑变化，并解除雨滴节拍的等待。普通关可不全收集通关，最终关需要8粒孢子、星图仪式与伙伴共同归来。撤销回退上一格或上一次操作，提示不扣分。

每一步自动存入浏览器localStorage，刷新后「继续上次的微光」恢复。每个浏览器独立保存；存储不可用时仍可游玩但无法跨刷新保留。v1旧档自动迁移，原v1键保留。不同关卡共用一个进行中存档，进入另一关会替换上一次未完成局。

## 回归测试

`npm test` 执行81项规则、存档、人物动作、格子移动、图鉴和云庭样章测试，包括每关物理格子解法、升降、伙伴协作、障碍、跳跃限制与可达状态验证。浏览器测试额外需要Playwright和本地Chrome，先运行开发服务器，再执行：

```sh
node scripts/browser-check.mjs
```

也可将已安装的Playwright模块绝对路径作为第一个参数，`PLAYWRIGHT_CHANNEL=msedge`可选择Edge。该脚本使用独立的无头浏览器会话，通过实际UI游玩12关，不修改日常浏览器存档。全旅程截图和结果写入 `docs/qa-reference/full-journey/`。格子输入与响应式专项检查运行 `node scripts/check-grid-ui.mjs`，结果在 `docs/qa-grid/`。
